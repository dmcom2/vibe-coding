시작 전 사전 준비 사항

설치를 시작하기 전에 아래 항목을 미리 준비해 두면 모든 과정을 막힘 없이 진행할 수 있습니다.

1

구글 개인 계정 2개 준비 (핵심 필수)

Antigravity IDE는 구글 계정 1개당 무료 쿼터(주간 사용량)가 별도로 제공됩니다. 계정 2개를 준비하면 한 계정의 쿼터가 소진되어도 즉시 다른 계정으로 전환하여 24시간 끊김 없는 바이브코딩이 가능합니다.

계정 A (주계정)

평소 사용하는 메인 구글 계정.
먼저 쿼터를 사용합니다.

계정 B (부계정)

별도 Gmail 계정 (무료 생성 가능).
주계정 소진 시 즉시 투입합니다.

💡

구글 계정 만드는 방법

accounts.google.com 접속 ➔ 계정 만들기 ➔ 개인용 선택 ➔ 안내에 따라 완료. 스마트폰 번호 없이 생성 가능합니다.

2

🪟 Windows 10 / 11 PC

64bit 운영체제 권장. 인터넷 연결 필수.

STEP 05 · 특집

🔥 무료 쿼터 극대화! 다중 계정(Multi-Account) 활용 노하우

구글 계정 1개당 Gemini API 무료 쿼터가 별도로 제공됩니다. 구글 계정 2개 이상을 준비하면 쿼터 소진 즉시 다른 계정으로 전환하여 24시간 끊김 없는 자율 코딩 환경을 구축할 수 있습니다.

A

Zoo Code 멀티 프로필(Multi-Profile) 설정 기법

🔑

1단계 — API 키 발급

Google AI Studio에 접속하여 구글 계정 2개로 각각 별도의 Gemini API 키를 발급받습니다.

AI Studio
aistudio.google.com
⚙️

2단계 — 프로필 등록

Zoo Code 설정(Settings) ➔ 프로필/모델 관리 메뉴에서 Profile 1, Profile 2에 각 계정의 API 키를 등록합니다.

🔄

3단계 — 클릭 한 번으로 전환

한 계정의 일일 한도 (500 RPD)에 도달하면 프로필을 클릭 한 번으로 교체하여 쿼터를 즉시 충전합니다.

💡

결과: 계정 A 쿼터 소진 → Profile 2로 전환 → 계정 B 쿼터 소진 → Profile 1으로 복귀. 이 사이클로 24시간 끊김 없는 자율 코딩 환경이 완성됩니다.

B

Antigravity IDE 주계정/부계정 스위칭 기법

1

주간 쿼터 소진 확인 후 로그아웃

IDE 우측 상단 계정 아이콘 클릭 ➔ [Sign Out] 클릭하여 현재 계정 로그아웃

2

부계정으로 즉시 로그인

[Sign in with Google]을 눌러 미리 준비해둔 부계정으로 로그인하면 쿼터가 즉시 충전됩니다.

⭐

3단계 — 계정 전환 직후 반드시 실행!

계정 전환 직후에는 채팅창 상단의 + (New Chat) 버튼을 눌러 이전 세션 메모리를 완전히 비웁니다. 이전 계정의 에러 맥락이 새 세션에 섞이지 않아 깨끗한 상태로 바이브코딩을 재개할 수 있습니다.

📋 다중 계정 운영 권장 구성

주계정 (Primary)

메인 작업용. 쿼터를 우선 사용하고 소진 시 부계정으로 전환합니다.

부계정 (Backup)

별도 구글 계정(Gmail 무료 계정 가능). 주계정 쿼터 소진 시 즉시 투입합니다.

💡

구글 계정은 무료로 여러 개 만들 수 있습니다. 계정을 3개 이상 준비하면 주간 쿼터 걱정 없이 연속 작업이 가능합니다.

  • Resets at & Countdown: 쿼터 초기화 시각 및 남은 카운트다운 시간

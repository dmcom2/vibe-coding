SECTION 5 · Python

파이썬(Python) 제대로 알기

🐍
Python이란?
문법이 사람 말과 비슷해서, 처음 배우는 사람도 쉽게 읽을 수 있는 프로그래밍 언어입니다.
🧰
비유하면: 이미 만들어진 부품(라이브러리)이 정말 많은 "만능 도구 상자"입니다. 엑셀 파일 읽기, 데이터 그래프 그리기, 인공지능 학습까지 — 필요한 부품을 꺼내 조립하듯 사용합니다.
엑셀·데이터 자동화
여러 개의 엑셀 파일을 한 번에 합치거나, 반복되는 보고서 작성을 자동화할 때 가장 많이 쓰입니다.
데이터 분석·시각화
판매 실적, 설문 결과 같은 데이터를 분석하고 그래프·차트로 보여줄 때 활용합니다.
AI·챗봇 개발
우리가 쓰는 Gemini 같은 AI 모델과 연결되는 프로그램 대부분이 Python으로 만들어집니다.
SECTION 5 · Python 설치

파이썬 설치하기

🤖
가장 쉬운 방법: Cline에게 그냥 부탁하세요!
Cline 채팅창에 "파이썬 설치해줘"라고 입력하면, Cline이 터미널 명령어를 스스로 실행해서 설치부터 확인까지 끝내줍니다. 대부분은 이 방법이면 충분합니다.
🔧 직접 설치하고 싶다면? 두 가지 방법이 있습니다
1
홈페이지에서 다운로드 설치
python.org에서 설치 파일을 받아 직접 설치합니다. 설치 화면 맨 아래 "Add python.exe to PATH"를 반드시 체크하세요. 놓치면 Python이 "없다"고 인식되는 가장 흔한 실수가 생깁니다.
python.org/downloads 접속 → Download 클릭 → PATH 체크 → Install Now
2
터미널 명령어로 설치
Windows 11에는 winget이라는 설치 도구가 기본 내장되어 있어, 명령어 한 줄로 설치할 수 있습니다.
winget install Python.Python.3.12
✅
설치 확인하기
어떤 방법으로 설치했든, VS Code 터미널(Terminal → New Terminal)에서 아래 명령어로 확인합니다.
python --version // 예: Python 3.12.4 출력되면 성공
SECTION 5 · Node.js

노드(Node.js) 이해하고 설치하기

Node.js란?
원래 자바스크립트(JS)는 웹 브라우저 안에서만 동작했지만, Node.js 덕분에 내 컴퓨터에서도 JS 코드를 실행할 수 있게 되었습니다. 실시간 채팅, 대시보드 같은 동적인 웹앱을 만들 때 필수입니다.
npm이 함께 따라와요
Node.js를 설치하면 npm(패키지 관리자)도 자동으로 설치됩니다. npm은 다른 사람이 만든 부품(라이브러리)을 손쉽게 내려받아 쓸 수 있게 해줍니다.
🤖
가장 쉬운 방법: Cline에게 그냥 부탁하세요!
Cline 채팅창에 "Node.js 설치해줘"라고 입력하면, Cline이 터미널 명령어를 스스로 실행해서 설치부터 확인까지 끝내줍니다. 대부분은 이 방법이면 충분합니다.
🔧 직접 설치하고 싶다면? 두 가지 방법이 있습니다
1
홈페이지에서 다운로드 설치
숫자 옆에 LTS라고 적힌, 가장 안정적인 버전을 받습니다. 설치 화면에서는 기본값 그대로 Next만 눌러도 됩니다.
nodejs.org 접속 → LTS 버전 다운로드 → 기본값으로 설치 진행
2
터미널 명령어로 설치
Windows 11에 내장된 winget 명령어 한 줄로도 설치할 수 있습니다.
winget install OpenJS.NodeJS.LTS
✅
설치 확인하기
어떤 방법으로 설치했든, 터미널에서 두 명령어 모두 버전이 나오면 정상 설치된 것입니다.
node -v // Node.js 버전 확인
npm -v // npm 버전 확인
SECTION 5 · Git

Git 이해하고 설치하기

Git이란?
게임에서 세이브 포인트를 만드는 것처럼, 코드가 바뀔 때마다 기록을 저장해두는 프로그램입니다. 문제가 생기면 이전 저장 시점으로 언제든 되돌릴 수 있습니다.
GitHub과의 관계
Git이 "저장·되돌리기 기능이 있는 프로그램"이라면, GitHub은 그 기록들을 인터넷에 올려 팀원과 함께 보고 공유하는 서비스입니다. Git이 설치되어 있어야 GitHub도 사용할 수 있습니다.
🤖
가장 쉬운 방법: Cline에게 그냥 부탁하세요!
Cline 채팅창에 "Git 설치해줘"라고 입력하면, Cline이 터미널 명령어를 스스로 실행해서 설치부터 확인까지 끝내줍니다. 대부분은 이 방법이면 충분합니다.
🔧 직접 설치하고 싶다면? 두 가지 방법이 있습니다
1
홈페이지에서 다운로드 설치
아래 주소에서 다운로드한 뒤, 설치 화면에서 특별히 바꿀 것 없이 계속 Next만 눌러 기본값으로 설치합니다.
git-scm.com/downloads 접속 → 운영체제에 맞는 설치 파일 다운로드 → 기본값으로 설치 진행
2
터미널 명령어로 설치
Windows 11에 내장된 winget 명령어 한 줄로도 설치할 수 있습니다.
winget install Git.Git
✅
설치 확인하기
어떤 방법으로 설치했든, 터미널에 아래 명령어를 입력해 버전이 나오는지 확인합니다.
git --version // 예: git version 2.45.0 출력되면 성공
SECTION 5 · 확인

브라우저 확인 & 설치 체크리스트

🌐
웹 브라우저는 이미 준비되어 있어요
Chrome, Edge 같은 브라우저는 대부분 컴퓨터에 이미 설치되어 있습니다. Cline이 만든 결과물(HTML 파일)은 브라우저로 열어 확인하며, F12 키를 누르면 "개발자 도구"로 오류 메시지도 확인할 수 있습니다.
한 번에 모아보는 설치 확인 명령어
VS Code에서 Terminal → New Terminal을 연 뒤, 아래 네 줄을 하나씩 입력해보세요. 모두 버전이 표시되면 오늘 배운 실행 환경이 전부 준비된 것입니다.
python --version
node -v
npm -v
git --version
🛠️
버전이 안 뜨고 오류가 난다면?
대부분 "설치 후 VS Code를 다시 시작하지 않아서" 생기는 문제입니다. VS Code를 완전히 껐다가 다시 켜고 터미널을 새로 열어 명령어를 재입력해보세요.
SECTION 5 · 확장

이제 HTML을 넘어 확장합니다

🚀
지금까지 실습은 모두 브라우저 하나로 열리는 HTML 파일이었습니다. 오늘 익힌 Python·Node.js·Git 덕분에, 이제는 훨씬 더 다양한 형태의 프로그램을 바이브 코딩으로 만들 수 있습니다.
지금까지 · HTML 실습
더블클릭하면 브라우저 하나로 바로 열리는 정적인 결과물이었습니다.
예: 디지털 명함 · 계산기 · 타이머 · 메모장
이제부터 · 다양한 실행 환경
Python·Node.js·Git이 더해져, 브라우저 밖에서 동작하는 프로그램까지 만들 수 있습니다.
예: 자동화 스크립트 · 실시간 웹서비스 · 협업 프로젝트
Python 예시
매일 아침 여러 지점의 엑셀 실적을 자동으로 취합해 보고서를 만들어주는 프로그램
Node.js 예시
여러 명이 동시에 접속해 실시간으로 공지를 확인하는 사내 게시판 서비스
Git 예시
여러 팀원이 함께 코드를 수정하고, 실수해도 이전 버전으로 되돌릴 수 있는 협업 프로젝트
💡
Cline에게 "~해줘"라고 말하는 방식은 똑같습니다. 달라지는 건 그 결과물이 동작하는 무대(실행 환경)뿐입니다.

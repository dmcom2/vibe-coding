핵심 기술 ① — oninput & fmtB()

슬라이더 즉시 반응 + 한국식 금액 표기
// oninput: 입력 즉시(Enter 불필요) 호출 // <input type="range" oninput="calc()"> // <input type="number" oninput="calc()"> // 슬라이더 값과 레이블 동기화 function calc() { const baseRev = +document.getElementById('baseRev').value; const growthR = +document.getElementById('growthR').value / 100; // 레이블 동기화 (슬라이더 현재 값 표시) document.getElementById('growthLabel').textContent = (growthR*100).toFixed(1) + '%'; // 계산 후 화면 갱신 const result = simulate(baseRev, growthR); updateUI(result); } // 한국 대단위 통화 포매터 function fmtB(n) { const abs = Math.abs(n); if (abs >= 1e12) return (n/1e12).toFixed(1) + '조'; if (abs >= 1e10) return (n/1e10).toFixed(1) + '백억'; if (abs >= 1e8) return (n/1e8).toFixed(1) + '억'; if (abs >= 1e4) return (n/1e4).toFixed(0) + '만'; return n.toLocaleString() + '원'; }
💡 onchange는 포커스 이탈 시에만 발동, oninput은 한 글자·한 픽셀마다 발동. 슬라이더는 반드시 oninput을 사용하세요.

핵심 기술 ② — 계절 보정 & 시나리오

월별 배수 배열로 현실적인 매출 추정
// 계절 인수 배열 (1월~12월 배수) const SEASONS = [0.7,0.75,0.9,1.0,1.05,1.1, 1.2,1.15,1.0,0.95,1.1,1.3]; // 시나리오별 파라미터 const SCENARIOS = { optimistic: { growthBonus: 0.05, costRatio: 0.60 }, base: { growthBonus: 0.00, costRatio: 0.65 }, pessimistic:{ growthBonus: -0.03, costRatio: 0.72 }, }; function simulate(baseMonthlyRev, growthRate, scenarioKey) { const sc = SCENARIOS[scenarioKey]; const monthlyRevs = []; for (let m = 0; m < 12; m++) { // 성장률 복리 + 계절 보정 const growthFactor = Math.pow(1 + growthRate + sc.growthBonus, m / 12); const rev = baseMonthlyRev * growthFactor * SEASONS[m]; const cost = rev * sc.costRatio; monthlyRevs.push({ rev, cost, profit: rev - cost }); } const annualRev = monthlyRevs.reduce((s, m) => s + m.rev, 0); const annualProfit = monthlyRevs.reduce((s, m) => s + m.profit, 0); return { monthlyRevs, annualRev, annualProfit, margin: annualProfit / annualRev * 100 }; }

핵심 기술 ③ — 민감도 분석 테이블

성장률 × 비용률 조합의 순이익 매트릭스
// 성장률 범위: -5% ~ +15% (5단계) const GROWTH_STEPS = [-0.05, 0, 0.05, 0.10, 0.15]; // 비용률 범위: 55% ~ 75% (5단계) const COST_STEPS = [0.55, 0.60, 0.65, 0.70, 0.75]; function buildSensitivityTable(baseRev) { let html = '<tr><th>성장률↓ / 비용률→</th>'; COST_STEPS.forEach(c => html += `<th>${(c*100).toFixed(0)}%</th>`); html += '</tr>'; GROWTH_STEPS.forEach(g => { html += `<tr><td>${(g>=0?'+':'')+(g*100).toFixed(0)}%</td>`; COST_STEPS.forEach(c => { const annualRev = baseRev * 12 * (1 + g); const profit = annualRev * (1 - c); // 이익률 기준으로 셀 색상 결정 const color = profit > 0 ? '#e0f2fe' : '#e0f2fe'; html += `<td style="background:${color}">${fmtB(profit)}</td>`; }); html += '</tr>'; }); return html; }
💡 민감도 분석은 "만약 성장률이 X이고 비용률이 Y라면 이익이 얼마인가"를 한눈에 보여주는 2D 매트릭스입니다. 이중 forEach로 행·열을 만듭니다.

P&L 테이블 구성

손익계산서 형태로 12개월 데이터 표시
1

헤더: 1월~12월 컬럼

Array.from({length:12}, (_, i) => `${i+1}월`)로 헤더를 동적 생성. 연간 합계 열 추가.

2

매출 행

simulate() 결과의 monthlyRevs 배열을 map해서 각 셀에 fmtB(m.rev)로 표시. 마지막 셀에 연간 합계.

3

비용 / 이익 행

동일한 구조. 이익이 음수이면 style="color:red"로 빨간색 표시.

4

이익률 행

(profit/rev*100).toFixed(1)+'%'. 30% 이상이면 초록, 0~30%면 주황, 음수면 빨강 배경.

5

차트 동기 업데이트

chart.data.datasets[0].data = monthlyRevs.map(m => m.rev) 후 chart.update()로 Chart.js 차트를 테이블과 함께 갱신.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 입력 변수를 분류해 목록화

"매출 가정/비용 가정/세금&기간" 카테고리로 슬라이더 10개를 묶어 나열했습니다. AI가 각 변수에 맞는 range 속성(단위·범위)과 레이아웃을 정확하게 생성합니다.

"SEASONS 배열", "fmtB() 함수"처럼 코드에 쓸 변수·함수 이름을 명시하면 AI가 코드 전반에서 일관된 이름을 사용해 유지보수가 쉬운 코드가 생성됩니다.

POINT 3 — KPI 집합을 이름과 함께 열거

"KPI 카드 4개: 연간 예상 매출·영업이익(EBIT)·순이익(세후)·월 손익분기점"처럼 결과값 이름과 개수를 명시하면 AI가 재무 공식을 직접 구현합니다.

POINT 4 — 차트 종류와 데이터 계열 명시

"① 월별 매출&이익 추이 라인차트 ② 비용 구조 파이차트"처럼 Chart.js 타입과 데이터 계열을 함께 기술하면 chart config가 정확히 생성됩니다.

2

포매터 요구

"금액은 fmtB() 함수로 조/억/만 단위로 표시해주세요" — 함수명까지 지정하면 일관된 코드가 나옵니다.

3

미션 1: Monte Carlo 확률 시뮬레이션

성장률과 비용률의 표준편차 입력을 추가하고, 1,000회 무작위 시뮬레이션을 실행해 순이익 분포를 SVG 히스토그램으로 시각화. P5(하방 위험)·P50(중앙값)·P95(상방 기대) 지표를 계산해 표시.

  • Box-Muller 변환으로 정규분포 난수 생성 함수 구현
  • 1,000회 루프 결과를 구간별로 카운트하여 분포 계산
  • SVG viewBox 히스토그램 동적 렌더링 및 P5/P50/P95 표기
4

미션 2: Goal-Seek 목표 역산 계산기

원하는 연간 순이익 목표를 입력하면 이진 탐색(binary search)으로 필요한 매출 성장률을 자동 역산하여 슬라이더 값을 갱신하는 'Solve!' 버튼 구현.

  • 이진 탐색 알고리즘 구현 (허용 오차 1만원 이내 수렴)
  • 역산된 성장률로 슬라이더 value와 표시값 동기화
  • 역산 성공·실패 결과를 Toast 메시지로 알림

오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀 두면 수업이 술술 풀립니다

📌 운전자본 (DSO·DIO·DPO)

받을 돈(매출채권)+재고−줄 돈(매입채무). 회수기간(DSO)이 길수록 현금이 더 묶입니다.

📌 잉여현금흐름 (FCF)

세후 영업이익 + 감가상각 − 설비투자 − 운전자본 증가. 주주·채권자에게 돌려줄 수 있는 현금입니다.

📌 할인율 (WACC)

내년 100원은 오늘 100원보다 가치가 낮습니다. 미래 현금을 오늘 가치로 바꾸는 이율입니다.

📌 잔존가치 (TV)

계획 기간(3년) 이후 영원히 이어질 가치. FCF × (1+g) ÷ (WACC − g), 고든 성장 모형으로 구합니다.

📌 NPV · IRR

NPV = 기업가치 − 투자 금액. IRR은 NPV를 0으로 만드는 할인율 — "이 투자의 연 수익률"입니다.

📌 민감도 분석

가정 하나를 바꿨을 때 결과가 얼마나 흔들리는지. 토네이도 차트와 2차원 데이터 표로 봅니다.

핵심 기술 ① — 3대 재무제표를 하나의 루프로

매달 손익 → 현금흐름 → 재무상태 순서로 계산하면 세 표가 저절로 맞물립니다
// 손익계산서 const sales = p.base * (1 + mg) ** t * sf; const ebitda = sales - cogs - opex; const ebit = ebitda - dep; // 감가상각 const net = ebit - interest - tax; // 현금흐름표 (간접법) const cfo = net + dep - dNwc; // 비현금 비용 되돌리기 cash += cfo - p.capex;
// 재무상태표 const assets = cash + ar + inv + ppe; const liab = ap + p.debt; const equity = eq0 + retained; // 순이익 누적 // 연결이 맞으면 매달 0 const check = assets - liab - equity; // eq0 = 기초 자산 − 기초 부채 로 출발
📒 완성 예제에서 36개월 모두 대차 차이는 0(부동소수점 오차 10⁻¹⁴ 수준)입니다. 하나라도 빠뜨리면 앱 상단 배지가 빨간 "대차 불일치"로 바뀌어, AI가 만든 재무 로직을 스스로 검산할 수 있습니다.

핵심 기술 ② — 운전자본과 결손금 이월

"흑자인데 현금이 부족하다"와 "적자 뒤 첫 흑자에는 세금이 없다"를 코드로
// 운전자본: 일수 ÷ 30 × 월 금액 const nwc = (s, c) => ({ ar: s * p.dso / 30, // 매출채권 inv: c * p.dio / 30, // 재고 ap: c * p.dpo / 30 // 매입채무 }); // 늘어난 만큼 현금이 묶인다 dNwc = (w.ar + w.inv - w.ap) - (prev.ar + prev.inv - prev.ap);
// 결손금(nol): 적자는 쌓아 두었다가 // 이익이 나면 먼저 공제한다 if (ebt > 0) { const use = Math.min(nol, ebt); nol -= use; tax = (ebt - use) * taxRate; } else { nol -= ebt; // 적자 누적 }
💸 완성 예제 기준 12개월째부터 영업흑자지만, 매출채권이 쌓여 현금은 15개월째 −4.0억까지 떨어집니다(추가 자금 9억 필요). DSO를 60일에서 30일로 줄이면 최저 현금이 +3.1억으로 올라갑니다.

핵심 기술 ③ — DCF 기업가치와 IRR

3년 FCF의 현재가치 + 잔존가치 = 기업가치, NPV를 0으로 만드는 할인율 = IRR
// 연도별 FCF를 연말 기준으로 할인 const pv = fcf.map((f, i) => f / (1 + w) ** (i + 1)); // 고든 성장 모형 잔존가치 const tv = fcf[2] * (1 + g) / (w - g); const ev = sum(pv) + tv / (1 + w) ** 3; const npv = ev - p.invest; // w ≤ g 이면 계산 불가 → 경고
// IRR: 이분법으로 NPV(r) = 0 찾기 let lo = -0.99, hi = 10; for (let i = 0; i < 100; i++) { const mid = (lo + hi) / 2; if (npv(lo) * npv(mid) <= 0) hi = mid; else lo = mid; } // 현금흐름: [−투자, FCF1, FCF2, FCF3 + TV]
🏷️ 완성 예제 기준 기업가치 191억, 투자 150억 대비 NPV 41.5억, IRR 20.1%(할인율 11%보다 높아 투자 매력 있음). 그런데 기업가치의 95%가 잔존가치 — 장기 가정의 근거가 투자 심사의 핵심인 이유입니다.

핵심 기술 ④ — 민감도·가치 브리지·목표 역산

"무엇이 가장 중요한가", "왜 달라졌나", "얼마나 필요한가"에 답하는 세 도구
// 토네이도: 가정 하나씩 ±20% TORNADO.map(([k]) => ({ evLo: model({ ...p, [k]: p[k] * 0.8 }).val.ev, evHi: model({ ...p, [k]: p[k] * 1.2 }).val.ev })).sort(흔들림 큰 순); // 브리지: 바뀐 가정을 하나씩 차례로 대입 cur = { ...cur, [k]: to[k] }; delta = model(cur).val.ev - prev;
// 목표 역산: f(x) = 지표(x) − 목표 const f = x => metric(model({ ...p, [k]: x })) - target; let lo = d.min, hi = d.max; if (f(lo) * f(hi) > 0) return '범위 밖'; for (let i = 0; i < 50; i++) { const mid = (lo + hi) / 2; if (f(lo) * f(mid) <= 0) hi = mid; else lo = mid; }
🎯 완성 예제에서 가장 민감한 가정은 매출원가율(±20%에 기업가치 −19억 ~ 402억). 목표 역산으로 "최저 현금 5억을 지키려면?"을 물으면 DSO 17일이라는 답이 나옵니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 재무 로직을 시키는 법"을 배웁니다

POINT 1 — 가정은 범위·기본값까지

21개 가정의 최소·최대·간격·기본값을 모두 적었습니다. 기본값이 다르면 강사 화면과 수강생 화면의 숫자가 달라 수업이 흔들립니다.

POINT 2 — 공식은 수식으로

감가상각, 운전자본, 잔존가치를 수식으로 적었습니다. "DCF로 기업가치 계산해줘"라고만 하면 할인 시점·잔존가치 방식이 AI마다 다릅니다.

POINT 3 — 검산 장치를 요구한다

"매월 대차 차이를 계산해 배지로 표시"를 넣었습니다. AI가 만든 재무 로직이 맞는지 사람이 일일이 볼 필요가 없어집니다.

POINT 4 — 예외 조건을 적는다

"WACC ≤ 영구성장률이면 경고"처럼 계산이 깨지는 경우를 명시했습니다. 빠지면 기업가치가 음수 무한대로 튀는 화면이 나옵니다.

✏️ 비교해 보기
❌ 막연한 요청

"매출 시나리오별로 이익이랑 기업가치 계산해 주는 앱 만들어줘."

✅ 구체적인 요청

"FCF = EBIT×(1−세율)+감가상각−CAPEX−운전자본 증가, 연말 할인, 잔존가치는 고든 성장 모형."

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요
⚖️ "대차 불일치가 떠요"

자본 계산에 기초 자본(기초 자산 − 기초 부채)이 빠졌거나 운전자본 증가를 현금흐름에 빼먹은 경우가 대부분입니다. "월별 대차 차이를 표로 보여줘"라고 요청해 처음 어긋나는 달을 찾으세요.

📈 "IRR이 — 로 나와요"

투자 금액이 0이거나 모든 현금흐름이 같은 부호면 IRR이 없습니다. 투자 금액을 넣고, 이분법 구간(−0.99~10)에서 부호가 바뀌는지 확인하세요.

♾️ "기업가치가 이상하게 커요"

WACC와 영구성장률이 너무 가까우면 잔존가치 분모가 0에 가까워집니다. WACC가 영구성장률보다 충분히 큰지 확인하세요.

🎚️ "슬라이더가 손에서 빠져요"

값이 바뀔 때마다 슬라이더 HTML을 다시 만들면 드래그가 끊깁니다. "슬라이더는 한 번만 만들고 값만 갱신해줘"라고 요청하세요.

🤖 만능 해결법: F12 → Console의 빨간 오류나 이상한 화면을 그대로 복사(캡처)해서 Antigravity에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요.

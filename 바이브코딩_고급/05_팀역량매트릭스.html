핵심 개념 ② — 레이더 차트

Chart.js radar 타입으로 팀원별 역량 비교
// 팀원별 color 정의 const COLORS = ['#8b5cf6', '#3b82f6', '#10b981', '#f59e0b', '#ef4444']; function renderRadarChart() { if (radarChart) radarChart.destroy(); radarChart = new Chart(ctx, { type: 'radar', data: { labels: SKILLS.map(s => s.name), // 스킬명 → 꼭짓점 레이블 datasets: MEMBERS.map((m, i) => ({ label: m.name, // 각 스킬 점수 배열 data: SKILLS.map(s => scores[m.id][s.id] || 0), borderColor: COLORS[i], backgroundColor: COLORS[i] + '30', // 30% 투명도 pointBackgroundColor: COLORS[i], })) }, options: { scales: { r: { min: 0, max: 5, ticks: { stepSize: 1 } } } } }); }
💡 COLORS[i] + '30' — hex 색상 뒤에 '30'을 붙이면 약 19% 투명도의 fill 색상이 됩니다. '80'은 약 50%, 'ff'는 불투명. 간단한 트릭!

핵심 개념 ③ — 갭 분석

목표 수준 vs 현재 팀 평균 → 교육 우선순위 자동 도출
const TARGET = 4; // 목표 역량 수준 (0~5) // 스킬별 갭 계산 및 정렬 function calcGapAnalysis() { return SKILLS .map(skill => ({ name: skill.name, avg: getSkillAvg(skill.id), gap: TARGET - getSkillAvg(skill.id), })) .filter(s => s.gap > 0) // 갭 있는 것만 .sort((a, b) => b.gap - a.gap); // 갭 큰 순서로 정렬 } // 목표 미달 팀원 찾기 function getMembersBelow(skillId) { return MEMBERS.filter(m => (scores[m.id][skillId] || 0) < TARGET ); } // 갭 분석 렌더링 function renderGapView() { const gaps = calcGapAnalysis(); document.getElementById('gapList').innerHTML = gaps.map(g => `<div class="gap-row"> <span>${g.name}</span> <span>현재 ${g.avg.toFixed(1)} → 목표 ${TARGET}</span> <div class="gap-bar" style="width:${g.gap/TARGET*100}%"></div> </div>`).join(''); }

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 라이브러리 버전까지 고정

"Chart.js 4.4.0 (CDN)"으로 버전을 못박으면, API 호환성 오류 없이 정확한 메서드가 사용된 코드가 생성됩니다. 버전 미명시 시 구버전 API가 섞이는 오류가 흔합니다.

POINT 2 — 데이터 구조 변수명·타입 직접 명시

"scores[memberId][skillId] = 0~5"처럼 변수명과 타입을 직접 지정하면, AI가 원하는 2D 중첩 객체 구조를 임의 설계 없이 그대로 구현합니다.

POINT 3 — 탭 순서를 번호로 명세

"탭 3개: ① 역량 매트릭스 ② 레이더 차트 ③ 갭 분석"처럼 번호와 순서로 뷰 계층을 명확히 기술하면, AI가 전환 순서를 혼동하지 않고 정확한 탭 구조를 생성합니다.

POINT 4 — 인터랙션 동작을 단계 순서로 명세

"셀 클릭 → 점수 0~5 순환 → 배경색 반영 → 범례 표시"처럼 사용자 행동과 시스템 반응을 순서대로 기술하면 정확한 UX 로직이 구현됩니다.

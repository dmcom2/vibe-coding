날짜→픽셀 변환

DAY_W = 24픽셀/일. 시작일 기준으로 날짜 차이 × 24 = left 오프셋. 이 하나의 상수가 전체 차트 스케일을 결정.

마일스톤 다이아몬드

시작일 = 종료일인 태스크를 다이아몬드로 표시. CSS transform: rotate(45deg)로 정사각형을 45도 회전.

핵심 기술 ① — 날짜→픽셀 변환

모든 막대의 위치와 너비를 결정하는 핵심 공식
태스크 A
태스크 B

const DAY_W = 24; // 1일 = 24픽셀 (이 상수 하나로 전체 스케일 조정) // 기준일(baseDate)로부터 타겟 날짜까지 일수 계산 function dateToDay(base, target) { return Math.floor( (new Date(target) - new Date(base)) / (1000 * 60 * 60 * 24) ); } // 태스크 막대의 CSS 좌표 계산 function calcBarStyle(task, baseDate) { const startDay = dateToDay(baseDate, task.start); const endDay = dateToDay(baseDate, task.end); return { left: startDay * DAY_W + 'px', width: (endDay - startDay + 1) * DAY_W + 'px' }; }
💡 날짜를 픽셀로 바꾸는 공식: 일수 × DAY_W = 픽셀. DAY_W = 24를 48로 바꾸면 차트가 2배 확대됩니다. 이 상수 하나가 줌(zoom) 기능의 핵심.

핵심 기술 ② — 월 헤더 동적 생성

시작월부터 종료월까지 반복하며 월 셀 자동 생성
function renderMonthHeader(startDate, endDate) { const start = new Date(startDate); const end = new Date(endDate); let html = ''; let cur = new Date(start.getFullYear(), start.getMonth(), 1); while (cur <= end) { // 해당 월의 날짜 수 (2월은 28/29, 긴 달은 30/31) const daysInMonth = new Date( cur.getFullYear(), cur.getMonth() + 1, 0 ).getDate(); const monthWidth = daysInMonth * DAY_W; // 월 너비 = 일수 × DAY_W html += `<div class="month-cell" style="width:${monthWidth}px"> ${cur.getFullYear()}년 ${cur.getMonth() + 1}월 </div>`; cur.setMonth(cur.getMonth() + 1); // 다음 달로 이동 } return html; }
💡 new Date(year, month+1, 0).getDate() — month+1의 0번째 날 = 현재 달의 마지막 날. 이 트릭으로 월별 일수를 쉽게 계산합니다.

핵심 기술 ③④ — 마일스톤 & 스크롤 동기화

CSS rotate 트릭과 scroll 이벤트 동기화
// ── 마일스톤 판별 ──────────────────────── function renderTask(task, baseDate) { const isMilestone = task.start === task.end; // 시작=종료 = 마일스톤 const style = calcBarStyle(task, baseDate); if (isMilestone) { // 정사각형을 45도 회전 → 다이아몬드 모양 return `<div class="milestone" style="left:${style.left};transform:rotate(45deg)"></div>`; } return `<div class="gantt-bar" style="left:${style.left};width:${style.width}"> ${task.title} </div>`; } // ── 스크롤 동기화 ──────────────────────── const taskArea = document.getElementById('taskArea'); const headerArea = document.getElementById('headerArea'); // 태스크 영역 스크롤 → 헤더 동기화 taskArea.addEventListener('scroll', () => { headerArea.scrollLeft = taskArea.scrollLeft; });
💡 스크롤 동기화는 단 3줄. 두 div가 overflow:hidden인 상태에서 한 쪽의 scrollLeft를 다른 쪽에 즉시 복사. overflow:hidden으로 스크롤바는 숨기되 scrollLeft 조작은 가능.

간트차트 전체 구조

고정 좌측 + 스크롤 우측 레이아웃 패턴
1

고정 좌측 패널 (태스크 이름)

태스크 이름, 담당자, 진행률이 들어가는 좌측 패널은 position: sticky; left: 0으로 고정. 가로 스크롤해도 항상 보임.

2

스크롤 가능한 우측 영역

월 헤더 영역 + 태스크 막대 영역이 각각 overflow-x: auto로 가로 스크롤 가능. 두 영역의 scrollLeft를 동기화.

3

오늘 날짜 선 표시

오늘 날짜의 dateToDay(base, today) × DAY_W 픽셀 위치에 빨간 세로선 표시. position:absolute로 위치 지정.

4

태스크 추가/편집 모달

태스크 바 클릭 → 편집 모달 열기. 날짜 input과 색상 선택을 통해 막대 위치와 색상을 실시간 수정.

진행률 자동 계산 & 색상

오늘 날짜 기준으로 예정 진행률 자동 계산
// 예정 진행률 = 오늘까지 경과일 / 전체 기간 function calcScheduledProgress(task) { const today = new Date(); const start = new Date(task.start); const end = new Date(task.end); const total = (end - start) / (1000*60*60*24); const elapsed = (today - start) / (1000*60*60*24); return Math.min(100, Math.max(0, Math.round(elapsed / total * 100))); } // 실제 진행률 vs 예정 진행률 비교 function getBarColor(task) { const scheduled = calcScheduledProgress(task); const actual = task.progress; if (actual >= scheduled) return '#10b981'; // 일정 준수 if (actual >= scheduled-20) return '#f59e0b'; // 약간 지연 return '#ef4444'; // 심각한 지연 }
💡 실제 진행률 vs 예정 진행률 비교로 일정 지연을 색상으로 즉시 파악. 예정보다 뒤처지면 빨간색, 정상이면 초록색으로 자동 변환.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 핵심 상수값 직접 명시

"DAY_W=24"처럼 알고리즘의 핵심 매개변수를 숫자값과 함께 지정하면, AI가 임의의 스케일이 아닌 의도된 픽셀 계산 로직을 정확히 구현합니다.

POINT 2 — 데이터 URL과 컬럼명 명시

fetch() URL과 CSV 컬럼명(그룹, 작업명, 시작일, 종료일, 진척률…)을 함께 제시하면, AI가 데이터 구조를 오해 없이 파악하고 올바른 파싱 코드를 생성합니다.

POINT 3 — UI 영역을 계층별로 열거

"헤더 / 툴바 / KPI바 / 간트 차트"로 영역을 나눈 뒤 각 컴포넌트 이름을 나열하면, 누락 없이 전체 UI가 구현되고 AI가 레이아웃 의도를 파악합니다.

POINT 4 — 파일 분리 아키텍처 명시

"index.html, style.css, script.js 3개로 나눠서"처럼 출력 구조를 미리 지정하면, 역할이 분리된 유지보수 가능한 코드가 처음부터 생성됩니다.

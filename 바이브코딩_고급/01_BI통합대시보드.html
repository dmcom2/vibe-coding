📌 Mixed Chart

한 canvas에 막대·선 등 서로 다른 차트 유형을 동시에 그리는 Chart.js 기능

📌 카운터 애니메이션

setInterval로 숫자를 0에서 목표값까지 빠르게 증가시켜 보여주는 시각 효과

📌 상태 변수

📌 chart.destroy()

핵심 기술 ① — Chart.js 복합 차트

같은 canvas에 bar + line을 동시에 그리는 mixed chart 패턴
new Chart(ctx, { type: 'bar', // 기본 타입 (bar) data: { datasets: [ { type: 'bar', // 매출 — 막대 label: '매출', data: monthlyRevenue, backgroundColor: 'rgba(99,102,241,.7)' }, { type: 'line', // 이익률 — 꺾은선 (다른 Y축) label: '이익률(%)', data: profitRates, yAxisID: 'y2', // ★ 오른쪽 Y축 연결 tension: 0.4 } ] }, options: { scales: { y: { position: 'left' }, // 매출 축 y2: { position: 'right' } // 이익률 축 } } });
💡 datasets 배열에서 각 항목이 type을 개별 선언하면 서로 다른 차트 유형이 한 canvas에 공존합니다. yAxisID로 서로 다른 단위(원 vs %)를 각각 다른 축에 연결.

핵심 기술 ② — 카운터 애니메이션

숫자가 0에서 목표값까지 빠르게 증가하는 시각 효과
function animateCounter(el, target, duration = 1200) { let current = 0; const step = target / (duration / 16); // 16ms ≈ 60fps const timer = setInterval(() => { current += step; if (current >= target) { current = target; clearInterval(timer); } el.textContent = Math.round(current).toLocaleString(); }, 16); } // 사용 예시 — KPI 카드 렌더링 후 애니메이션 시작 document.querySelectorAll('.kpi-value').forEach(el => { animateCounter(el, parseInt(el.dataset.target)); });
💡 16ms 간격 = 초당 60회 갱신으로 부드러운 숫자 증가 효과. toLocaleString()으로 1,234 형식의 천 단위 콤마 자동 적용.

핵심 기술 ③ — 테이블 다중 정렬

칼럼 클릭 → 상태 변수로 방향 토글 → 재렌더링
1

상태 변수 선언

let sortKey = 'revenue' (정렬 기준 칼럼), let sortAsc = false (내림차순 기본). 이 두 변수가 현재 정렬 상태를 담습니다.

2

헤더 클릭 핸들러

같은 칼럼 재클릭 → sortAsc = !sortAsc (방향 토글). 다른 칼럼 클릭 → sortKey = newKey; sortAsc = false (내림차순 초기화).

3

정렬 로직

[...data].sort((a,b) => sortAsc ? a[sortKey]-b[sortKey] : b[sortKey]-a[sortKey]) — 원본 배열을 spread로 복사 후 정렬하여 원본 보존.

4

헤더 아이콘 표시

활성 칼럼에만 ▲ / ▼ 아이콘 추가. th.classList.toggle('sort-asc', sortAsc) CSS 클래스로 색상 강조.

핵심 기술 ④ — 다크 테마 & CSV 내보내기

CSS 변수로 테마 전환, BOM 문자로 한글 CSV 깨짐 방지
/* CSS 변수로 다크/라이트 테마 분리 */ :root { --bg: #f8fafc; --card: #ffffff; --text: #1e293b; } [data-theme="dark"] { --bg: #0f172a; --card: #1e293b; --text: #e2e8f0; } // 테마 토글 function toggleTheme() { document.documentElement.dataset.theme = document.documentElement.dataset.theme === 'dark' ? '' : 'dark'; } // CSV 내보내기 — BOM('﻿') 추가로 한글 깨짐 방지 function exportCSV() { const rows = data.map(d => [d.name, d.revenue, d.cost].join(',')); const blob = new Blob(['﻿' + rows.join('\n')], { type: 'text/csv;charset=utf-8;' }); // a 태그 클릭으로 파일 다운로드 트리거 }
💡 ﻿ (BOM) = Byte Order Mark. Excel이 UTF-8 한글을 올바르게 읽도록 파일 맨 앞에 삽입하는 3바이트 마커.

KPI 카드 구현 패턴

상단 액센트 바 + 카운터 애니메이션 조합
/* CSS — 카드 상단 컬러 바 */ .kpi { position: relative; } .kpi::before { content: ''; position: absolute; top: 0; left: 0; right: 0; height: 3px; background: var(--accent); /* 카드별 색상 */ border-radius: 3px 3px 0 0; }

KPI 데이터 구조

각 KPI 카드는 label, value, unit, change(전월 대비 %), accent(색상) 5개 속성으로 정의합니다.

렌더링 후 애니메이션

HTML 삽입 후 querySelectorAll('.kpi-value')로 모든 KPI 요소를 선택해 animateCounter() 일괄 실행.

변화율 표시: change > 0이면 녹색 ▲ +X%, change < 0이면 빨간색 ▼ -X%로 조건부 CSS 클래스 부여

차트 갱신 패턴

메모리 누수 없이 차트를 안전하게 재생성하는 방법
// 전역 차트 인스턴스 보관 let mainChart = null; function renderChart(period) { // 기존 차트가 있으면 반드시 먼저 파괴 if (mainChart) mainChart.destroy(); // 기간별 데이터 선택 const dataset = period === 'monthly' ? monthlyData : quarterlyData; mainChart = new Chart(document.getElementById('mainChart'), { type: 'bar', data: { datasets: [ ... ] }, options: { responsive: true, maintainAspectRatio: false } }); } // 탭 클릭 시 차트 교체 document.querySelectorAll('.period-tab').forEach(btn => btn.addEventListener('click', () => renderChart(btn.dataset.period)) );
💡 chart.destroy() 없이 새 Chart()를 만들면 이전 인스턴스가 DOM에 남아 이벤트 리스너가 중복 동작합니다. 항상 destroy → new 순서를 지키세요.

핵심 기술 ① — 카테고리 메타데이터

색상·아이콘을 한 곳에서 관리하는 패턴
// 카테고리별 아이콘·색상·배경을 하나의 객체로 관리 const CATEGORIES = { '업무자동화': { icon: '⚙️', color: '#3b82f6', bg: '#eff6ff' }, '문서작성': { icon: '📝', color: '#6366f1', bg: '#eef2ff' }, '데이터분석': { icon: '📊', color: '#10b981', bg: '#f0fdf4' }, '코드생성': { icon: '💻', color: '#f59e0b', bg: '#fffbeb' }, '마케팅': { icon: '📣', color: '#ec4899', bg: '#fdf2f8' }, }; // 사용: 어느 컴포넌트에서든 일관된 스타일 참조 function getCatStyle(catName) { return CATEGORIES[catName] || { icon: '📌', color: '#64748b', bg: '#f1f5f9' }; } // 카드 렌더링에서 사용 const style = getCatStyle(prompt.category); // → <span style="background:${style.bg};color:${style.color}">${style.icon} ${prompt.category}</span>
💡 색상값을 컴포넌트마다 직접 쓰면 나중에 변경이 어렵습니다. CATEGORIES 객체 한 곳만 수정하면 앱 전체 색상이 일괄 변경됩니다.

핵심 기술 ② — Clipboard API & Toast

한 번의 클릭으로 복사 + 시각적 피드백 제공
// Clipboard API: async/await 비동기 복사 async function copyPrompt(promptId) { const prompt = prompts.find(p => p.id === promptId); try { await navigator.clipboard.writeText(prompt.content); prompt.uses++; // 사용 횟수 증가 save(); showToast('클립보드에 복사되었습니다! 📋'); } catch (e) { showToast('복사 실패: 브라우저 권한을 확인하세요'); } } /* CSS Toast: 기본 숨김 → show 클래스로 나타남 */ /* .toast { transform:translateY(80px); opacity:0; transition:.3s } */ /* .toast.show { transform:translateY(0); opacity:1 } */ function showToast(msg) { const toast = document.getElementById('toast'); toast.textContent = msg; toast.classList.add('show'); setTimeout(() => toast.classList.remove('show'), 2000); }
💡 navigator.clipboard는 HTTPS 또는 localhost에서만 동작합니다. try/catch로 오류 처리 필수. Toast는 setTimeout 2초 후 자동 숨김.

핵심 기술 ③ — 태그 입력 & 다중 필터

// 태그 추가: Enter 키 이벤트 const tagList = []; tagInput.addEventListener('keydown', e => { if (e.key === 'Enter' && tagInput.value.trim()) { e.preventDefault(); const tag = tagInput.value.trim(); if (!tagList.includes(tag)) { // 중복 방지 tagList.push(tag); renderTags(); } tagInput.value = ''; } }); // 다중 필터 조합 (AND 조건) function getFilteredPrompts() { const q = searchInput.value.toLowerCase(); const cat = activeCat; let result = prompts.filter(p => { const matchSearch = !q || p.title.toLowerCase().includes(q) || p.content.toLowerCase().includes(q) || p.tags.some(t => t.includes(q)); const matchCat = !cat || p.category === cat; const matchFav = sort !== 'favorites' || p.favorite; return matchSearch && matchCat && matchFav; // 세 조건 AND }); if (sort === 'popular') result.sort((a, b) => b.uses - a.uses); return result; }

카드 UI 구성 & 즐겨찾기

프롬프트 카드의 5가지 핵심 요소
1

카테고리 배지

CATEGORIES 메타데이터에서 색상·아이콘 가져와 인라인 스타일로 적용. 카드마다 다른 색상이 자동 부여됩니다.

2

프롬프트 미리보기

content.slice(0, 120) + '...'으로 3줄 이내로 잘라 표시. "더 보기" 클릭 시 전체 내용 펼치기.

3

복사 버튼

클릭 → copyPrompt(id) → Clipboard 복사 → uses++ → Toast. 3가지 동작이 한 번의 클릭으로.

4

즐겨찾기 토글

prompt.favorite = !prompt.favorite 후 save(). 별 아이콘 색상으로 즐겨찾기 상태를 시각화.

5

사용 횟수

복사할 때마다 자동 증가하는 uses 카운터. "인기순" 정렬의 기준이 됩니다.

사이드바 카테고리 필터

카테고리별 프롬프트 수를 실시간으로 표시
// 카테고리별 건수 집계 function renderSidebar() { const counts = {}; prompts.forEach(p => { counts[p.category] = (counts[p.category] || 0) + 1; }); sidebarEl.innerHTML = Object.keys(CATEGORIES) .map(cat => { const s = getCatStyle(cat); return `<div class="cat-item" onclick="filterCat('${cat}')"> <span>${s.icon} ${cat}</span> <span class="cnt">${counts[cat]||0}</span> </div>`; }).join(''); }

카테고리 클릭 동작

activeCat = cat 설정 후 getFilteredPrompts() 재호출. "전체" 버튼은 activeCat = ''으로 초기화.

정렬 버튼

최신순(b.id - a.id) / 인기순(b.uses - a.uses) / 즐겨찾기 3가지. currentSort 변수로 상태 관리.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 결과 역산 스키마 설계

"인기순 정렬·즐겨찾기" 기능이 동작하려면 uses·favorite 필드가 스키마에 먼저 있어야 합니다. 원하는 기능을 먼저 결정하고, 그에 필요한 데이터 필드를 역으로 설계한 것이 핵심 기법입니다.

POINT 2 — 복합 동작을 한 문장에 묶음

"복사 버튼 클릭 시 clipboard.writeText() + 사용횟수+1 + Toast 2초"처럼 하나의 사용자 동작에 딸린 부작용 3가지를 한 문장으로 기술하면 AI가 3가지 모두 빠뜨리지 않고 구현합니다.

POINT 3 — 단축키를 UI 기능 옆에 병기

"통합 검색 입력 (단축키 Ctrl+K)"처럼 UI 기능 이름 옆에 키보드 단축키를 같이 적으면 AI가 JavaScript keydown 이벤트 리스너까지 함께 생성합니다.

POINT 4 — 산출물 규격을 마지막에 명시

"index.html·style.css·script.js 3개로 나눠서, 코드에 한국어 주석 달아줘"처럼 파일 분리 방식과 주석 언어를 끝에 지정하면 협업에 적합한 형태의 코드가 나옵니다.

AI 프롬프트 & 실습 미션

효과적인 생성 지시와 확장 과제
1

데이터 구조 명시

"prompts: [{id, title, category, tags[], content, uses, favorite}]" — uses와 favorite 필드를 명시해야 인기순 정렬·즐겨찾기가 생성됩니다.

2

Clipboard & Toast 요청

"복사 버튼 클릭 시 navigator.clipboard.writeText(), 사용횟수 +1, 하단 Toast 2초 표시" — 세 동작을 함께 명시.

3

미션 1: 변수 치환

프롬프트에 {{이름}} 변수 삽입, 복사 클릭 시 팝업으로 값 입력 후 치환된 텍스트 복사.

미션 2: 사용 통계 히트맵 모달

카테고리별 사용 횟수(uses 합산)를 시각화하는 '통계' 버튼과 모달 구현. SVG 막대 차트로 카테고리별 인기도를 렌더링하고, 각 카드의 마지막 사용 시각을 usedAt 필드로 localStorage에 기록해 모달에 표시.

  • 카테고리별 uses 합산 계산 함수 작성
  • SVG viewBox로 막대 차트 동적 렌더링
  • 복사 시 usedAt(ISO 타임스탬프) 갱신 및 모달 표시

전문 검색

markdownToHtml()

핵심 기술 ① — 전문 검색 & 결합 필터

제목·본문·태그를 동시에 검색하는 통합 필터
// 전문 검색 + Set 태그 AND 필터 조합 let activeTags = new Set(); // 선택된 태그들 function getFilteredArticles() { const q = searchInput.value.toLowerCase(); return articles.filter(a => { // 1. 검색어 필터: 제목/본문/태그 중 하나라도 포함 const matchSearch = !q || a.title.toLowerCase().includes(q) || a.body.toLowerCase().includes(q) || a.tags.some(t => t.toLowerCase().includes(q)); // 2. 태그 AND 필터: activeTags의 모든 태그를 문서가 가져야 함 const matchTags = activeTags.size === 0 || [...activeTags].every(tag => a.tags.includes(tag)); return matchSearch && matchTags; }); } // 태그 클릭 토글 function toggleTag(tag) { activeTags.has(tag) ? activeTags.delete(tag) : activeTags.add(tag); render(); }
💡 OR 필터는 some(), AND 필터는 every(). Set은 중복 없이 항목을 관리하는 자료구조로 태그 선택 상태 관리에 딱 맞습니다.

핵심 기술 ② — markdownToHtml()

정규식 체인으로 마크다운을 HTML로 변환
// 간단한 마크다운 → HTML 변환 함수 (정규식 체인) function markdownToHtml(md) { return md // 제목: ## 텍스트 → <h2> .replace(/^## (.+)$/gm, '<h2>$1</h2>') .replace(/^# (.+)$/gm, '<h1>$1</h1>') // 강조: **텍스트** → <strong> .replace(/\*\*(.+?)\*\*/g, '<strong>$1</strong>') // 이탤릭: *텍스트* → <em> .replace(/\*(.+?)\*/g, '<em>$1</em>') // 인라인 코드: `코드` → <code> .replace(/`(.+?)`/g, '<code>$1</code>') // 목록: - 항목 → <li> .replace(/^- (.+)$/gm, '<li>$1</li>') // 빈 줄 → <br> .replace(/\n\n/g, '<br><br>'); } // 렌더링: innerHTML로 HTML 삽입 function showArticle(id) { const a = articles.find(x => x.id === id); a.views++; // 조회수 증가 save(); articleBody.innerHTML = markdownToHtml(a.body); showingArticle = id; }

문서 목록 & 상세 뷰

SPA 방식으로 목록↔상세 전환
1

목록 렌더링

getFilteredArticles() 결과를 map해서 카드 그리드 표시. 카드에는 제목, 카테고리, 태그, 조회수, 수정일 포함.

2

상세 뷰 전환

카드 클릭 → showingArticle = id → listView 숨기기, detailView 보이기. 뒤로가기 버튼으로 showingArticle = null.

3

조회수 카운터

showArticle() 호출 시 a.views++ 후 save(). 인기 문서 정렬은 sort((a,b) => b.views - a.views).

4

태그 클라우드

모든 문서의 태그를 flat + new Set()으로 중복 제거. 태그별 문서 수 표시, 클릭 시 toggleTag().

5

편집 모드

상세 뷰에서 편집 버튼 → textarea로 마크다운 편집 → 미리보기 토글 → 저장. showingArticle 상태 변수 활용.

카테고리 사이드바 & 통계

카테고리 사이드바

reduce로 카테고리별 문서 수 집계. 클릭 시 해당 카테고리만 필터. 전체 선택 시 activeCat = '' 초기화.

인기 문서 TOP5

articles.sort((a,b) => b.views - a.views).slice(0,5)로 상위 5개 추출해서 사이드바 하단에 표시.

// 태그 클라우드 생성 function getAllTags() { const all = articles.flatMap(a => a.tags); const unique = [...new Set(all)]; // 태그별 문서 수 const counts = {}; all.forEach(t => counts[t] = (counts[t] || 0) + 1); return unique.map(t => ({ tag: t, count: counts[t] })).sort((a,b) => b.count - a.count); }

핵심 기술 ① — SVG 원형 타이머

stroke-dashoffset으로 원의 "채워진 비율" 조절
반지름 r = 54px
둘레 = 2 × π × 54 ≈ 339
stroke-dasharray="339" (전체 선 길이)
stroke-dashoffset = 339 × (1 - 비율)
transform="rotate(-90)" → 12시 방향 시작
// 타이머 틱마다 호출 — SVG 업데이트 function updateTimerSVG(remaining, total) { const ratio = remaining / total; const offset = 339 * (1 - ratio); // 0=완전히 채워짐, 339=빈 상태 document.getElementById('timerCircle').setAttribute( 'stroke-dashoffset', offset ); document.getElementById('timerText').textContent = formatTime(remaining); // MM:SS 형식 }
💡 circumference = 2πr. r=54이면 약 339. dashoffset이 0이면 원이 완전히 그려지고, 339이면 아무것도 없습니다. 타이머는 339 → 0 방향으로 감소.

핵심 기술 ② — setInterval 관리

중복 타이머 방지 · 정지 · 재개 패턴
let timerInterval = null; // null = 타이머 중지 상태 let remaining = 0; function startTimer() { // ★ 핵심: 이미 실행 중이면 중복 생성 방지 if (timerInterval) return; timerInterval = setInterval(() => { remaining--; updateTimerSVG(remaining, totalSeconds); if (remaining <= 0) { stopTimer(); onTimerEnd(); // 다음 안건으로 이동 } }, 1000); } function stopTimer() { clearInterval(timerInterval); timerInterval = null; // 반드시 null 초기화 } function resetTimer(seconds) { stopTimer(); remaining = seconds; updateTimerSVG(remaining, seconds); }
💡 if (timerInterval) return; 한 줄이 핵심. 버튼을 빠르게 여러 번 클릭해도 setInterval이 중복 생성되지 않습니다. stopTimer에서 null 초기화가 필수.

핵심 기술 ③ — 3-View SPA 패턴

페이지 전환 없이 하나의 HTML에서 3개 화면 구성
// HTML 구조: 3개 뷰를 같은 레벨에 배치 // <div id="setupView">...</div> // <div id="meetingView" style="display:none">...</div> // <div id="summaryView" style="display:none">...</div> const VIEWS = ['setupView', 'meetingView', 'summaryView']; function showView(targetId) { // 모든 뷰를 먼저 숨김 VIEWS.forEach(id => { document.getElementById(id).style.display = 'none'; }); // 목표 뷰만 표시 document.getElementById(targetId).style.display = 'block'; } // 사용 예시 function startMeeting() { if (!agendas.length) { alert('안건을 추가하세요'); return; } currentAgendaIdx = 0; showView('meetingView'); loadAgenda(0); }
💡 뷰 전환은 단순히 display 속성 토글. 복잡한 라우터 없이 3줄 forEach로 구현. 각 뷰 진입 시 해당 데이터 렌더링 함수를 함께 호출.

핵심 기술 ④ — 보고서 자동 생성

템플릿 리터럴 + spread 연산자로 구조화된 텍스트 조립
1

회의 기본 정보

제목, 날짜, 참석자 배열을 템플릿 리터럴에 주입. attendees.join(', ')로 배열을 문자열로 변환.

2

안건 목록 생성

...agendas.map(a => ` • ${a.title} (${a.time}분)`) — spread 연산자로 map 배열을 템플릿 안에 줄바꿈 삽입.

3

액션 아이템 정리

담당자·마감일·내용을 포함한 액션 아이템을 번호 목록 형식으로 자동 생성. 완료 여부도 체크박스 표시.

4

클립보드 복사

navigator.clipboard.writeText(reportText)로 생성된 보고서를 클립보드에 복사. 이메일·메신저에 바로 붙여넣기 가능.

안건-타이머 연동 구조

안건 배열과 타이머가 상호작용하는 흐름

안건 데이터 구조

agendas: [{id, title, time(분), notes, done}] 배열. currentAgendaIdx로 현재 안건 추적.

안건 전환 로직

타이머 종료 시 currentAgendaIdx++. 마지막 안건이면 showView('summaryView')로 자동 이동.

진행 바 표시

상단 안건 목록에서 현재 안건을 파란색 강조. index < currentIdx면 완료(초록), index > currentIdx면 대기(회색).

노트 실시간 저장

각 안건의 메모 textarea에 oninput 이벤트 연결. 타이핑 즉시 agendas[idx].notes = value 갱신.

POINT 1 — 화면 흐름을 순서도처럼 명시

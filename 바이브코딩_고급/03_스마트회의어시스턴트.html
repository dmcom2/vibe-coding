시작 전 준비물 체크

01 · 02 실습과 같은 도구 — Node.js로 서버를 직접 띄웁니다

🟩 Node.js LTS

터미널에서 node -v가 v18 이상이면 됩니다. SQLite(better-sqlite3) · 파일 업로드(multer) 모듈은 npm install 때 함께 설치됩니다.

🤖 Antigravity 확장

파일 6개(index.html · style.css · data.js · script.js · server.js · package.json)가 생성됩니다. 승인(Approve)을 빠짐없이 눌러 주세요.

💻 Chrome · Edge + 마이크

받아쓰기(음성 인식)와 녹음은 Chrome · Edge에서 됩니다. npm start 후 http://localhost:3005로 열고 마이크 권한을 허용하세요.

📂 샘플 파일 2개

샘플데이터_회의준비.txt(9/22 Q4 전략 기획 회의 안건 5개)와 샘플데이터_지난회의록.txt(8/27 회의록 · 할 일 6개). "가져오기"로 넣어 봅니다.

💡 AI 다듬기와 화자 분리는 선택입니다. 쓰려면 .env.example을 .env로 복사해 키를 넣으세요. .env는 절대 git에 올리지 않습니다.

오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀 두면 수업이 술술 풀립니다

📌 타임박스

안건마다 미리 정한 시간 상자. 넘치면 멈추고 "계속할지 · 다음으로 넘길지"를 정합니다. 회의가 늘어지는 것을 막는 가장 단순한 방법입니다.

📌 태그 메모

메모 맨 앞의 /결정 · /할일 · /질문 · /이슈. 사람이 읽는 메모이면서 동시에 컴퓨터가 분류할 수 있는 데이터가 됩니다.

📌 액션 아이템 (할 일)

회의에서 나온 누가 · 무엇을 · 언제까지. 셋 중 하나라도 빠지면 대개 아무도 하지 않습니다.

📌 회의 비용

참석 인원 × 회의 시간 × 1인 시간당 인건비. 5명이 1시간 반 회의하면 시간당 5만원 기준 37.5만원입니다.

📌 유효 발언자 수

1 ÷ (발언 비중² 의 합). 5명이 똑같이 말하면 5명, 한 사람만 말하면 1명. 숫자가 참석자 수에 가까울수록 고르게 말한 회의입니다.

📌 SSE (실시간 공유)

Server-Sent Events. 서버가 브라우저로 한 방향으로 계속 소식을 밀어 주는 연결. 참관자는 새로고침 없이 진행 화면을 봅니다.

핵심 기술 ① — 회의 · 할 일 · 녹음을 SQLite에

회의 본문은 JSON 한 칸에, 따로 고치고 거를 할 일은 별도 테이블에 — 회의를 지우면 할 일도 함께
db.pragma('foreign_keys = ON'); CREATE TABLE meetings (id INTEGER PRIMARY KEY, title, date, time, place, data -- 참석자 · 안건 · 메모 · 발언 시간 · 회의록 (JSON)); CREATE TABLE action_items (id INTEGER PRIMARY KEY, meeting_id REFERENCES meetings(id) ON DELETE CASCADE, text, owner, due, done); CREATE TABLE recordings (id INTEGER PRIMARY KEY, meeting_id REFERENCES meetings(id) ON DELETE SET NULL, filename, label, duration_ms, size, transcript);
// 할 일 하나만 고칠 때: 회의 JSON은 건드리지 않는다 app.put('/api/actions/:id', (req, res) => { db.prepare(`UPDATE action_items SET done=?, owner=?, due=? WHERE id=?`).run(…); }); // 녹음: multer로 data/recordings/에 저장, // 재생은 Range 요청(206)으로 — 긴 녹음도 원하는 곳부터 app.get('/api/recordings/:id/file', …);
🗄️ 완성 예제 기준 서버를 처음 켜면 지난 회의 7번(8/6 ~ 9/17)과 할 일 21개(완료 13)가 들어갑니다. 기준일 9/22에 열린 할 일은 8개, 그중 기한 초과는 2개(결제 모듈 테스트 9/18 · 온보딩 플로우 단순화 9/20)입니다.

핵심 기술 ② — 안건 타이머와 시간 재배분

1초마다 경과를 쌓고, 늦어지면 "남은 안건을 몇 분으로 줄여야 제시간에 끝나는지" 계산한다
// 1초마다: 전체 · 현재 안건 · 지금 발언자 시간을 1씩 function tick() { L.elapsed++; L.agendas[L.idx].actual++; L.talk[L.speaker]++; if (현재 안건 경과 === 계획 × 60) beep(); // 한 번만 } // 새로고침해도 이어지도록 5초마다 localStorage에 저장
function rebalance(agendas, idx, curSec, elapsed) { const available = 계획 합 × 60 - elapsed; const need = 현재 안건 남은 초 + 남은 안건 계획 합; if (need <= available) return { ok: true }; // 남은 안건을 같은 비율로 줄이고 내림, 최소 3분 plan = 남은.map(g => max(3, floor(g.planned × 여유 ÷ 남은 계획 합))); }
⏱️ 완성 예제 기준 Q4 전략 기획 회의(계획 90분)에서 1번 안건이 22분, 2번 안건이 31분까지 가면 8분 늦어지고 있다고 알리고, 남은 안건을 20 · 15 · 10분 → 16 · 12 · 8분으로 줄이자고 제안합니다. "재배분 적용"을 누르면 계획이 바뀝니다.

핵심 기술 ③ — 태그 메모와 자동 회의록

메모 한 줄을 정규식으로 태그 · 담당 · 기한으로 나누고, 회의를 끝내면 마크다운 회의록으로 모은다

핵심 기술 ④ — 회의 통계: 비용 · 초과 · 발언 균형

회의 하나마다 같은 stats()를 돌려 홈 · 회의록 · 분석 화면이 모두 같은 숫자를 쓴다
function stats(m, hourly) { const actual = round(m.duration / 60); // 분 const cost = round(인원 × actual / 60 × hourly); const over = actual - 계획 합; // 발언 비중 = 내 발언 초 ÷ 전체 발언 초 const eff = 1 / sum(share × share); // 유효 발언자 return { actual, cost, over, eff, top, … }; }
// 예) 발언 비중 26 · 24 · 18 · 17 · 15 % 1 / (.26² + .24² + .18² + .17² + .15²) = 1 / 0.209 ≈ 4.78명 // 5명 중 4.8명분 // 예) 46 · 18 · 14 · 12 · 10 % (한 사람이 거의 절반) ≈ 3.47명 // 할 일 상태: 완료 / 기한 < 기준일이면 기한 초과 / 진행
📊 완성 예제 기준 지난 회의 7번은 총 487분(계획 385분, +102분) · 비용 202.9만원입니다. 앞 4번은 평균 +23.8분 넘쳤지만 최근 3번은 +2.3분, 유효 발언자는 3.5 → 4.7명, 팀장 발언 비중은 46% → 28%로 좋아졌습니다.

■ 0. 만들 것 - 'MeetFlow — 스마트 회의 어시스턴트'를 파일 6개로 만들어줘. · 화면: index.html · style.css · script.js · 공용: data.js — 샘플 회의 · 메모 태그 해석(parseNote) · 시간 재배분(rebalance) · 회의 통계(stats) · 회의록 작성(minutesMD) · 준비 문서/회의록 가져오기(parsePrep · parseMinutesText) (브라우저 전역 MFDATA, Node에서는 require로 같은 파일) · 서버: server.js(Node.js + Express + better-sqlite3 + multer + dotenv, 포트 3005), package.json("start": "node server.js") - 화자 분리용 diarize.py · requirements.txt는 실습 폴더에 있는 것을 그대로 쓰고, 서버는 그 파일을 실행만 해줘. - index.html은 data.js → script.js 순서로 불러와줘. - npm start 후 http://localhost:3005이면 서버 모드(SQLite · 녹음 · AI · 실시간 공유), index.html을 바로 열면 로컬 데모 모드(localStorage)로 나머지는 같은 결과 - 현재 안건 남은 초 = max(0, 계획 × 60 − 현재 안건 경과), 필요 = 현재 안건 남은 초 + 뒤 안건 계획 합 × 60 - 뒤 안건이 없거나 필요 ≤ 쓸 수 있는 시간이면 제안 없음 - 아니면 늦어진 분 = 반올림((필요 − 쓸 수 있는 시간) ÷ 60), 여유 = max(0, 쓸 수 있는 시간 − 현재 안건 남은 초), 새 계획 = max(3, 내림(계획 × 여유 ÷ 60 ÷ 뒤 안건 계획 합)) — 합 × 60 ≤ 여유면 "제시간에 끝납니다", 아니면 "최대한 맞출 수 있습니다" - 안건 경과가 계획과 같아지는 순간 삐 소리 두 번 + 알림(안건마다 한 번) 회의 통계 - 계획 = 안건 계획 분 합, 실제 = 반올림(회의 길이 초 ÷ 60), 초과 = 실제 − 계획 - 비용 = 반올림(참석 인원 × 실제 ÷ 60 × 시간당 인건비), 표시는 1만원 이상이면 '39.2만원'처럼 소수 한 자리 - 발언 비중 = 사람별 발언 초 ÷ 전체 발언 초, 유효 발언자 = 1 ÷ Σ 비중² - 프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 업무 도구를 시키는 법"을 배웁니다

POINT 1 — 업무 흐름대로 화면을 나눈다

"회의 도구 만들어줘" 대신 준비 → 진행 → 회의록 → 할 일 → 분석을 화면 이름으로 줬습니다. AI가 기능을 빠뜨리거나 엉뚱한 곳에 넣지 않습니다.

POINT 2 — 입력 형식을 약속한다

"/할일 @담당 9/30"처럼 메모 문법과 가져올 문서의 모양을 적었습니다. 형식이 정해져야 AI 없이도 정확히 분류됩니다.

POINT 3 — "적당히"를 공식으로

"늦으면 시간을 조정해줘"가 아니라 쓸 수 있는 시간 · 비율 · 최소 3분 · 내림까지 적었습니다. 모두 같은 재배분 숫자를 얻습니다.

POINT 4 — 비밀은 서버에만

AI 키는 .env와 서버에서만 쓰고, .env.example은 빈 값으로 두게 했습니다. 키가 코드나 git에 섞여 들어가는 사고를 막습니다.

서버 실행 방법

터미널 두 줄이면 SQLite 서버가 켜집니다 — 안 되면 index.html만 열어도 로컬 데모 모드
1

설치 · 실행

실습 폴더에서 npm install → npm start. "샘플 회의 7건을 넣었습니다"와 주소가 보이면 성공입니다.

2

http://localhost:3005 · 준비

배지가 초록 '서버 · SQLite'인지 확인하고, 가져오기로 샘플데이터_회의준비.txt를 넣어 준비 화면이 채워지는지 봅니다.

3

회의 진행

회의 시작 → 발언자를 누르고 /할일 @박서연 결제 재테스트 9/30을 입력해 보세요. 이어서 데모로 채우기를 누릅니다.

4

종료 · 회의록 · 할 일

회의 종료를 누르면 회의록 화면으로 갑니다. 할 일 화면에서 기한 초과를 완료로 바꿔 보세요. 끝낼 때는 터미널에서 Ctrl+C.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요
🎙️ "받아쓰기 · 녹음 버튼이 회색이에요"

음성 인식은 Chrome · Edge에서만 됩니다. 녹음은 서버 모드(http://localhost:3005)에서만 켜집니다. 파일을 더블클릭해 연 경우라면 서버 주소로 다시 여세요.

🔇 "마이크 권한을 허용해 주세요"가 떠요

주소창 왼쪽 자물쇠(또는 설정) 아이콘 → 마이크 → 허용 후 새로고침하세요. 회사 PC는 보안 정책으로 막혀 있을 수 있습니다.

🚪 "3005 포트 사용 중"

다른 서버가 3005를 쓰고 있습니다. 그 터미널을 Ctrl+C로 끄거나 $env:PORT=3105; npm start(PowerShell)로 바꿔 여세요.

🧑‍🤝‍🧑 "화자 분리가 안 돼요"

선택 기능입니다. 파이썬 · pip install -r requirements.txt · .env의 HF_TOKEN · pyannote 모델 라이선스 수락이 모두 필요합니다. 없어도 나머지는 그대로 됩니다.

🤖 만능 해결법: 터미널의 빨간 글자나 F12 → Console의 오류를 그대로 복사해서 Antigravity에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요.

AI는 "마지막 손질"에만

회의록 뼈대는 규칙으로 만들고, AI에게는 문장 다듬기만 맡겼습니다. AI가 없어도 동작하고, AI가 숫자를 바꿀 위험도 줄어듭니다.

수업용 "데모 버튼"을 요청한다

핵심 기술 ① — 가중 평균 & 등급 결정

4주체 점수를 비율로 합산하는 핵심 로직
// 평가 주체별 가중치 정의 const EV_WEIGHT = { self: 0.15, boss: 0.40, peer: 0.30, report: 0.15 }; // 가중 평균 계산 function calcWeightedScore(scores) { // scores = { self: {역량1:4, 역량2:3,...}, boss: {...}, ... } const keys = Object.keys(EV_WEIGHT); let total = 0, weightSum = 0; keys.forEach(type => { const typeScores = Object.values(scores[type] || {}); if (typeScores.length === 0) return; const avg = typeScores.reduce((s, v) => s + v, 0) / typeScores.length; total += avg * EV_WEIGHT[type]; weightSum += EV_WEIGHT[type]; }); return weightSum > 0 ? total / weightSum : 0; } // 등급 자동 결정 const GRADE_MAP = [ { min: 4.5, grade: 'S', color: '#7c3aed' }, { min: 4.0, grade: 'A', color: '#2563eb' }, { min: 3.0, grade: 'B', color: '#059669' }, { min: 2.0, grade: 'C', color: '#d97706' }, { min: 0, grade: 'D', color: '#dc2626' }, ]; function getGrade(score) { return GRADE_MAP.find(g => score >= g.min); // 배열 순서 중요! }
💡 GRADE_MAP은 내림차순으로 정렬되어야 합니다. find()는 첫 번째 일치를 반환하므로 4.5 이상이면 S등급이 먼저 걸립니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 상수 이름과 값 직접 제공

EV_WEIGHT = {self:0.15, boss:0.40, peer:0.30, report:0.15}처럼 상수 이름 + 값을 함께 제공. 이름 덕분에 코드 어디서든 쉽게 찾아 수정 가능. 합계 1.0 조건도 AI가 자동 검증하도록 유도.

POINT 2 — 등급 배열 구조와 탐색 패턴 명시

GRADE_MAP = [{min:4.5,grade:'S'}...] 내림차순 배열로 정의. "find() 또는 순서대로 검사"가 암묵적으로 내포됨. 구조를 주면 AI가 알맞은 탐색 패턴을 자동 선택.

POINT 3 — 탭 이름과 기능 목록화

4개 탭(평가입력/결과분석/코멘트/최종보고서)과 각 탭의 기능을 구체적으로 열거. "탭 4개"만 말하면 AI가 탭 이름과 내용을 임의로 결정. 명확한 명칭이 구조의 불일치를 막음.

POINT 4 — CSV 컬럼명으로 데이터 매핑 확보

CSV 컬럼명(직원명, 부서, 리더십, 커뮤니케이션...)을 명시해 코드의 필드명과 CSV 헤더가 1:1 매핑되도록 고정. 컬럼명 불일치로 인한 undefined 오류를 사전 차단.

과제 진행 순서

3단계 프롬프트로 완성 — 막히면 Antigravity에게 질문하세요

1

1단계 — 기본 레이아웃

좌우 2열 구조 + 보고서 유형 탭 + 섹션 레이블
→ 좌측 입력폼과 우측 A4 패널이 나란히 보이면 성공

2

2단계 — 입력 기능 구현

보고자 정보 + 업무 목록(행 추가·삭제) + KPI 달성률 자동계산
→ 행 추가·삭제와 달성률 계산이 동작하면 성공

3

3단계 — 미리보기 & 저장

실시간 A4 미리보기 연동 + PDF 저장 + localStorage 임시저장
→ 새로 고침 후에도 입력 내용이 남아 있으면 성공

💡 막혔을 때 대처법

오류 메시지나 이상한 화면을 그대로 복사해서 Antigravity에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요.

📁 파일 위치

바탕화면 → 테스트 폴더를 VS Code로 열어주세요.

자주 막히는 문제 & 해결법

이 화면으로 돌아와서 확인하세요

❓ 우측 미리보기가 업데이트되지 않아요

input 이벤트 리스너가 빠진 것입니다. Antigravity에게 "입력할 때마다 미리보기가 실시간으로 바뀌도록 이벤트를 연결해줘"라고 요청하세요.

❓ 행 추가 버튼을 눌러도 행이 안 생겨요

개발자 도구(F12) → Console 탭의 에러를 복사해서 Antigravity에게 "이 오류 고쳐줘"라고 붙여넣으세요.

❓ KPI 달성률 계산이 NaN으로 나와요

목표값이 0이거나 비어 있을 때 나누기를 실행한 것입니다. Antigravity에게 "목표값이 0이면 달성률을 0%로 표시해줘"라고 말하세요.

❓ 새로 고침하면 입력 내용이 사라져요

localStorage 저장 코드가 빠진 것입니다. Antigravity에게 "새로 고침해도 입력 내용이 유지되도록 localStorage를 추가해줘"라고 말하세요.

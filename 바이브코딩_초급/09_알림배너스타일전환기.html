CSS 변수 (Custom Properties)

모양과 색을 변수로 정의해서 한 번에 바꾸는 방법

CSS 변수는 --변수명으로 정의하고 var(--변수명)으로 사용합니다.
JS로 변수 하나를 바꾸면 그 변수를 쓰는 모든 곳이 동시에 바뀝니다.
/* CSS - :root에 변수 선언 */ :root { --page-bg: #f1f5f9; --panel-bg: #ffffff; --radius: 12px; --font-size: 16px; } /* 변수 사용 */ body { background: var(--page-bg); } .b-title { font-size: var(--font-size); }
💡

CSS 변수의 장점

배너가 4개든 40개든, 변수 하나만 바꾸면 끝!

기존 방식: 배너마다 style.fontSize... 일일이 바꿔야

변수 방식: setProperty 한 번으로 모두 변경

⚙️

setProperty — JS로 CSS 변수 변경

document.documentElement로 :root 변수에 접근

JS // :root = document.documentElement const root = document.documentElement; // CSS 변수 값 변경 root.style.setProperty('--page-bg', '#0f172a'); root.style.setProperty('--font-size', '20px'); root.style.setProperty('--font-family', "'Batang',serif"); // 현재 변수 값 읽기 const current = getComputedStyle(root) .getPropertyValue('--page-bg'); // localStorage에 스타일 저장 localStorage.setItem('banner-style', 'dark');

스타일 객체 패턴

JS const BANNER_STYLES = { light: { '--page-bg': '#f1f5f9', '--panel-bg': '#ffffff', '--radius': '12px' }, dark: { '--page-bg': '#0f172a', '--panel-bg': '#1e293b', '--radius': '12px' } }; function applyStyle(name) { const s = BANNER_STYLES[name]; Object.entries(s).forEach(([k,v]) => root.style.setProperty(k, v) ); }
➕

배열로 알림 추가·삭제하기

알림 여러 개를 배열 하나로 관리하면 추가/삭제가 간단해집니다

// 알림 목록 = 배열 let banners = [ { id: 1, type: 'info', title: '정보', message: '...' } ]; // 추가: 맨 앞에 새 항목 삽입 function addBanner() { banners.unshift({ id: Date.now(), type, title, message }); saveBanners(); renderBanners(); } // 삭제: 해당 id만 빼고 새 배열 생성 function deleteBanner(id) { banners = banners.filter(b => b.id !== id); saveBanners(); renderBanners(); }
왜 배열인가요?

알림 4개를 각각 변수로 만들면 관리가 어렵지만, 배열 하나로 묶으면 몇 개가 되든 .map() 한 줄로 화면에 그릴 수 있습니다.
🔁

추가/삭제 → 다시 그리기

배열이 바뀔 때마다 renderBanners()가 목록 전체를 새로 그려서 화면과 데이터를 항상 일치시킵니다.

🌙

시스템 다크모드 자동 감지

사용자 OS 설정에 따라 첫 방문 시 자동으로 스타일 적용

// 시스템 다크모드 여부 확인 const prefersDark = window .matchMedia('(prefers-color-scheme: dark)') .matches; // 저장된 스타일이 없으면 시스템 설정을 따름 const saved = localStorage.getItem('banner-style') || (prefersDark ? 'dark' : 'light'); applyStyle(saved); // 시스템 테마 변경 감지 (실시간) window.matchMedia('(prefers-color-scheme: dark)') .addEventListener('change', e => { applyStyle(e.matches ? 'dark' : 'light'); });
📱

우선순위 처리

1️⃣ localStorage에 저장된 스타일이 있으면 그것 사용
2️⃣ 없으면 시스템 설정 따름
3️⃣ 시스템도 모르면 라이트 스타일 기본값

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

기술 구현 방법을 직접 명시

CSS 변수(--page-bg, --font-size 등)처럼 사용할 기술과 변수명까지 예시를 들어주면 AI가 추측 없이 바로 적용합니다.

✅ POINT 2

UI 구조를 계층으로 나열

상단 · 툴바1 · 툴바2 · 관리자패널 · 폼 · 하단처럼 화면을 영역별로 나눠 설명하면 AI가 레이아웃 전체를 빠짐없이 이해합니다.

✅ POINT 3

수치 범위와 단위를 구체적으로

"테두리 두께 2px~8px, 2px 단위"처럼 숫자로 범위와 단위를 주면 AI가 임의로 결정하지 않고 정확히 구현합니다.

✅ POINT 4

엣지케이스까지 조건 명시

"저장된 스타일이 없으면 시스템 다크모드를 따름"처럼 예외 상황 처리 조건을 미리 적어두면 완성도 높은 결과가 나옵니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"알림 배너 사이트 만들어줘"
→ 스타일 수, 저장 방법, UI 구조가 제각각
✅ 구체적인 요청
"CSS 변수로 라이트/다크/강조형 3가지 전환, localStorage로 스타일·알림 모두 기억"
→ 한 번에 원하는 결과

코드 핵심 설명

index.html 파일에서 찾아봐야 할 핵심 부분

① 알림 추가 (addBanner)

function addBanner() { const message = messageInput.value.trim(); if (!message) return; // 내용 없으면 무시 banners.unshift({ id: Date.now(), type, title, message }); saveBanners(); renderBanners(); }
• Date.now() — 겹치지 않는 고유 id로 사용
• unshift — 배열 맨 앞에 추가해 최신순 정렬

② 글자 크기 조절 (changeFontSize)

function changeFontSize(delta) { const root = document.documentElement; const current = parseInt( getComputedStyle(root) .getPropertyValue('--font-size') ); // 14px ~ 22px 범위로 제한 const next = Math.min(22, Math.max(14, current + delta)); root.style.setProperty('--font-size', next + 'px'); localStorage.setItem('banner-font-size', next); }
• Math.min / Math.max — 값이 범위를 벗어나지 않게 고정
• glyph 크기 하나만 바꾸면 모든 알림 제목·내용이 동시에 커짐

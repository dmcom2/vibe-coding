오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 변수(let)

바뀔 수 있는 값을 담는 상자. 클릭 횟수가 여기 담깁니다

📌 상수(const)

한 번 정하면 바뀌지 않는 값. 목표 횟수 같은 것에 씁니다

📌 if / else

"만약 ~라면 A, 아니면 B"로 갈라지는 조건문. 신호등 규칙과 같아요

📌 DOM

화면의 글자·버튼을 코드로 만질 수 있게 해주는 통로

📌 textContent

화면 요소의 글자 내용을 바꾸는 명령. 전광판 숫자 갈아끼우기

📌 함수

증가·감소·초기화처럼 기능을 묶어 이름 붙인 것

🌱 낯선 단어가 나와도 괜찮습니다. 이 슬라이드로 돌아와서 다시 확인하면 됩니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!
📦

변수 — let 과 const

값이 바뀌면 let, 안 바뀌면 const

변수는 데이터를 담아두는 상자입니다.
let은 나중에 내용을 바꿀 수 있는 상자, const는 한 번 채우면 바꿀 수 없는 상자입니다.
// let — 나중에 값을 바꿀 수 있음 let count = 0; count = count + 1; // → 1 (가능!) count++; // → 2 (가능!) count--; // → 1 (가능!) // const — 한 번 정하면 변경 불가 const MAX = 10; // MAX = 20; ← 오류! 변경 불가 // DOM 조작으로 화면 업데이트 const display = document .getElementById('counter'); display.textContent = count;
🤔

언제 let? 언제 const?

✅ let 사용: 카운터, 점수, 현재 페이지, 상태값 등 바뀌는 값

✅ const 사용: 최대값, 버튼, 컬러 코드 등 고정된 값

💡 기본적으로 const 먼저 쓰고, 바꿔야 할 때만 let

🔀

if / else if — 조건 분기

숫자에 따라 다른 색상과 메시지를 표시하는 조건문

JS function updateDisplay() { countEl.textContent = count; if (count === 0) { // 초기 상태 countEl.style.color = '#94a3b8'; msgEl.textContent = '시작해보세요!'; } else if (count <= 5) { // 1~5: 초록 countEl.style.color = '#059669'; msgEl.textContent = '순조롭게 진행 중'; } else if (count <= 9) { // 6~9: 주황 countEl.style.color = '#ea580c'; msgEl.textContent = '열심히 하고 있어요!'; } else { // 10+: 빨강 countEl.style.color = '#dc2626'; msgEl.textContent = '🎉 목표 달성!'; } }

조건문 흐름도

count === 0
→ 회색, "시작해보세요"
count 1~5
→ 초록색, "순조롭게"
count 6~9
→ 주황색, "열심히"
count 10 이상
→ 빨강, "목표 달성!"
🖥️

DOM 조작 — 화면 바꾸기

JavaScript로 HTML 요소의 내용과 스타일을 변경

// 요소 찾기 const el = document .getElementById('myDiv'); // 텍스트 바꾸기 el.textContent = '새로운 내용'; // HTML 바꾸기 (태그 포함) el.innerHTML = '<b>굵은 글씨</b>'; // 스타일 바꾸기 el.style.color = '#dc2626'; el.style.fontSize = '2rem'; el.style.backgroundColor = '#fee2e2'; // 클래스 추가/제거 el.classList.add('active'); el.classList.remove('hidden');
🔗

textContent vs innerHTML

textContent
→ 순수 텍스트만 설정
→ 더 안전 (XSS 방지)

innerHTML
→ HTML 태그도 해석
→ 외부 입력엔 주의 필요

AI에게 말 거는 법 — 프롬프트 3단 구조

말하듯 쓰면 됩니다. 이 순서만 기억하세요

①
무엇을 "클릭 카운터를 만들어줘"
만들 것을 한 문장으로. 첫 줄이 가장 중요합니다
②
내용 "+ 버튼, - 버튼, 리셋 버튼, 색상 변화"
들어갈 정보를 목록으로 나열합니다
③
조건 "0 미만으로 안 내려가게, 심플하고 크게, 파일 하나로"
원하는 동작과 형식을 구체적으로 적습니다
❌ 아쉬운 프롬프트
"카운터 만들어줘"
→ AI가 마음대로 만듭니다
✅ 좋은 프롬프트
"숫자에 따라 색이 바뀌고, 0 아래로는 안 내려가고, 리셋 버튼도 있게"
→ 원하는 대로 나옵니다
💡 전문용어를 몰라도 됩니다. "숫자가 커지면 색깔이 진해지게"처럼 말로 설명해도 AI가 알아듣습니다.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🔍 "Go Live 버튼이 안 보여요"

VS Code 왼쪽 확장(Extensions) 메뉴에서 Live Server를 검색해 설치한 뒤, VS Code를 껐다가 다시 켜세요.

💾 "고쳤는데 화면이 그대로예요"

저장(Ctrl+S)이 먼저입니다! 저장하지 않으면 반영되지 않아요. 저장 후 브라우저에서 새로고침(F5) 하세요.

⏸️ "Cline이 멈춰서 아무것도 안 해요"

파일을 만들거나 고치기 전에 승인(Approve)을 기다리는 중입니다. Cline 채팅창의 승인 버튼을 눌러주세요.

🔤 "한글이 깨져 보여요"

AI에게 "한글이 깨져 보여. UTF-8 인코딩으로 고쳐줘"라고 요청하세요. VS Code 오른쪽 아래 인코딩 표시가 UTF-8인지도 확인!

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

코드 핵심 — 증가/감소/초기화

세 가지 버튼 함수와 화면 업데이트 패턴

JS let count = 0; // 현재 카운트 (변경 가능이라 let) const countEl = document.getElementById('count'); const msgEl = document.getElementById('message'); function increment() { count++; // count = count + 1 updateDisplay(); } function decrement() { if (count > 0) count--; // 0 미만 방지 updateDisplay(); } function reset() { count = 0; updateDisplay(); } // HTML: onclick="increment()" 으로 연결

수정 미션, 이렇게 진행하세요

바이브 코딩의 진짜 실력은 "고쳐달라고 잘 말하기"에서 나옵니다

1
같은 Cline 대화에서 이어가기
새 작업(New Task)을 열지 마세요! 코드를 만들어 준 대화에 이어서 요청해야 Cline이 맥락을 기억합니다.
2
미션 문구 붙여넣기
다음 슬라이드의 미션 프롬프트를 복사하거나, 원하는 변화를 말로 설명하세요. 문법·전문용어는 몰라도 됩니다.
3
변경 내용 확인하고 승인
Cline이 파일을 직접 고쳐줍니다. 어떤 부분이 바뀌는지(diff) 훑어보고 승인하세요. 직접 타이핑할 필요가 없어요.
4
저장하고 확인
저장(Ctrl+S) → 브라우저 새로고침(F5) → 바뀐 부분을 확인합니다.

Math.random() — 랜덤 숫자 생성

0 이상 1 미만의 랜덤 소수를 생성하는 내장 함수

Math.random()은 0 이상 1 미만 (0 ≤ x < 1) 의 랜덤 소수를 반환합니다.
배열의 인덱스와 조합하면 랜덤 항목 선택이 가능합니다.
// 기본: 0.0 ~ 0.999... 소수 Math.random(); // → 0.7341... // 0~9 정수 랜덤 Math.floor(Math.random() * 10); // 1~6 주사위 Math.floor(Math.random() * 6) + 1; // 배열에서 랜덤 1개 선택 const arr = ['홍길동', '김철수', '이영희']; const idx = Math.floor(Math.random() * arr.length); const picked = arr[idx]; // → '홍길동', '김철수', '이영희' 중 하나
📌

Math.floor 란?

소수를 버림해서 정수로 만듭니다.

Math.floor(3.9) → 3
Math.floor(0.7 * 3) → 2

random()*배열길이는 0.0 ~ 2.999...
floor하면 → 0, 1, 2 중 하나

배열 메서드 — push, filter, map

팀원과 업무 목록을 관리하는 배열 조작 메서드

JS let members = ['홍길동', '김철수']; // push: 맨 뒤에 추가 members.push('이영희'); // → ['홍길동','김철수','이영희'] // filter: 조건에 맞는 것만 추출 const without = members.filter( m => m !== '김철수' ); // → ['홍길동','이영희'] // map: 각 항목을 변환 const upper = members.map( m => `👤 ${m}` ); // → ['👤 홍길동','👤 김철수','👤 이영희'] // includes: 포함 여부 확인 members.includes('홍길동'); // → true

팀원 추가/삭제 패턴

JS // 추가 function addMember(name) { if (!name.trim()) return; if (members.includes(name)) { alert('이미 있는 이름!'); return; } members.push(name); render(); } // 삭제 (filter로 제외) function removeMember(name) { members = members.filter( m => m !== name ); render(); }

Fisher-Yates 셔플 — 공정한 섞기

배열을 완전히 무작위로 섞는 알고리즘

단순히 Math.random()으로 정렬하면 특정 순서가 더 자주 나옵니다. Fisher-Yates 알고리즘은 완전히 공정한 셔플을 보장합니다.
function shuffle(arr) { // 원본 배열을 수정하지 않도록 복사 const copy = [...arr]; // 뒤에서부터 랜덤 위치와 교환 for (let i = copy.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); // i번째와 j번째 위치 교환 [copy[i], copy[j]] = [copy[j], copy[i]]; } return copy; } // 사용 예시 const shuffled = shuffle(['A','B','C','D']); // → ['C','A','D','B'] 같이 섞임
🔄

스프레드 연산자 [...]

[...arr]는 배열을 복사합니다.

원본을 바로 수정하면 나중에 다시 배정할 때 원래 목록이 사라지므로, 복사본을 만들어 셔플합니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

화면 레이아웃을 직접 설계했다

"입력 영역 2열", "결과 영역 탭 2개"처럼 배치 구조를 명시했습니다. AI가 임의로 레이아웃을 정하지 않고 원하는 모습 그대로 만들어 줍니다.

✅ POINT 2

예외 상황을 미리 정해줬다

팀원 수 > 업무 수면 "대기", 업무 수 > 팀원 수면 "2개 이상 담당" 등 경우의 수를 직접 써줬습니다. 이 덕분에 AI가 스스로 판단할 빈틈이 없어집니다.

✅ POINT 3

버튼 동작 방식을 세부까지 설명했다

"🔒 잠금 = 현재 업무 고정", "부재 = 배정 대상 제외·취소선·흐림 처리"처럼 각 버튼이 어떻게 작동해야 하는지 구체적으로 명시했습니다.

✅ POINT 4

출력 형식과 기술 요건을 명시했다

"파일은 index.html 하나로", "코드에 한국어 주석"처럼 결과물의 형식까지 지정했습니다. 코드 품질과 유지보수성이 처음부터 확보됩니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"팀원한테 업무 랜덤으로 배정해줘"
→ 어떤 UI로 나올지, 예외는 어떻게 처리할지 AI가 마음대로 결정
✅ 구체적인 요청
"팀원 수 > 업무 수면 대기 처리, 잠금 버튼으로 배정 고정, 이력은 localStorage에 날짜와 함께 저장"

코드 핵심 설명

index.html 파일에서 찾아봐야 할 핵심 부분

① 배정 로직 (assign)

function assign() { if (members.length === 0) { alert('팀원을 먼저 추가해주세요!'); return; } if (tasks.length === 0) { alert('업무를 먼저 추가해주세요!'); return; } // 팀원·업무 각각 섞기 const shuffledMembers = shuffle(members); const shuffledTasks = shuffle(tasks); // 팀원 기준으로 업무 순환 배정 const results = shuffledMembers.map((member, i) => ({ member, task: shuffledTasks[i % shuffledTasks.length] })); renderResults(results); }
• i % shuffledTasks.length — 나머지 연산으로 업무 배열을 순환 사용
• 팀원이 업무보다 많으면 남은 팀원은 업무를 다시 받음
• 매번 shuffle()을 새로 호출하니 결과가 항상 달라짐

② 태그 삭제 (filter)

function removeMember(name) { members = members.filter( m => m !== name ); renderTags('member'); } // 태그 목록 다시 그리기 function renderTags(type) { const arr = type === 'member' ? members : tasks; el.innerHTML = arr.map(name => `...`) .join(''); }
• filter() — 삭제할 이름과 다른 항목만 남겨 새 배열 생성
• 원본 배열을 직접 지우지 않고 통째로 교체하는 방식
• 데이터가 바뀔 때마다 render 계열 함수를 다시 호출해 화면 갱신

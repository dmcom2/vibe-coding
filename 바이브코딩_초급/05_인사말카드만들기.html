템플릿 리터럴 — 문자열 조합

백틱(`)으로 변수를 자연스럽게 문자열에 넣는 방법

템플릿 리터럴은 작은따옴표/큰따옴표 대신 백틱(` `)을 사용해서
${변수명} 형식으로 변수 값을 문자열 안에 자연스럽게 넣습니다.
// ❌ 예전 방식 (+ 로 이어붙이기) const name = '홍길동'; const msg = '안녕하세요, ' + name + '님! ' + '좋은 하루 되세요.'; // ✅ 템플릿 리터럴 (훨씬 깔끔!) const msg2 = `안녕하세요, ${name}님! 좋은 하루 되세요.`; // 계산식도 넣을 수 있음 const a = 3, b = 5; console.log(`합계: ${a + b}원`); // → "합계: 8원"
💡

백틱(`)은 어디에?

키보드 숫자 1 왼쪽, Esc 아래

한/영 전환 상태에서 눌러야 합니다.
한글 상태에서는 ₩ (원화 기호)가 입력됩니다.

상황별 메시지 분기

JS function getMsg(name, situation) { if (situation === 'birthday') { return `🎂 ${name}님, 생일을 진심으로 축하합니다! 오늘 하루 행복하세요!`; } else if (situation === 'thanks') { return `🙏 ${name}님, 항상 도움 주셔서 감사합니다!`; } else { return `🎉 ${name}님, 새해 복 많이 받으세요!`; } }

async / await 란?

클립보드 복사는 비동기 작업입니다. async/await는 완료를 기다리는 문법입니다.

지금은 "복사할 때 이렇게 쓴다"만 기억하면 충분합니다!

SITUATION & ROLE

신규 고객사에 보낼 인사 메일이 매번 밋밋하다

상황 (Situation)

영업팀이 신규 고객사마다 인사 메일을 보내는데 매번 똑같은 텍스트 복붙이라 인상이 없다는 피드백을 받았습니다.

역할 (Role)

영업 지원 담당인 당신, 고객사 이름과 담당자 이름만 입력하면 예쁜 인사 카드 이미지로 뽑히는 도구를 만들고 싶습니다.

"이름이랑 회사 이름 넣으면 카드 형태로 나오면 좋겠는데요." — 영업팀장의 한 마디

AI와 함께 이름과 메시지를 입력하면 카드가 바로 완성되는 인사말 생성기를 만들어냅니다.

🔤 "한글이 깨져 보여요"

AI에게 "한글이 깨져 보여. UTF-8 인코딩으로 고쳐줘"라고 요청하세요. VS Code 오른쪽 아래 인코딩 표시가 UTF-8인지도 확인!

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

코드 핵심 설명

index.html 파일에서 찾아봐야 할 핵심 부분

① 입력값 읽기 → 카드 생성 (generateCard)

JS function generateCard() { // 1) 입력값 읽고 .trim()으로 공백 제거 const recipient = document .getElementById('recipient').value.trim() || '소중한 분'; const cardType = document .getElementById('card-type').value; // 2) 템플릿 리터럴로 카드 내용 조립 card.innerHTML = ` <div class="card-name">${recipient}</div> <div class="card-message">${data.message}</div> `; }
• .value — 입력창·드롭다운의 현재 값을 읽어옵니다
• .trim() — 앞뒤 공백을 제거해 실수를 줄여줍니다
• `${recipient}` — 템플릿 리터럴로 값을 문자열에 끼워 넣습니다

② 테마 버튼 클릭 처리 (setTheme)

JS function setTheme(theme, btn) { currentTheme = theme; // 모든 버튼에서 active 제거 후 // 클릭한 버튼에만 active 추가 document.querySelectorAll('.theme-btn') .forEach(b => b.classList.remove('active')); btn.classList.add('active'); // 카드에 테마 클래스 적용 → CSS가 배경색 변경 card.className = theme; }
• this로 클릭한 버튼 자신을 함수에 전달합니다
• classList — 요소에 CSS 클래스를 붙이고 떼는 도구
• 클래스만 바꾸면 CSS의 .spring/.summer 등이 배경을 자동으로 바꿔줍니다

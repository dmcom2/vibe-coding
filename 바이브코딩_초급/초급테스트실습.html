과제 진행 순서

3단계 프롬프트로 완성 — 막히면 Antigravity에게 질문하세요

1

1단계 — 기본 틀 만들기

HTML 구조 + CSS 디자인 + 날짜 표시
→ 헤더, 입력창, 빈 목록이 나타나면 성공

2

2단계 — 기능 구현하기

할일 추가 / 완료 체크 / 삭제 / 카테고리 분류 / 필터
→ 할일을 추가·체크·삭제할 수 있으면 성공

3

3단계 — 저장 & 꾸미기

localStorage 저장 + 진행률 바 + 토스트 메시지 + 빈 상태
→ 새로 고침 후에도 데이터가 남아 있으면 성공

💡 막혔을 때 대처법

오류 메시지나 이상한 화면을 그대로 복사해서 Antigravity에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요.

📁 파일 위치

바탕화면 → 바이브코딩 → 과제_할일체크리스트 폴더를 새로 만들고 VS Code로 열어주세요.

자주 막히는 문제 & 해결법

이 화면으로 돌아와서 확인하세요

❓ 버튼을 눌러도 아무것도 안 나와요

개발자 도구(F12) → Console 탭을 열어서 빨간 에러 메시지를 복사한 뒤 Antigravity에게 "이 오류 고쳐줘"라고 붙여넣으세요.

❓ 새로 고침하면 목록이 사라져요

localStorage 저장 코드가 빠진 것입니다. 3단계 프롬프트로 돌아가서 다시 요청하거나, Antigravity에게 "새로 고침해도 목록이 유지되도록 localStorage를 추가해줘"라고 말하세요.

❓ 화면이 깨지거나 CSS가 이상해요

Antigravity에게 화면 캡처를 붙여넣거나 "레이아웃이 깨졌어, 다시 고쳐줘"라고 말하면 자동으로 수정해 줍니다.

❓ 필터를 눌렀는데 목록이 안 바뀌어요

Antigravity에게 "필터 탭을 클릭해도 목록이 안 바뀌는 버그를 고쳐줘"라고 정확히 설명해 주세요.

오늘 만드는 것

팀 업무를 칸반 보드로 관리하고 Gemini AI가 현황을 분석해 보고서를 자동 생성하는 대시보드

🗂️

칸반 보드 (드래그 앤 드롭)

할 일 / 진행 중 / 완료 3열로 업무 카드를 관리합니다. 카드를 드래그해서 열 사이를 이동합니다. 우선순위 배지, D-day, 담당자 아바타까지 표시됩니다.

📈

Chart.js 차트 + 현황 사이드바

도넛 차트로 상태별 업무 비율을 시각화합니다. 담당자별 진행률 바가 카드 변경 즉시 실시간으로 갱신됩니다.

🖥️

Node.js 서버 + data.json 저장

서버를 만들어 업무와 보고서 이력을 data.json 파일에 영구 저장합니다. 새로고침해도 데이터가 사라지지 않습니다. npm 패키지 설치는 불필요합니다.

🤖

Gemini AI 보고서 + 이력 관리

버튼 한 번으로 AI 현황 분석 보고서를 생성합니다. 보고서 이력이 사이드바에 자동 저장되고, 클릭해서 재열람할 수 있습니다. JSON 내보내기도 지원합니다.

📁

최종 파일 구조
index.html  ·  server.js  ·  .env  ·  data.json (자동 생성)  ·  start.bat

🗺️

과제 진행 순서 — 3단계

각 단계마다 브라우저에서 직접 확인하고 다음 단계로 넘어가세요

1

1단계 — 칸반 보드 기본 틀 (index.html)

서버 없이 브라우저에서 바로 열 수 있는 단일 HTML 파일. 3열 칸반 보드, 드래그 앤 드롭, 업무 추가 모달, Chart.js 도넛 차트, CSV 내보내기까지 완성.
→ index.html을 파일로 열어 칸반 보드가 보이면 성공

2

2단계 — Node.js 서버 + data.json 영구 저장

server.js 생성. Node.js 내장 모듈(http, fs, path)만 사용 — npm install 불필요. GET/POST /api/data로 데이터를 파일에 영구 저장. node server.js로 실행.
→ 새로고침해도 데이터가 남으면 성공

3

3단계 — Gemini AI 보고서 생성 + 이력 관리

Gemini API 프록시 추가. API 키는 서버의 .env에 보관 (브라우저에 노출 안 됨). 보고서 생성 → 이력 저장 → 클릭 재열람. JSON 내보내기 추가.
→ AI 보고서가 생성되고 이력에 남으면 성공

💡 2단계부터는 서버 실행이 필요합니다. 터미널에서 node server.js 실행 후 http://localhost:3002 접속. 또는 start.bat 더블클릭.

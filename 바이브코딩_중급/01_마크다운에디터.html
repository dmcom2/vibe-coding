오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 CDN

설치 없이 인터넷에서 바로 불러다 쓰는 외부 라이브러리 서버. <script src="URL"> 한 줄로 사용

📌 라이브러리

누군가 미리 만들어 둔 기능 모음. 오늘은 마크다운→HTML 변환을 대신 해주는 marked.js를 사용

📌 debounce

짧은 시간 안에 여러 번 일어나는 이벤트를 마지막 한 번만 처리하도록 미루는 기법

📌 localStorage

브라우저에 데이터를 저장해두는 보관함. 새로고침해도 내용이 남아있는 이유

📌 Blob

브라우저 메모리에서 즉석으로 만드는 파일 데이터 덩어리. 다운로드 기능의 핵심

📌 3파일 구조

index.html(구조) · style.css(디자인) · script.js(동작)로 역할을 나눈 표준 웹앱 구성

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

CDN 라이브러리 — marked.js

설치 없이 URL 한 줄로 마크다운 변환 기능을 가져오기

CDN(Content Delivery Network)은 라이브러리를 인터넷 서버에서 직접 불러오는 방법입니다.
npm install 없이 <script src="URL"> 한 줄만으로 사용할 수 있습니다.
<!-- HTML head에 CDN 추가 --> <script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js" ></script> // JavaScript - 마크다운 → HTML 변환 const markdown = `# 제목 **굵게** *기울임* - 항목 1 - 항목 2`; const html = marked.parse(markdown); // → <h1>제목</h1><p><strong>...</p> // 미리보기에 적용 document.getElementById('preview') .innerHTML = html;

debounce — 입력 폭발 방지

빠른 타이핑 시 함수를 매번 실행하지 않고 잠깐 기다렸다 실행

JS // 문제: 입력마다 즉시 실행 → 성능 저하 textarea.addEventListener('input', () => { updatePreview(); // 글자마다 실행! }); // 해결: debounce — 300ms 후 한 번만 실행 let timer; textarea.addEventListener('input', () => { clearTimeout(timer); // 이전 예약 취소 timer = setTimeout(() => { updatePreview(); // 300ms 뒤 실행 }, 300); }); // 자동 저장도 동일 패턴 (3초) let saveTimer; function autoSave() { clearTimeout(saveTimer); saveTimer = setTimeout(() => { localStorage.setItem('doc', textarea.value); showToast('자동 저장됨'); }, 3000); }

debounce 동작 원리

타이핑 중 (이전 타이머 계속 취소)

ㅇ → 취소 / ㅏ → 취소 / ㄴ → 취소 ...

300ms 동안 입력 없음 → 실행!

updatePreview() 한 번만 호출

결과: 부드럽고 빠른 에디터

초당 수십 번 실행 → 초당 3~4번으로 감소

📤

HTML 내보내기 — Blob API

완성된 미리보기를 독립 HTML 파일로 다운로드

function exportHTML() { const content = document .getElementById('preview').innerHTML; // 완성된 HTML 문서 생성 const fullHtml = `<!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8"> <title>내보낸 문서</title> <style> body { max-width:800px; margin:40px auto; font-family:sans-serif; } h1,h2 { border-bottom:1px solid #e2e8f0; } code { background:#f1f5f9; padding:2px 6px; } </style> </head> <body>${content}</body> </html>`; // Blob → URL → 다운로드 const blob = new Blob([fullHtml], { type: 'text/html' }); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = '문서.html'; a.click(); }
🗜️

Blob이란?

Binary Large OBject — 파일 데이터를 메모리에 생성합니다.

서버 없이 브라우저에서 직접 파일을 만들어 다운로드할 수 있습니다.

🔗

URL.createObjectURL()

Blob 데이터에 임시 URL을 부여합니다. 이 URL을 <a> 태그의 href에 설정하고 click()을 호출하면 다운로드됩니다.

AI에게 말 거는 법 — 프롬프트 3단 구조

중급도 원리는 같습니다. 다만 "파일을 나눠달라"는 조건이 하나 추가됩니다

①
무엇을 "마크다운 에디터를 만들어줘"
만들 것을 한 문장으로. 첫 줄이 가장 중요합니다
②
기능/라이브러리 "marked.js CDN 사용, 실시간 미리보기, 자동저장"
필요한 기능과 외부 라이브러리를 목록으로 나열합니다
③
조건/파일 구조 "index.html, style.css, script.js 3개로 나눠줘"
중급부터는 파일을 나눠달라는 조건을 꼭 넣어야 관리가 편합니다
💡 라이브러리 이름이 기억 안 나도 괜찮습니다. "마크다운을 HTML로 바꿔주는 라이브러리 써줘"처럼 말로 설명해도 AI가 marked.js를 선택해줍니다.

CDN 라이브러리는 인터넷 연결이 필요합니다. 안 되면 화면 일부가 아니라 편집기·미리보기가 통째로 먹통이 됩니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

툴바 버튼 — 선택 텍스트 감싸기

selectionStart/End로 커서 위치를 파악하고 문법 삽입

JS function insertMarkdown(before, after = '') { const ta = document.getElementById('editor'); const start = ta.selectionStart; // 선택 시작 위치 const end = ta.selectionEnd; // 선택 끝 위치 const sel = ta.value.substring(start, end); // 선택된 텍스트 // 선택 텍스트 앞뒤에 마크다운 기호 삽입 ta.value = ta.value.substring(0, start) + before + sel + after + ta.value.substring(end); // 커서 위치 조정 (삽입된 기호 안쪽으로) ta.focus(); ta.selectionStart = start + before.length; ta.selectionEnd = end + before.length; updatePreview(); } // 버튼 HTML 예시 // onclick="insertMarkdown('**', '**')" → 굵게 // onclick="insertMarkdown('# ')" → H1 제목 // onclick="insertMarkdown('- ')" → 리스트

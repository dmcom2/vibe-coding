핵심 기술 개념 미리보기

실무 웹 애플리케이션 개발에 필수적인 4가지 기술 키워드

📌 Drag & Drop API

마우스 요소 잡기(dragstart), 이동(dragover), 놓기(drop) 이벤트를 감지하여 카드를 드래그로 옮기는 브라우저 표준 API

📌 JSON 백업 / 복원

JSON.stringify()로 보드 데이터를 파일로 내보내고, JSON.parse()로 백업 파일을 읽어 동기화하는 구조

📌 Modal Dialog

일정 추가/상세 보기 시 화면 위에 레이어로 떠오르는 팝업창. 배경 클릭 및 ESC 키 닫기 이벤트 포함

📌 Data-Attribute

data-id, data-status 등 HTML 태그에 자바스크립트용 식별 데이터를 보관하고 추적하는 방법

🚚

Drag & Drop API 동작 원리

웹 브라우저의 드래그 앤 드롭 이벤트를 이해하면 쉽게 제어할 수 있습니다

// 1. 카드를 드래그 가능하게 설정 (HTML) <div class="card" draggable="true">업무 내용</div> // 2. JS: 드래그 시작 시 카드 ID 저장 card.addEventListener('dragstart', (e) => { e.dataTransfer.setData('text/plain', card.dataset.id); }); // 3. JS: 타겟 컬럼 위에 있을 때 drop 허용 column.addEventListener('dragover', (e) => { e.preventDefault(); // 필수! 기본 동작 차단 }); // 4. JS: 놓았을 때 컬럼 상태 변경 column.addEventListener('drop', (e) => { const cardId = e.dataTransfer.getData('text/plain'); updateCardStatus(cardId, column.dataset.status); });

드래그 앤 드롭 3단계 흐름

① dragstart

사용자가 카드를 마우스로 집어 올릴 때 발동. 이동시킬 카드의 ID를 기록합니다.

② dragover

카드가 목표 컬럼 위를 지날 때 발동. e.preventDefault()를 호출해야 drop 이벤트를 받을 수 있습니다.

③ drop

마우스를 놓았을 때 발동. 새 컬럼으로 카드를 옮기고 localStorage 데이터를 업데이트합니다.

📦

JSON 백업 / 복원 로직

서버 없이도 팀원 간 프로젝트 파일 공유가 가능해지는 매커니즘

JS - 백업 (Export) function exportBoardData() { const data = localStorage.getItem('kanban-tasks'); const blob = new Blob([data], { type: 'application/json' }); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = `kanban_backup_${new Date().toISOString().slice(0,10)}.json`; a.click(); }
JS - 복원 (Import) function importBoardData(file) { const reader = new FileReader(); reader.onload = (e) => { try { const tasks = JSON.parse(e.target.result); localStorage.setItem('kanban-tasks', JSON.stringify(tasks)); renderBoard(); // 보드 다시 그리기 } catch(err) { alert('올바른 JSON 파일이 아닙니다.'); } }; reader.readAsText(file); }

프롬프트 해설 — 왜 효과적인가?

실무 수준의 완성도를 높이는 프롬프트 구성 요소

✅ POINT 1: 업무 도메인 특화 속성 정의

단순 메모가 아니라 '담당자', '마감일', '우선순위' 등 실제 사내 프로젝트에 필수적인 메타데이터 항목을 정확히 요구했습니다.

✅ POINT 2: 사용자 경험(UX) 조건 지정

우선순위별 배지 색상 차별화, 마감일 지난 카드 경고 표시, 모달 ESC 닫기 등 사용자 편의 기능을 구체적으로 명시했습니다.

✅ POINT 3: 팀 협업을 위한 JSON 백업/복원

서버가 없는 클라이언트 단 환경에서도 JSON 내보내기/불러오기로 팀원 간 데이터 공유가 가능하도록 설계를 유도했습니다.

✅ POINT 4: 3개 파일 모듈화 분리

HTML(구조), CSS(스타일), JS(로직)를 깔끔하게 분리하여 코드 가독성 및 유지보수성을 극대화했습니다.

자주 막히는 트러블슈팅

실습 중 에러가 발생할 때 체크해야 할 사항

🚚 "카드가 드래그되지 않아요"

HTML 카드 엘리먼트에 draggable="true" 속성이 빠져있는지 확인하거나, dragover 이벤트에 e.preventDefault()가 실행되는지 체크하세요.

💾 "새로고침하면 옮긴 카드가 원위치돼요"

drop 이벤트 처리 함수 내부에서 카드의 status 변경 후 localStorage.setItem()이 정상 호출되고 있는지 확인하세요.

📁 "JSON 백업 파일 복원이 안 돼요"

불러온 파일 데이터가 JSON.parse() 시 구문 에러가 나지 않는지, FileReader의 읽기 완료 시점(onload) 로직을 확인하세요.

🎨 "스타일이 깨지거나 모달이 안 떠요"

index.html 상단에 <link rel="stylesheet" href="style.css"> 경로가 올바르게 연결되어 있는지 확인하세요.

오늘 나오는 용어 미리보기

3가지만 기억하면 수업이 술술 풀립니다

📅

Date 객체

자바스크립트 내장 기능. new Date()로 오늘 날짜를 가져오고, .getFullYear() .getMonth() .getDay()로 년·월·요일을 꺼냅니다. getMonth()는 0부터 시작(1월=0)하므로 +1 해야 합니다.

🌐

Express 서버 / API

Node.js용 웹 서버 라이브러리. app.get('/api/events') 처럼 URL 경로별로 응답을 정의합니다. 일정 데이터를 JSON 파일에 저장해 팀 전체가 공유합니다.

🔗

fetch API

브라우저에서 서버와 통신하는 방법. fetch('/api/events')로 일정을 가져오고, method:'POST'로 새 일정을 보냅니다. localStorage 대신 서버에 저장되어 팀원 모두가 볼 수 있습니다.

📌 시나리오 — 왜 팀 캘린더가 필요할까요?
팀장님: "이번 주 회의 일정이
누구 캘린더에 있어요?"
😤 문제 상황
팀원마다 각자 캘린더를 씁니다. 회의 일정이 바뀌면 카카오톡으로 다시 알려야 하고, 누가 휴가인지 아무도 모릅니다.
🔍 기존 방식의 한계
localStorage는 내 브라우저에만 저장됩니다. 같은 컴퓨터에서도 다른 브라우저면 데이터가 없습니다. 팀 공유가 불가능합니다.
✅ 오늘의 해결책
Node.js 서버를 만들고 일정을 서버의 JSON 파일에 저장합니다. 같은 네트워크의 팀원이면 누구나 같은 캘린더를 볼 수 있습니다.
🎯 완성 후 모습
누가 어떤 일정을 등록했는지 작성자 이름이 표시됩니다. 30초마다 자동 갱신되어 팀원 변경사항을 바로 확인합니다.

Date 객체 — 캘린더의 심장

3줄 코드가 캘린더 전체 날짜를 만듭니다

JavaScript // 1. 현재 날짜 가져오기 const today = new Date(); // → 2025-08-25T09:30:00 today.getFullYear(); // → 2025 today.getMonth(); // → 7 (8월인데 0-based이므로 +1 해야 함) today.getDate(); // → 25 today.getDay(); // → 1 (월요일. 0=일, 6=토) // 2. 이달 첫 날의 요일 → 캘린더 앞 빈칸 개수 const firstDay = new Date(year, month, 1).getDay(); // 이달 1일이 무슨 요일? // 3. 이달 마지막 날짜 → 몇 일까지 있나 const lastDate = new Date(year, month + 1, 0).getDate(); // 다음달 0일 = 이달 마지막 // 4. 날짜 키 (일정 저장용 객체 key) function dateKey(y, m, d) { return `${y}-${String(m+1).padStart(2,'0')}-${String(d).padStart(2,'0')}`; } // → "2025-08-25"
💡 캘린더 그리드 생성 원리. 첫 날 요일만큼 빈 셀을 앞에 붙이고, 1일부터 마지막 날까지 셀을 반복 생성합니다. Date 객체 3줄로 모든 월의 레이아웃을 자동 계산합니다.

서버가 왜 필요할까요?

localStorage의 한계와 서버의 차이점

localStorage 개인 저장소

✗ 내 브라우저에만 저장됨
✗ 다른 컴퓨터에선 빈 캘린더
✗ 팀원이 등록한 일정을 볼 수 없음
✗ 브라우저 초기화 시 데이터 손실

Node.js 서버 팀 공유 저장소

✓ 서버 JSON 파일에 영구 저장
✓ 팀원 전원이 같은 데이터 공유
✓ 작성자·시간·카테고리 함께 저장
✓ 서버 재시작 후에도 데이터 유지
🔑 핵심 변화. localStorage.setItem() → fetch('/api/events', {method:'POST'}) 로 바꾸면 됩니다. 브라우저에 저장하는 대신 서버에 보내는 것입니다.

server.js 코드 이해

Express 서버는 단 4가지 역할만 합니다

JavaScript — server.js const express = require('express'); const fs = require('fs'); // 파일 읽기/쓰기 const app = express(); app.use(express.json()); // JSON 요청 파싱 app.use(express.static(__dirname)); // index.html 서빙 // ① 일정 목록 조회 — GET /api/events app.get('/api/events', (req, res) => { const data = JSON.parse(fs.readFileSync('calendar_data.json')); res.json({ ok: true, events: data.events }); }); // ② 일정 추가 — POST /api/events app.post('/api/events', (req, res) => { const { date, text, color, author } = req.body; // 요청에서 꺼냄 const data = loadData(); if (!data.events[date]) data.events[date] = []; data.events[date].push({ id: Date.now(), text, color, author }); fs.writeFileSync('calendar_data.json', JSON.stringify(data)); // 파일에 저장 res.json({ ok: true }); }); // ③ 일정 삭제 — DELETE /api/events/:date/:id // ④ 30초 자동 갱신 — 브라우저가 setInterval로 GET /api/events 반복 호출 app.listen(8948); // 포트 8948에서 대기
💡 calendar_data.json 파일이 팀의 공유 저장소입니다. 서버가 이 파일을 읽고 쓰면서 팀원 모두가 같은 데이터를 공유합니다.

사이드바(side-col)에 "이달 공휴일" 카드를 추가해 주세요.

- 현재 보고 있는 달(curYear, curMonth)의 HOLIDAYS 객체에서
  해당 월의 공휴일만 필터링합니다.
- 각 공휴일마다 날짜(M/D), 공휴일명, D-Day 표시
  (오늘 기준 남은 일수: "D-3", 이미 지났으면 "지남")
- 빨간 점(●)으로 시각적으로 구분
- 이달 공휴일이 없으면 "이달 공휴일 없음" 메시지 표시
- renderSidebar() 함수 안에서 함께 처리합니다.
💡 navigate() 함수로 월이 바뀔 때 renderSidebar()가 자동 호출되므로, 카드 내용도 자동 갱신됩니다.
📊

미션 5 — 카테고리 통계 차트

AI 요청 | 이달 카테고리별 일정 수를 막대 그래프로 표시합니다

📋 목표. 사이드바 통계 카드 아래에 카테고리별 일정 수를 인라인 막대 그래프로 시각화합니다. 외부 라이브러리 없이 CSS로만 구현합니다.
💬 CLINE에 이렇게 요청하세요
사이드바 통계 카드에 카테고리별 막대 차트를 추가해 주세요.

- 이달(curYear, curMonth) 모든 날짜의 일정에서
  COLOR_LIST 카테고리별 건수를 집계합니다.
- 각 카테고리마다 색상 점(●) + 이름 + 막대 + 건수를 한 줄로 표시
- 막대는 CSS width: (건수/최대건수 * 100)%로 상대 비율을 표현
- 0건인 카테고리는 숨깁니다.
- renderSidebar() 함수 내에서 함께 처리합니다.

예시 HTML 구조:
<div style="display:flex;align-items:center;gap:6px;margin-bottom:6px;">
  <span style="color:#1d4ed8;">●</span>
  <span style="width:36px;font-size:.78rem;">업무</span>
  <div style="flex:1;background:#f1f5f9;border-radius:4px;height:8px;">
    <div style="width:70%;background:#3b82f6;border-radius:4px;height:8px;"></div>
  </div>
  <span style="font-size:.78rem;font-weight:700;">7건</span>
</div>
💡 CDN·외부 라이브러리 없이 순수 CSS width로 막대 비율을 표현합니다. 단순하지만 효과적입니다.
🌙

미션 6 — 다크 모드 지원

AI 요청 | 라이트/다크 테마 전환 기능을 추가합니다

📋 목표. 헤더에 토글 버튼을 추가하고 CSS 변수로 전체 색상을 전환합니다. 선택한 테마는 localStorage에 저장되어 재접속 시에도 유지됩니다.
💬 Antigravity에 이렇게 요청하세요
캘린더에 다크 모드 지원을 추가해 주세요.

[요구사항]
- 헤더 오른쪽에 🌙 / ☀️ 토글 버튼 추가
- CSS :root 변수(--bg, --card, --text, --border 등)로 색상 정의
- body에 data-theme="dark" 속성 토글로 전체 테마 전환
- 다크 모드일 때 배경은 #0f172a, 카드는 #1e293b, 텍스트는 #e2e8f0
- 선택한 테마를 localStorage('cal_theme')에 저장
- 페이지 로드 시 저장된 테마 자동 적용
💡 CSS 변수만 바꾸면 전체 색상이 한 번에 바뀝니다. 직접 색상값을 조정해 나만의 테마를 만들어 보세요.

미션 6 완료 후 — 서버 운영 순서

팀원들이 접속하기까지 6단계

1

의존성 설치

VS Code 터미널에서 npm install 실행 → express 설치 완료

2

서버 실행

node server.js 실행 → 터미널에 "📅 서버 실행 중: http://localhost:8948" 출력 확인

3

내 IP 확인

Windows: ipconfig | Mac: ifconfig → IPv4 주소 확인 (예: 192.168.1.100)

4

접속 주소 공유

팀원들에게 http://192.168.1.100:8948 주소 공유 (같은 네트워크여야 함)

5

이름 설정

팀원 각자가 처음 일정 추가 시 이름 입력 모달이 뜸 → 이름 입력 후 일정이 등록되며 작성자로 표시됨

6

일정 등록 & 공유

누구 하나가 일정을 등록하면 30초 내에 모든 팀원 화면에 자동 반영됨

💡 서버를 끄면 팀원들이 접속할 수 없습니다. 업무 시간 중에는 서버를 켜 두세요. 일정 데이터는 calendar_data.json 파일에 안전하게 저장됩니다.

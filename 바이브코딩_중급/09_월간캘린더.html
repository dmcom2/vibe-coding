외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 Date 객체

자바스크립트에서 날짜와 시간을 다루는 내장 객체. new Date()로 현재 시각을 생성

📌 getDay / getMonth

Date 객체에서 요일(0~6)과 월(0~11, 0부터 시작!)을 꺼내는 메서드

📌 날짜 키(dateKey)

'2025-06-07' 형식의 문자열. 일정을 날짜별로 저장/조회할 때 객체의 key로 사용

📌 달력 그리드 계산

첫날 요일만큼 빈 칸을 채우고 마지막 날짜까지 채워 7×6(42칸) 격자를 완성하는 계산

📌 이벤트 CRUD

일정을 추가(Create)·조회(Read)·수정(Update)·삭제(Delete)하는 기본 데이터 처리 패턴

📌 월 오버플로우

12월 다음달은 내년 1월, 1월 이전달은 작년 12월로 자동 넘어가도록 처리하는 로직

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

Date 객체 — 캘린더 계산

첫날 요일과 마지막 날짜를 구하는 2가지 공식

let curYear = new Date().getFullYear(); // 2025 let curMonth = new Date().getMonth(); // 5 (6월, 0-indexed) // ① 첫날의 요일 (0=일, 1=월, ..., 6=토) const firstDay = new Date(curYear, curMonth, 1) .getDay(); // 2025년 6월 1일 = 일요일 → 0 // ② 마지막 날짜 (다음달 0번째 날 = 이번달 마지막날) const lastDate = new Date(curYear, curMonth + 1, 0) .getDate(); // 2025년 6월 → 30 // ③ 날짜 키 생성 (일정 저장용) function dateKey(year, month, day) { return `${year}-${ String(month + 1).padStart(2, '0') }-${ String(day).padStart(2, '0') }`; } // dateKey(2025, 5, 7) → '2025-06-07'

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

첫 문장에 목적을 명시

"HTML, CSS, JavaScript로 월간 캘린더를 만들어줘"처럼 무엇을 만들지 한 문장으로 시작하면 AI가 전체 구조를 즉시 파악해 엉뚱한 방향으로 진행하지 않습니다.

✅ POINT 2

기능을 섹션·목록으로 열거

"기능:", "기타:", "디자인:" 섹션으로 나눠 글머리 기호로 나열하면 AI가 항목을 빠뜨리지 않고 모두 구현합니다. 문단으로 섞어 쓰면 일부 기능이 누락될 수 있습니다.

✅ POINT 3

파일 구조까지 지정

"index.html, style.css, script.js 3개로 나눠서"처럼 출력 형태를 명시하면 AI가 유지보수하기 좋은 구조로 코드를 분리합니다. 지정하지 않으면 모든 코드가 한 파일에 뭉쳐질 수 있습니다.

✅ POINT 4

코드 품질 조건 추가

"한국어 주석 달아줘"처럼 코드 스타일 조건을 덧붙이면 나중에 코드를 읽거나 수정할 때 훨씬 이해하기 쉬운 결과물이 나옵니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"캘린더 앱 만들어줘"
→ 기능 누락, 단일 파일, 영어 주석 등 예측 불가한 결과
✅ 구체적인 요청
"기능 목록 + 3파일 분리 + 한국어 주석"
→ 한 번에 원하는 구조와 품질로 완성

💾 "고쳤는데 화면이 그대로예요"

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

월 이동 — 오버플로우 처리

12월 다음달 → 1월, 1월 이전달 → 12월 자동 처리

function changeMonth(delta) { curMonth += delta; // +1 또는 -1 // Month 오버플로우 처리 if (curMonth > 11) { curMonth = 0; // 12월 → 1월 curYear++; } else if (curMonth < 0) { curMonth = 11; // 1월 → 12월 curYear--; } buildCalendar(); updateHeader(); } // 월 헤더 업데이트 function updateHeader() { const months = [ '1월','2월','3월','4월', '5월','6월','7월','8월', '9월','10월','11월','12월' ]; document.getElementById('header').textContent = `${curYear}년 ${months[curMonth]}`; } // 팁: new Date(year, month, day)에서 // month가 범위를 벗어나도 자동 보정됨! // new Date(2025, 12, 1) → 2026년 1월 1일

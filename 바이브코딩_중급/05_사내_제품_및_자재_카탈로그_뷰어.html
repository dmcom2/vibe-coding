CSS Grid로 그리드/리스트 뷰 전환

grid-template-columns 한 줄만 바꾸면 레이아웃이 바뀝니다

/* 그리드 뷰: 4열 카드 */ .catalog-grid { display: grid; grid-template-columns: repeat(4, 1fr); gap: 14px; } /* 리스트 뷰: 1열 행형 */ .catalog-grid.list-view { grid-template-columns: 1fr; gap: 8px; } // JS: 클래스 토글로 전환 function setView(isGrid) { grid.classList.toggle( 'list-view', !isGrid ); }
Grid vs Flex

• Grid — 행·열 2차원 제어
→ 카드 갤러리, 대시보드

• Flex — 1차원 방향 제어
→ 헤더, 버튼 그룹, 리스트 행

카탈로그 카드 = Grid
헤더 레이아웃 = Flex

Array.filter()로 검색 & 카테고리 필터

배열의 filter() 메서드 하나로 검색과 카테고리를 동시에 처리

function getFiltered() { return ITEMS.filter(item => { // 카테고리 조건 const matchCat = currentCategory === '전체' || item.category === currentCategory; // 검색어 조건 const matchSearch = !currentSearch || item.id.includes(currentSearch) || item.name.includes(currentSearch); // 둘 다 만족해야 표시 return matchCat && matchSearch; }); }
filter() 동작 원리

배열의 각 항목에 조건 함수를 실행해
true를 반환하는 항목만 새 배열로 반환

→ 원본 배열(ITEMS)은 변경되지 않음
→ 검색할 때마다 원본에서 다시 필터링
→ 검색어·카테고리 상태만 바꾸고 re-render
✅ 상태(state) = currentCategory, currentSearch
✅ 렌더 = getFiltered() → DOM 업데이트
✅ 상태가 바뀔 때마다 렌더 함수 호출

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

기능을 영역별로 구조화

"카탈로그 UI · 품목 카드 · 샘플 데이터 · 기능"처럼 섹션을 나눠 요청하면 AI가 빠뜨리지 않고 전체를 구현합니다.

✅ POINT 2

데이터 구조를 미리 지정

"id, name, spec, category, status, price, unit, minOrder, leadTime, note 필드"처럼 필드명을 명시하면 AI가 임의로 결정하지 않습니다.

✅ POINT 3

UI 패턴 이름을 사용

"모달", "사이드패널", "배지"처럼 UI 패턴 이름을 쓰면 AI가 정확히 알아듣고 표준적인 구현을 제공합니다.

✅ POINT 4

출력 형식 명확히 지정

"index.html·style.css·script.js 3개로, 한국어 주석"처럼 결과물 형태를 지정하면 원하는 구조 그대로 파일을 만들어 줍니다.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

🔍 "검색해도 카드가 안 걸러져요"

F12 → Console에서 오류 확인. filter() 함수가 제대로 호출되는지 Cline에게 로그를 추가해 달라고 하세요.

🛒 "담기 버튼 클릭 시 모달이 열려요"

담기 버튼 이벤트에 e.stopPropagation()이 없어서 카드 클릭 이벤트까지 발생하는 현상입니다. Cline에게 오류를 설명하면 바로 수정됩니다.

📥 "CSV 다운로드가 안 돼요"

Blob과 URL.createObjectURL을 사용합니다. 브라우저 팝업 차단 여부를 확인하고 오류 메시지를 Cline에 붙여넣으세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 Cline에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

핵심 코드 이해하기

localStorage로 출고요청 장바구니를 새로고침 후에도 유지하는 원리

// 앱 시작 시 localStorage에서 장바구니 복원 let cart = JSON.parse( localStorage.getItem('catalogCart') || '[]' ); // 담기: 이미 있으면 수량 +1, 없으면 새로 추가 function addToCart(id) { const existing = cart.find(c => c.id === id); if (existing) { existing.qty += 1; } else { cart.push({ id, qty: 1, /* ... */ }); } localStorage.setItem( 'catalogCart', JSON.stringify(cart) ); } // CSV 내보내기: Blob → 가상 a 태그 → 클릭 const blob = new Blob([csv], {type:'text/csv'}); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = '출고요청서.csv'; a.click();

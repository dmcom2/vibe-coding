CSS Grid로 그리드/리스트 뷰 전환

grid-template-columns 한 줄만 바꾸면 레이아웃이 바뀝니다

/* 그리드 뷰: 4열 카드 */ .catalog-grid { display: grid; grid-template-columns: repeat(4, 1fr); gap: 14px; } /* 리스트 뷰: 1열 행형 */ .catalog-grid.list-view { grid-template-columns: 1fr; gap: 8px; } // JS: 클래스 토글로 전환 function setView(isGrid) { grid.classList.toggle( 'list-view', !isGrid ); }
Grid vs Flex

• Grid — 행·열 2차원 제어
→ 카드 갤러리, 대시보드

• Flex — 1차원 방향 제어
→ 헤더, 버튼 그룹, 리스트 행

카탈로그 카드 = Grid
헤더 레이아웃 = Flex

Array.filter()로 검색 & 카테고리 필터

배열의 filter() 메서드 하나로 검색과 카테고리를 동시에 처리

function getFiltered() { return ITEMS.filter(item => { // 카테고리 조건 const matchCat = currentCategory === '전체' || item.category === currentCategory; // 검색어 조건 const matchSearch = !currentSearch || item.id.includes(currentSearch) || item.name.includes(currentSearch); // 둘 다 만족해야 표시 return matchCat && matchSearch; }); }
filter() 동작 원리

배열의 각 항목에 조건 함수를 실행해
true를 반환하는 항목만 새 배열로 반환

→ 원본 배열(ITEMS)은 변경되지 않음
→ 검색할 때마다 원본에서 다시 필터링
→ 검색어·카테고리 상태만 바꾸고 re-render
✅ 상태(state) = currentCategory, currentSearch
✅ 렌더 = getFiltered() → DOM 업데이트
✅ 상태가 바뀔 때마다 렌더 함수 호출

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

기능을 영역별로 구조화

"카탈로그 UI · 품목 카드 · 샘플 데이터 · 기능"처럼 섹션을 나눠 요청하면 AI가 빠뜨리지 않고 전체를 구현합니다.

✅ POINT 2

데이터 구조를 미리 지정

"id, name, spec, category, status, price, unit, minOrder, leadTime, note 필드"처럼 필드명을 명시하면 AI가 임의로 결정하지 않습니다.

✅ POINT 3

UI 패턴 이름을 사용

"모달", "사이드패널", "배지"처럼 UI 패턴 이름을 쓰면 AI가 정확히 알아듣고 표준적인 구현을 제공합니다.

✅ POINT 4

출력 형식 명확히 지정

"index.html·style.css·script.js 3개로, 한국어 주석"처럼 결과물 형태를 지정하면 원하는 구조 그대로 파일을 만들어 줍니다.

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

🔍 "검색해도 카드가 안 걸러져요"

F12 → Console에서 오류 확인. filter() 함수가 제대로 호출되는지 Zoo Code에게 로그를 추가해 달라고 하세요.

🛒 "담기 버튼 클릭 시 모달이 열려요"

담기 버튼 이벤트에 e.stopPropagation()이 없어서 카드 클릭 이벤트까지 발생하는 현상입니다. Zoo Code에게 오류를 설명하면 바로 수정됩니다.

📥 "CSV 다운로드가 안 돼요"

Blob과 URL.createObjectURL을 사용합니다. 브라우저 팝업 차단 여부를 확인하고 오류 메시지를 Zoo Code에 붙여넣으세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 Zoo Code에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

수정 과제 — 고급 기능

완성품에 구현된 고급 기능을 직접 만들어보세요 — 어려울수록 실력이 늘어납니다!

📖
과제 1 · 중간 난이도

사용 매뉴얼 모달

헤더에 매뉴얼 버튼을 추가하고, 클릭 시 앱 사용법 안내 모달을 띄웁니다.

• 헤더 "📖 매뉴얼" 버튼
• 사용자 기능 8개 카드 그리드
• 재고 상태 기준표 (표 형식)
• ESC·오버레이 클릭으로 닫기
💬 "헤더에 매뉴얼 버튼 추가하고, 클릭 시 앱 사용법이 정리된 모달을 띄워줘. 사용자 기능 항목을 카드 그리드로 보여줘"
🔐
과제 2 · 어려운 난이도

관리자 모드 + 로그인

비밀번호 인증 후 관리자 전용 기능(수정/삭제)이 활성화됩니다.

• 헤더 "🔐 관리자" 버튼
• 비밀번호 입력 모달 (1234)
• 관리자 모드 ON 알림 바
• 카드에 수정/삭제 버튼 표시
💬 "헤더에 관리자 버튼 추가. 클릭 시 비밀번호 입력 모달 표시. 비밀번호(1234) 맞으면 관리자 모드 ON, 각 카드에 수정·삭제 버튼 표시해줘"
⚙️
과제 3 · 최고 난이도

제품 추가·수정·삭제 (CRUD)

관리자 모드에서 제품을 직접 추가하고, 수정하고, 삭제할 수 있습니다.

• 제품 추가 폼 모달 (8개 필드)
• 제품 수정 (기존 데이터 자동 채움)
• 삭제 확인 후 제거
• localStorage에 자동 저장
💬 "관리자 모드에서 제품 추가·수정·삭제 기능 구현. 추가/수정은 폼 모달 사용. 변경사항은 localStorage에 저장해줘"

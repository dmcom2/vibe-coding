핵심 기술 개념 미리보기

사내 지식베이스 시스템 구축에 필수적인 4가지 기술 키워드

📌 Accordion UI

클릭된 아이템의 식별자(`openFaqId`)를 추적하여 해당 답변 카드만 펼치고 화살표 아이콘을 회전시키는 토글 기법

📌 event.stopPropagation()

"도움이 되었어요" 추천 버튼 클릭 시 상위 아코디언 토글 이벤트가 동시에 발생하는 부작용(이벤트 버블링)을 막는 메서드

📌 Counter Analytics

FAQ가 펼쳐질 때마다 `views`(조회수) 카운트를 1씩 올리고 추천 클릭 시 `likes` 수치를 올리는 카운터 로직

📌 JSON Import/Export

사내 구축된 전체 FAQ 항목을 .json 파일로 백업하여 신규 부서나 타 인트라넷 시스템에 손쉽게 대량 이관하는 기능

// 1. 아코디언 토글 및 조회수 카운트 function toggleAccordion(id) { if (openFaqId === id) { openFaqId = null; // 이미 열려있으면 닫기 } else { openFaqId = id; const item = faqs.find(f => f.id === id); if (item) item.views += 1; // 조회수 증가 } saveState(); } // 2. 추천 버튼 클릭 (버블링 차단 필수) function likeFaq(e, id) { e.stopPropagation(); // 상위 아코디언 닫힘 방지! const item = faqs.find(f => f.id === id); if (item) {{ item.likes += 1; saveState(); }} }

아코디언 제어 3단계

① 열림 상태 식별

openFaqId 변수로 현재 펼쳐진 FAQ 단 1개의 ID를 관리합니다.

② 클래스 토글 (CSS)

openFaqId === item.id 조건 시 .open 클래스를 부여하여 답변을 노출합니다.

③ event.stopPropagation()

추천 버튼을 누를 때 질문 상자가 접히지 않도록 이벤트 전파를 차단합니다.

프롬프트 해설 — 왜 효과적인가?

실무 지식 관리 도구 구축을 위한 요구사항 패턴

✅ POINT 1: 인터랙티브 아코디언 UX 요구

수많은 사내 지식을 한눈에 탐색할 수 있도록 접히고 펼쳐지는 아코디언 UI 구조를 명확히 정의했습니다.

✅ POINT 2: 사용자 반응 카운터(조회수/추천)

자주 찾는 질문과 도움이 된 지식을 수치화(views/likes)하여 사내 지식의 유용성을 평가할 수 있게 했습니다.

✅ POINT 3: 지식 이관을 위한 JSON 백업/복원

인사/IT 규정 변경 시 전체 FAQ를 파일로 다운로드받아 팀원에게 이관 공유 가능하도록 구성했습니다.

✅ POINT 4: 3개 파일 모듈 분리

HTML, CSS, JS 구조 분리로 실무 유지보수성을 극대화했습니다.

📂 "추천 버튼을 눌렀는데 아코디언이 접혀요"

추천 버튼 이벤트 함수에서 e.stopPropagation()이 상위 클릭 이벤트를 제대로 차단하고 있는지 확인하세요.

💾 "새로고침하면 조회수가 리셋돼요"

📁 "JSON 백업 파일 복원이 안 돼요"

복원하려는 JSON 파일 구조가 FAQ 객체 배열(`[...]`) 형태로 정상 저장되어 있는지 확인하세요.

🎨 "아이콘이 안 보이거나 모달이 안 떠요"

index.html 상단에 Bootstrap Icons CDN 및 style.css 경로 연결 상태를 체크하세요.

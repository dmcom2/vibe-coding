핵심 기술 개념 미리보기

실무 재무 시스템 개발에 활용되는 4가지 필수 기술 키워드

📌 Array.reduce() 연산

부서별 지출 배열의 금액 속성을 누적 합산하여 총 집행 금액과 집행률(%)을 집계하는 자바스크립트 배열 메서드

📌 KPI Progress Bar

(사용 금액 / 목표 예산) 비율을 계산하여 시각적 프로그레스 바의 너비(width %)를 동적으로 변경하는 UI 기법

📌 Cross Filtering

검색어, 부서 드롭다운, 비목(카테고리) 드롭다운을 결합하여 조건에 맞는 정산 데이터만 테이블에 필터링 노출하는 원리

📌 JSON Import/Export

Blob API를 통해 예산 및 경비 객체를 .json 파일로 다운로드받고 FileReader로 읽어와 복원하는 백업 매커니즘

📊

집행률 연산 및 초과 판별 로직

부서별 예산과 사용 금액을 계산하는 메커니즘

// 부서별 지출 합계 연산 함수 function calculateDeptSpent(deptName) { return expenses .filter(e => e.dept === deptName) .reduce((sum, e) => sum + Number(e.amount), 0); } // 집행률 및 예산 초과 판별 const deptBudget = budgets[deptName]; const deptSpent = calculateDeptSpent(deptName); const usageRate = Math.round((deptSpent / deptBudget) * 100); const isOver = deptSpent > deptBudget; // 초과 여부

예산 상태 처리 3단계

① 지출 합계 집계

filter()로 해당 부서 항목만 추출 후 reduce()로 총 사용 금액 합산

② 사용 비율(%) 산출

총 예산 대비 사용 금액 비율을 연산하고 프로그레스 바 너비로 지정

③ 예산 초과 알림 (Over-budget)

isOver === true 시 빨간색 '초과' 배지를 출력하고 테두리 강조

📦

JSON 백업 / 복원 로직

백업 파일(.json)로 재무 데이터를 백업하고 동기화하는 구조

JS - 백업 (Export) function exportJSON() { const payload = { budgets, expenses, exportedAt: new Date() }; const blob = new Blob([JSON.stringify(payload, null, 2)], { type: 'application/json' }); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = `dept_expense_backup_${new Date().toISOString().slice(0,10)}.json`; a.click(); }
JS - 복원 (Import) function importJSON(event) { const file = event.target.files[0]; const reader = new FileReader(); reader.onload = (e) => { const data = JSON.parse(e.target.result); if (data.budgets && data.expenses) { budgets = data.budgets; expenses = data.expenses; saveState(); // localStorage 저장 후 화면 갱신 } }; reader.readAsText(file); }

자주 막히는 트러블슈팅

실습 중 에러가 발생할 때 체크해야 할 사항

💳 "금액 합계나 집행률이 0%로 나와요"

입력된 금액 값이 문자열(String)로 처리되지 않도록 Number()로 변환 후 reduce() 합산 연산이 실행되는지 확인하세요.

💾 "새로고침하면 등록한 경비가 사라져요"

경비 추가/수정/삭제 제출 시 localStorage.setItem()이 작동하고 있는지 확인하세요.

📁 "JSON 백업 파일 복원이 안 돼요"

복원하려는 JSON 파일 구조에 budgets와 expenses 속성이 올바르게 정의되어 있는지 체크하세요.

🎨 "아이콘이 안 보이거나 모달이 안 떠요"

index.html 상단에 Bootstrap Icons CDN 링크가 연결되어 있는지 및 CSS 파일 연결 상태를 확인하세요.

📌 Chart.js

그래프를 그려주는 차트 라이브러리. 오늘은 도넛 차트와 막대 차트로 수입/지출을 시각화합니다

📌 Canvas

HTML에서 그림을 그릴 수 있는 그리기 영역. Chart.js가 이 위에 차트를 렌더링합니다

📌 배열의 CRUD

거래 내역 배열에 항목을 추가(Create)·조회(Read)·수정(Update)·삭제(Delete)하는 기본 동작

📌 filter / reduce

배열에서 조건에 맞는 항목만 걸러내고(filter), 하나의 값으로 합산(reduce)하는 메서드

📌 카테고리별 합계

식비·교통·문화 등 항목별로 묶어서 지출 금액을 더한 값. 도넛 차트의 데이터가 됩니다

📌 localStorage

브라우저에 데이터를 저장해두는 보관함. 새로고침해도 가계부 내역이 남아있는 이유

Chart.js — CDN으로 차트 그리기

new Chart()로 선언적으로 차트를 생성하고 update()로 갱신

<!-- CDN --> <script src="https://cdn.jsdelivr.net/ npm/chart.js"></script> <canvas id="myChart"></canvas> // 차트 생성 const ctx = document .getElementById('myChart') .getContext('2d'); const chart = new Chart(ctx, { type: 'doughnut', data: { labels: ['식비', '교통', '문화'], datasets: [{ data: [300000, 50000, 80000], backgroundColor: [ '#34d399','#60a5fa','#f472b6' ] }] } }); // 데이터 업데이트 chart.data.datasets[0].data = newData; chart.update();
차트 종류 선택 가이드

• doughnut — 카테고리 비율 (가장 직관적)
• bar — 월별 수입/지출 비교
• line — 시간에 따른 잔액 추이
🔄

chart.update() 중요!

데이터를 직접 수정한 후 반드시 chart.update()를 호출해야 화면에 반영됩니다.

차트를 새로 만들면 메모리 누수 발생 — 항상 update() 사용!

filter + reduce — 데이터 집계

배열 메서드로 월별 필터링과 카테고리별 합계를 한 줄로 계산

JS const records = [ { date: '2025-06-05', category: '식비', amount: -12000 }, { date: '2025-06-10', category: '교통', amount: -3000 }, { date: '2025-06-15', category: '급여', amount: 3000000}, { date: '2025-07-01', category: '식비', amount: -8000 }, ]; // ① 월별 필터 (날짜 문자열이 '2025-06'으로 시작하는 것) const june = records.filter(r => r.date.startsWith('2025-06') ); // ② 지출 합계 (음수만 필터 후 절댓값 합산) const totalExpense = june .filter(r => r.amount < 0) .reduce((sum, r) => sum + Math.abs(r.amount), 0); // ③ 수입 합계 const totalIncome = june .filter(r => r.amount > 0) .reduce((sum, r) => sum + r.amount, 0); // ④ 카테고리별 집계 (객체 누산) const byCategory = june.reduce((acc, r) => { acc[r.category] = (acc[r.category] || 0) + Math.abs(r.amount); return acc; }, {}); // → { '식비': 12000, '교통': 3000, '급여': 3000000 }

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

기능을 섹션별로 구조화

"상단 헤더:", "입력 폼:", "내역 목록:", "차트 (2개):", "기타:" 처럼 기능을 섹션으로 나눠 요청하면 AI가 항목을 빠짐없이 구현합니다. 나열식보다 섹션 구분이 훨씬 정확합니다.

✅ POINT 2

라이브러리 이름을 직접 명시

"Chart.js CDN"처럼 라이브러리 이름과 로딩 방식을 정확히 적으면 AI가 추가 검색 없이 즉시 적용합니다. "그래프 라이브러리 써줘"보다 훨씬 일관된 결과가 나옵니다.

✅ POINT 3

파일 구조를 명령으로 지정

"index.html, style.css, script.js 3개로 나눠서"라고 파일 구조를 명시하면 실제 프로젝트 수준의 유지보수 가능한 코드로 분리됩니다. 지정하지 않으면 모든 코드가 한 파일에 뭉칩니다.

✅ POINT 4

UX 세부사항까지 명시

키보드 단축키(Alt+←/→), 빠른 금액 버튼(+1만·+3만), 커스텀 확인 다이얼로그처럼 상호작용 세부사항을 적을수록 완성도 높은 앱이 나옵니다. 기능 이름만으로 충분하지 않습니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"가계부 만들어줘"
→ 단일 파일, 차트 없음, 기능이 들쑥날쑥
✅ 구체적인 요청
"Chart.js CDN, 섹션별 기능 목록, 3파일 분리, 단축키, 한국어 주석"
→ 한 번에 원하는 결과

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

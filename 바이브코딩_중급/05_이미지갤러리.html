오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 File 객체

input[type=file]로 선택한 파일 하나하나의 이름·크기·타입 정보를 담은 객체

📌 FileReader

파일을 읽어서 브라우저 안에서 사용할 수 있는 데이터로 변환해주는 내장 객체

📌 readAsDataURL (Base64)

이미지를 data:image/...;base64,... 문자열로 변환. <img src="">에 바로 사용 가능

📌 모달(Modal)

화면 위에 떠서 배경을 덮는 팝업 창. 라이트박스의 기반 구조

📌 라이트박스

이미지를 클릭하면 전체화면으로 크게 보여주는 뷰어 UI 패턴

📌 QuotaExceededError

localStorage 저장 용량(약 5MB)을 초과했을 때 발생하는 예외

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

다중 파일 업로드 & Base64 변환

input[multiple]로 여러 파일을 선택하고 readAsDataURL로 Base64 인코딩

<!-- multiple 속성으로 여러 파일 선택 --> <input type="file" accept="image/*" multiple id="fileInput" /> // FileList → 배열로 변환 후 반복 function handleFiles(files) { Array.from(files).forEach(file => { const reader = new FileReader(); reader.addEventListener('load', e => { const dataURL = e.target.result; // "data:image/png;base64,iVBORw0..." const img = { id: Date.now() + Math.random(), src: dataURL, // Base64 데이터 title: file.name, added: new Date().toLocaleDateString() }; images.push(img); saveAndRender(); }); reader.readAsDataURL(file); // Base64 변환 }); }
readAsText vs readAsDataURL

• readAsText — 텍스트 파일 (CSV, TXT)
→ 결과: "이름,나이,점수..."

• readAsDataURL — 이미지/바이너리
→ 결과: "data:image/png;base64,..."

<img src="data:image/..."/>처럼 바로 사용 가능!
⚠️

용량 주의!

localStorage는 보통 5MB 제한. 이미지를 Base64로 저장하면 용량이 커집니다. QuotaExceededError 예외 처리 필수!

라이트박스 모달 & 키보드 네비게이션

이미지 클릭 → 전체화면 모달, 키보드로 이전/다음 이동

let currentIdx = 0; function openModal(idx) { currentIdx = idx; const img = images[idx]; document.getElementById('modalImg').src = img.src; const modal = document.getElementById('modal'); modal.style.display = 'flex'; // 스크롤 방지 document.body.style.overflow = 'hidden'; } function closeModal() { document.getElementById('modal') .style.display = 'none'; document.body.style.overflow = ''; } // 키보드 이벤트 document.addEventListener('keydown', e => { if (e.key === 'ArrowRight') openModal((currentIdx + 1) % images.length); if (e.key === 'ArrowLeft') openModal((currentIdx - 1 + images.length) % images.length); if (e.key === 'Escape') closeModal(); });

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

기능을 카테고리로 구조화

"업로드 · 갤러리 UI · 라이트박스 · 기타"처럼 영역별로 나눠 요청하면 AI가 각 기능을 빠뜨리지 않고 전체 범위를 한 번에 구현합니다.

✅ POINT 2

구체적인 수치로 판단 여지 제거

"최대 1600px 리사이즈", "최대 20장 제한"처럼 숫자를 명시하면 AI가 임의로 결정하지 않아 수정 요청 없이 한 번에 원하는 결과가 나옵니다.

✅ POINT 3

엣지 케이스를 선제로 지정

"GIF는 원본 유지", "localStorage 용량 초과 예외 처리"처럼 특수 상황을 미리 적어두면 AI가 처음부터 예외를 처리해 나중에 오류가 생기지 않습니다.

✅ POINT 4

출력 형식을 명확히 지정

"index.html · style.css · script.js 3개로 나눠서, 한국어 주석 달아줘"처럼 결과물 형태를 지정하면 AI가 의도한 구조 그대로 파일을 만들어 줍니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"이미지 갤러리 만들어줘"
→ 단일 파일, 저장 없음, 기능 제각각
✅ 구체적인 요청
"Base64로 최대 20장 저장, GIF 원본 유지, 3개 파일로 분리"
→ 한 번에 원하는 결과

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

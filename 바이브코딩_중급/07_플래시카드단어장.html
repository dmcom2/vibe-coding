오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 perspective

3D 공간의 원근감(카메라 거리)을 설정하는 CSS 속성. 부모 요소에 적용

📌 rotateY()

Y축을 기준으로 요소를 회전시키는 3D transform 함수. 180deg면 완전히 뒤집힘

📌 backface-visibility

요소가 뒤집혔을 때 뒷면을 숨길지 결정하는 속성 (hidden 필수)

📌 배열 셔플

카드 순서를 무작위로 섞는 Fisher-Yates 등의 대표적인 알고리즘

📌 가중치(weight)

틀린 카드일수록 더 자주 출제되도록 부여하는 점수

📌 간격 반복(Spaced Repetition)

오답은 자주, 정답은 드물게 복습하는 학습 이론. Anki·Duolingo도 사용

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

3D CSS 뒤집기 — CSS 속성 4가지

perspective + transform-style + rotateY + backface-visibility 조합

/* 1. 부모: 원근감 설정 (필수!) */ .card-container { perspective: 1000px; /* 3D 깊이감 */ } /* 2. 내부: 3D 공간 보존 */ .card-inner { transform-style: preserve-3d; transition: transform .6s ease; } /* 3. 뒤집힌 상태 */ .card-inner.flipped { transform: rotateY(180deg); } /* 4. 앞/뒤면 겹치기 */ .card-front, .card-back { position: absolute; inset: 0; backface-visibility: hidden; /* 뒤집힐 때 숨김 */ } /* 5. 뒷면 초기 회전 (180도 미리 돌려둠) */ .card-back { transform: rotateY(180deg); }

가중치 학습 알고리즘

맞춘 단어는 덜 나오고, 틀린 단어는 자주 나오는 스마트 학습

// 각 단어에 가중치(weight) 속성 추가 const words = [ { front:'Apple', back:'사과', weight: 3 }, { front:'Banana', back:'바나나', weight: 1 }, ]; // 가중치에 비례하는 카드 풀(pool) 생성 function buildPool() { const pool = []; words.forEach(w => { // weight만큼 배열에 반복 추가 for (let i = 0; i < w.weight; i++) { pool.push(w); } }); return pool; } // pool = [Apple,Apple,Apple, Banana] // → Apple이 3배 더 자주 출제됨 // 정답/오답 시 가중치 조정 function onCorrect(word) { word.weight = Math.max(1, word.weight - 1); } function onWrong(word) { word.weight = Math.min(5, word.weight + 2); }

가중치 1 (거의 완벽)

Pool에서 1번 등장 → 드물게 출제

가중치 3 (기본)

Pool에서 3번 등장 → 보통 빈도

가중치 5 (자주 틀림)

Pool에서 5번 등장 → 자주 출제

💡 이 알고리즘을 "간격 반복(Spaced Repetition)"이라고 합니다. Anki, Duolingo도 유사한 방식 사용!

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

결과 중심으로 기술하기

"타이머 모드 토글: 체크 시 10초 카운트다운 바 표시, 시간 초과 시 자동 몰라요 처리"처럼 UI 동작을 직접 묘사해 AI 해석 여지를 없앴습니다.

✅ POINT 2

탭·섹션별로 기능 분류하기

[학습 탭] / [카드 관리 탭]으로 구역을 나눠 기술해 전체 레이아웃을 AI가 명확히 구조화할 수 있게 했습니다.

✅ POINT 3

구현 힌트를 함께 제공하기

"localStorage 저장", "JSON 내보내기/가져오기", "이미지 업로드 시 320px 자동 압축"처럼 기술 방법을 명시해 AI가 올바른 구현을 선택했습니다.

✅ POINT 4

파일 구조와 품질 기준 명시하기

"파일은 index.html, style.css, script.js 3개로 나눠서, 코드에 한국어 주석"처럼 결과물 형태와 품질 기준을 미리 못 박았습니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"단어 공부 앱 만들어줘"
→ 어떤 단어인지, 어떤 기능인지 AI가 마음대로 결정
✅ 구체적인 요청

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

카드 큐(Queue) 관리

다음 카드를 결정하는 shift/push 패턴

// 학습 세션 초기화 let cardQueue = buildPool(); // 가중치 기반 풀 생성 shuffle(cardQueue); // Fisher-Yates 섞기 function nextCard() { // 앞에서 꺼내기 const card = cardQueue.shift(); if (!card) { // 큐가 비면 세션 완료 showResult(); return; } showCard(card); } function onWrong(card) { card.weight = Math.min(5, card.weight + 2); // 틀린 카드는 큐 뒤에 다시 추가! cardQueue.push(card); saveAndNext(); } function onCorrect(card) { card.weight = Math.max(1, card.weight - 1); // 맞춘 카드는 그냥 다음으로 saveAndNext(); }

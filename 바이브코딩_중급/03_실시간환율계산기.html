오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 fetch

브라우저에 내장된 서버 요청 함수. fetch(URL) 한 줄로 외부 API를 호출합니다

📌 async / await

시간이 걸리는 작업(요청)을 순서대로 기다리며 코드를 자연스럽게 작성하는 문법

📌 Promise

비동기 작업의 결과를 나중에 알려주겠다는 약속 객체. fetch()가 반환하는 값

📌 JSON

서버와 데이터를 주고받는 표준 텍스트 형식. response.json()으로 객체로 변환합니다

📌 API

다른 프로그램(서버)이 제공하는 기능 사용 창구. 오늘은 환율 데이터를 제공하는 API를 씁니다

📌 fallback 데이터

API 호출이 실패했을 때 대신 사용할 미리 준비해둔 예비 데이터

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!
🌐

fetch API — 비동기 HTTP 요청

서버에서 데이터를 가져오는 현대적인 방법

// 예전 방식 (콜백 지옥) $.ajax({ url: ..., success: function(data) { $.ajax({ url: ..., success: function(data2) { // 점점 깊어지는 콜백... }}); }}); // 현대적 방식: async/await async function fetchRates() { try { // await: Promise가 완료될 때까지 대기 const response = await fetch( 'https://api.exchangerate-api.com /v4/latest/KRW' ); // JSON 파싱도 비동기 const data = await response.json(); // data.rates = { USD: 0.00072, EUR: ... } updateUI(data.rates); } catch (error) { // 네트워크 오류 처리 useFallbackRates(); } }

JSON.parse(cached).rates : FALLBACK_RATES; showStatus('캐시/기본 환율 (오프라인)', 'orange'); } }

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

목적 선언이 먼저다

"실시간 환율 계산기를 만들어줘"처럼 무엇을 만들지 첫 줄에 한 문장으로 선언하면 AI가 전체 방향을 잡고 세부 기능을 배치합니다.

✅ POINT 2

데이터 소스와 예외를 함께 지정

API URL과 "실패 시 예비 데이터로 자동 전환"을 같이 적으면 AI가 try/catch 폴백 패턴을 자동으로 작성합니다. 빠트리면 오류 처리 없는 코드가 나옵니다.

✅ POINT 3

레이아웃을 위치어로 설명

"상단 · 중앙 · 하단"처럼 위치어로 UI 영역을 구분하면 AI가 HTML 구조를 그대로 반영합니다. 기능 목록만 나열하면 배치가 제각각이 됩니다.

✅ POINT 4

파일 구조까지 지시

"index.html, style.css, script.js 3개로 나눠줘"처럼 출력 형태까지 지정하면 수정·유지관리하기 쉬운 코드를 한 번에 얻습니다.

🆚 막연한 요청 vs 이 프롬프트의 차이

❌ 막연한 요청
"환율 계산기 만들어줘"
→ 단순 HTML 한 파일, 오류 처리 없이 결과가 제각각
✅ 구체적인 요청
"fetch + 폴백 + 상태 뱃지 + 파일 3개로 분리"
→ 한 번에 완성도 높은 결과

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

역산 환율 변환

USD → KRW 변환 시 역수를 사용하는 수학적 구조

// API: KRW 기준 환율 (1원 = n달러) // data.rates = { USD: 0.00072 } → 1원 = 0.00072달러 // 원화 → 달러: 곱하기 function krwToUsd(krw) { return krw * rates.USD; // 10000 * 0.00072 = 7.2 } // 달러 → 원화: 역수 (나누기) function usdToKrw(usd) { return usd / rates.USD; // 7.2 / 0.00072 = 10000 } // 범용 변환 함수 (from-to 모두 처리) function convert(amount, fromCurrency, toCurrency) { // 먼저 KRW로 변환 const krw = fromCurrency === 'KRW' ? amount : amount / rates[fromCurrency]; // KRW에서 목적 통화로 변환 return toCurrency === 'KRW' ? krw : krw * rates[toCurrency]; }

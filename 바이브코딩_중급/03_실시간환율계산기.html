시작 전 준비물 체크

오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 fetch

브라우저에 내장된 서버 요청 함수. fetch(URL) 한 줄로 외부 API를 호출합니다

📌 async / await

시간이 걸리는 작업(요청)을 순서대로 기다리며 코드를 자연스럽게 작성하는 문법

📌 Promise

비동기 작업의 결과를 나중에 알려주겠다는 약속 객체. fetch()가 반환하는 값

📌 JSON

서버와 데이터를 주고받는 표준 텍스트 형식. response.json()으로 객체로 변환합니다

📌 API

다른 프로그램(서버)이 제공하는 기능 사용 창구. 오늘은 환율 데이터를 제공하는 API를 씁니다

📌 fallback 데이터

API 호출이 실패했을 때 대신 사용할 미리 준비해둔 예비 데이터

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!
🌐

fetch API — 비동기 HTTP 요청

서버에서 데이터를 가져오는 현대적인 방법

// 예전 방식 (콜백 지옥) $.ajax({ url: ..., success: function(data) { $.ajax({ url: ..., success: function(data2) { // 점점 깊어지는 콜백... }}); }}); // 현대적 방식: async/await async function fetchRates() { try { // await: Promise가 완료될 때까지 대기 const response = await fetch( 'https://api.exchangerate-api.com /v4/latest/KRW' ); // JSON 파싱도 비동기 const data = await response.json(); // data.rates = { USD: 0.00072, EUR: ... } updateUI(data.rates); } catch (error) { // 네트워크 오류 처리 useFallbackRates(); } }
1

fetch(URL) 호출

HTTP 요청을 보내고 Promise 반환

2

await response 대기

응답이 올 때까지 기다림 (브라우저는 멈추지 않음)

3

response.json() 파싱

텍스트 → 자바스크립트 객체

4

UI 업데이트

받아온 데이터로 화면 갱신

try/catch & 폴백 패턴

API가 실패해도 앱이 동작하도록 방어 코드 작성

JS // 폴백 데이터 (API 실패시 사용) const FALLBACK_RATES = { USD: 0.00072, EUR: 0.00067, JPY: 0.109, GBP: 0.00057 }; async function loadRates() { try { const res = await fetch(API_URL); // HTTP 오류 체크 (404, 500 등) if (!res.ok) throw new Error('API 오류'); const data = await res.json(); rates = data.rates; // 성공 → localStorage에 캐시 저장 localStorage.setItem('cachedRates', JSON.stringify({ rates, time: Date.now() })); showStatus('실시간 환율', 'green'); } catch (err) { // 실패 → 캐시 확인 → 없으면 하드코딩 사용 const cached = localStorage.getItem('cachedRates'); rates = cached ? JSON.parse(cached).rates : FALLBACK_RATES; showStatus('캐시/기본 환율 (오프라인)', 'orange'); } }

AI에게 말 거는 법 — 프롬프트 3단 구조

중급도 원리는 같습니다. 다만 "파일을 나눠달라"는 조건이 하나 추가됩니다

①
무엇을 "실시간 환율 계산기를 만들어줘"
만들 것을 한 문장으로. 첫 줄이 가장 중요합니다
②
기능/라이브러리 "fetch로 환율 API 호출, 실패 시 예비 데이터 사용"
필요한 기능과 외부 API를 목록으로 나열합니다
③
조건/파일 구조 "index.html, style.css, script.js 3개로 나눠줘"
중급부터는 파일을 나눠달라는 조건을 꼭 넣어야 관리가 편합니다
💡 API 이름이 기억 안 나도 괜찮습니다. "실시간 환율을 가져오는 무료 API 써줘"처럼 말로 설명해도 AI가 적절한 API를 골라줍니다.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

역산 환율 변환

USD → KRW 변환 시 역수를 사용하는 수학적 구조

// API: KRW 기준 환율 (1원 = n달러) // data.rates = { USD: 0.00072 } → 1원 = 0.00072달러 // 원화 → 달러: 곱하기 function krwToUsd(krw) { return krw * rates.USD; // 10000 * 0.00072 = 7.2 } // 달러 → 원화: 역수 (나누기) function usdToKrw(usd) { return usd / rates.USD; // 7.2 / 0.00072 = 10000 } // 범용 변환 함수 (from-to 모두 처리) function convert(amount, fromCurrency, toCurrency) { // 먼저 KRW로 변환 const krw = fromCurrency === 'KRW' ? amount : amount / rates[fromCurrency]; // KRW에서 목적 통화로 변환 return toCurrency === 'KRW' ? krw : krw * rates[toCurrency]; }

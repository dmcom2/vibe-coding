핵심 기술 개념 미리보기

실무 응답 자동화 시스템에 활용되는 4가지 필수 기술 키워드

📌 String.replace() & Regex

정규표현식 /\{([^}]+)\}/g 패턴으로 본문 내 {변수명}을 찾아 사용자가 입력한 값으로 치환하는 핵심 로직

📌 Clipboard API

navigator.clipboard.writeText()를 호출하여 생성된 메일/문자 문구를 원클릭으로 클립보드에 바로 복사하는 기능

📌 Dynamic Form Building

선택된 템플릿의 변수 목록을 추출하여, 필요한 입력 필드(input)만을 화면에 동적으로 만들어내는 DOM 생성 기법

📌 JSON Import/Export

팀 공용 메일 템플릿 모음을 .json 파일로 저장하여 공유하거나 불러와 복원하는 파일 입출력 로직

🔤

실시간 변수 치환 로직

본문의 플레이스홀더를 동적 입력값으로 바꾸는 구조

// 1. 본문에서 {변수명} 추출 const matches = tpl.body.match(/\{([^}]+)\}/g) || []; const uniqueVars = [...new Set(matches.map(m => m.slice(1, -1)))]; // 2. 변수값을 본문에 대입하여 최종 문구 생성 let result = tpl.body; uniqueVars.forEach(varName => { const val = variableValues[varName] || `{${varName}}`; const regex = new RegExp(`\\{${varName}\\}`, 'g'); result = result.replace(regex, val); });

치환 처리 3단계

① 변수 패턴 탐색

중괄호로 둘러싸인 {변수명} 패턴을 정규식으로 자동 추출합니다.

② 동적 입력 폼 생성

추출된 변수 개수만큼 왼쪽 패널에 입력 창(Input)을 실시간 생성합니다.

③ 실시간 바인딩 & 렌더링

키 입력 시 마다 replace() 함수가 동작하여 오른쪽 본문이 즉시 교체됩니다.

📦

JSON 백업 / 복원 로직

사내 팀원 간 템플릿 모음을 공유하는 파일 매커니즘

JS - 백업 (Export) function exportJSON() { const blob = new Blob([JSON.stringify(templates, null, 2)], { type: 'application/json' }); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = `email_templates_backup_${new Date().toISOString().slice(0,10)}.json`; a.click(); }
JS - 복원 (Import) function importJSON(e) { const file = e.target.files[0]; const reader = new FileReader(); reader.onload = (evt) => { const data = JSON.parse(evt.target.result); if (Array.isArray(data)) { templates = data; saveState(); // 로컬스토리지 저장 후 화면 갱신 } }; reader.readAsText(file); }

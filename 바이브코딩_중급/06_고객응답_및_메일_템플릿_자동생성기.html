핵심 기술 개념 미리보기

실무 응답 자동화 시스템에 활용되는 4가지 필수 기술 키워드

📌 String.replace() & Regex

정규표현식 /\{([^}]+)\}/g 패턴으로 본문 내 {변수명}을 찾아 사용자가 입력한 값으로 치환하는 핵심 로직

📌 Clipboard API

navigator.clipboard.writeText()를 호출하여 생성된 메일/문자 문구를 원클릭으로 클립보드에 바로 복사하는 기능

🤖 Gemini API + fetch

fetch()로 Gemini REST API에 POST 요청을 보내 AI 답변을 받아오는 비동기 통신 구조. 이번 수업의 핵심 신기술

📌 JSON Import/Export

팀 공용 메일 템플릿 모음을 .json 파일로 저장하여 공유하거나 불러와 복원하는 파일 입출력 로직

🔤

실시간 변수 치환 로직

본문의 플레이스홀더를 동적 입력값으로 바꾸는 구조

// 1. 본문에서 {변수명} 추출 const matches = tpl.body.match(/\{([^}]+)\}/g) || []; const uniqueVars = [...new Set(matches.map(m => m.slice(1, -1)))]; // 2. 변수값을 본문에 대입하여 최종 문구 생성 let result = tpl.body; uniqueVars.forEach(varName => { const val = variableValues[varName] || `{${varName}}`; const regex = new RegExp(`\\{${varName}\\}`, 'g'); result = result.replace(regex, val); });

치환 처리 3단계

① 변수 패턴 탐색

중괄호로 둘러싸인 {변수명} 패턴을 정규식으로 자동 추출합니다.

② 동적 입력 폼 생성

추출된 변수 개수만큼 왼쪽 패널에 입력 창(Input)을 실시간 생성합니다.

③ 실시간 바인딩 & 렌더링

키 입력 시 마다 replace() 함수가 동작하여 오른쪽 본문이 즉시 교체됩니다.

📦

JSON 백업 / 복원 로직

사내 팀원 간 템플릿 모음을 공유하는 파일 매커니즘

JS - 백업 (Export) function exportJSON() { const blob = new Blob([JSON.stringify(templates, null, 2)], { type: 'application/json' }); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = `email_templates_backup_${new Date().toISOString().slice(0,10)}.json`; a.click(); }
JS - 복원 (Import) function importJSON(e) { const file = e.target.files[0]; const reader = new FileReader(); reader.onload = (evt) => { const data = JSON.parse(evt.target.result); if (Array.isArray(data)) { templates = data; saveState(); // 로컬스토리지 저장 후 화면 갱신 } }; reader.readAsText(file); }

API란 무엇인가?

Gemini를 코드로 호출하기 전에 꼭 알아야 할 개념

API = Application Programming Interface
두 프로그램이 서로 대화하는 규격화된 창구
우리 앱 (브라우저) → Gemini API 서버 → AI 모델
"문의 내용 분석해서 답변 메일 써줘"
우리 앱 ← Gemini API 서버 ← AI 모델
"네, 작성했습니다. (답변 텍스트)"

식당으로 이해하기

1

손님 (우리 앱)

주문서(Request)를 작성하여 웨이터에게 전달합니다.

2

웨이터 (API)

정해진 형식으로 주방에 전달하고, 결과를 가져다 줍니다.

3

주방 (AI 모델)

요리(Response)를 만들어 웨이터에게 줍니다.

4

🔑 API 키

우리가 진짜 손님인지 확인하는 회원 카드. 없으면 주문을 받아주지 않습니다.

Gemini API 통신 흐름 상세

코드가 AI와 주고받는 내용을 JSON으로 이해하기

▼ 전송하는 내용 (Request)

// POST 요청 URL https://generativelanguage.googleapis.com/ v1beta/models/{모델ID} :generateContent?key=AIzaSy... // 모델 ID 예: gemini-2.5-flash-lite // AI Studio에서 직접 확인한 ID를 넣으세요 // 전송하는 JSON Body { "contents": [{ "parts": [{ "text": "당신은 메일 작성 어시스턴트입니다.\n어조: 정중한 비즈니스\n\n고객문의:\n배송이 언제 되나요?" }] }], "generationConfig": { "temperature": 0.7, "maxOutputTokens": 1024 } }

▲ 받는 내용 (Response)

// Gemini가 반환하는 JSON { "candidates": [{ "content": { "parts": [{ "text": "안녕하세요 고객님,\n문의해 주셔서 감사합니다.\n..." // ↑ 이 text가 우리가 원하는 AI 답변 }] } }] } // 답변 텍스트 추출 코드 const text = data.candidates[0] .content .parts[0] .text;
앱에서 [▼ 전송 Request] / [▲ 수신 Response] 탭을 클릭하면
실제 주고받는 JSON을 직접 눈으로 확인할 수 있습니다.

Gemini API 연결 구조 완전 해설

URL · 요청 · 응답 · 코드까지 한 눈에 이해하기

① ENDPOINT URL — 요청 주소

https://generativelanguage.googleapis.com/
v1beta/models/{MODEL}:generateContent
?key={API_KEY}
  • {MODEL} — 사용할 모델 ID (예: gemini-3.5-flash-lite)
  • ?key= — API 키를 URL 뒤에 붙여 인증
  • :generateContent — "콘텐츠 생성" 요청 메서드

② HTTP 방식 & 헤더

POST
Content-Type:
application/json
POST = 데이터를 서버로 전송해 결과를 받아오는 방식
Content-Type = "나는 JSON을 보냅니다" 라고 서버에 알려주는 헤더

③ REQUEST BODY — 전송하는 JSON

// 전송 데이터 구조 { "contents": [{ "parts": [{ "text": "프롬프트 내용" }] }], "generationConfig": { "temperature": 0.7 } }

temperature 0.2↓ = 정형 답변(코드·수학) / 0.7~1.0 = 창의적 대화·작문

④ RESPONSE — 받는 JSON과 추출

// Gemini 반환 구조 { "candidates": [{ "content": { "parts": [{ "text": "AI 답변 텍스트" }] } }] } // 답변 추출 data.candidates[0].content.parts[0].text

배열 0번째([0]) = 첫 번째 후보 답변 → parts[0].text가 최종 텍스트

⑤ JavaScript fetch 구현 전체 패턴

async function callGemini(prompt) { const url = `https://.../${MODEL} :generateContent?key=${KEY}`; const res = await fetch(url, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(requestBody) }); const data = await res.json(); return data.candidates[0].content.parts[0].text; }
async/await — 비동기 함수. AI 응답을 기다렸다가 다음 줄 실행
JSON.stringify() — JS 객체를 JSON 문자열로 변환해서 전송
await res.json() — 받은 JSON 문자열을 JS 객체로 다시 변환

JSON 파일 백업/복원으로 팀 공유가 가능하고, HTML·CSS·JS·config 파일 분리로 유지보수성을 확보했습니다.

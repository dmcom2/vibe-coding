오늘 나오는 용어

외우지 마세요 — 눈에 익혀 두기만 하면 됩니다

📌 서버 (Express)

브라우저의 요청을 받아 일지를 읽고 저장해 주는 프로그램. node server.js로 켭니다.

📌 API 주소

/api/logs처럼 서버에 일을 시키는 주소. GET 읽기 · PUT 저장 · DELETE 삭제

📌 upsert (덮어쓰기 저장)

"있으면 고치고, 없으면 만든다". 날짜 + 이름이 같으면 같은 일지 한 장입니다.

📌 409 응답

"지금은 그렇게 할 수 없어요"라는 서버의 거절. 제출된 일지를 또 제출하면 받습니다.

📌 .env 파일

API 키 같은 비밀 값을 코드 밖에 두는 파일. 깃허브에 올리지 않습니다.

📌 SSE 스트리밍

AI 답을 다 기다리지 않고 한 글자씩 흘려보내는 방식. 채팅 AI의 타이핑 효과

🔑

핵심 기술 5가지 — 쉽게 말하면

이 다섯 가지만 이해하면 오늘 앱이 어떻게 움직이는지 보입니다

1

서버가 일지를 보관한다

쉽게 말하면 팀 공용 일지 보관함. 누가 열어도 같은 일지가 보입니다. 브라우저는 fetch('/api/logs?from=…')로 "이 기간 일지 주세요"라고 부탁만 합니다.

2

하루 한 장 — 날짜 + 이름이 열쇠

쉽게 말하면 출근부 한 칸. PUT /api/logs/2026-10-16/홍길동은 그 칸이 비어 있으면 새로 쓰고, 차 있으면 고쳐 씁니다(upsert). 그래서 같은 날 일지가 두 장 생기지 않습니다.

3

작성중 → 제출 → 잠금

쉽게 말하면 결재 올리기. 제출하면 화면 입력이 잠기고, 서버도 다시 제출하려 하면 409로 거절합니다. 고치려면 '제출 취소'로 작성중에 돌려놓습니다.

4

더하고 묶기 — 시간 합계와 분류별 집계

쉽게 말하면 엑셀의 합계 · 피벗. 하루는 시간을 더해 8시간과 비교하고, 한 주는 분류별로 묶어 '운영·지원에 가장 많이 썼다'를 보여줍니다. 날짜는 내 컴퓨터 시간 기준.

5

AI는 서버에서 — 일지 → 주간보고

쉽게 말하면 비서에게 일지 묶음을 건네며 "보고서 초안 써 줘". 키는 서버의 .env에만 두고, 숫자는 서버가 먼저 세어 주고 AI는 문장만 씁니다.

🗂️

일지 한 장 들여다보기 — data/logs.json

서버가 자동으로 만드는 파일은 2개뿐입니다

data/logs.json (배열 중 한 건){ "date": "2026-10-16", "author": "홍길동", // 이 둘이 열쇠 "done": [ // 오늘 한 일 { "text": "보안 점검 결과 보고서 검토", "category": "문서 작성", "hours": 4 }, … ], "plan": ["신규 프로젝트 킥오프 준비", …], // 내일 할 일 "issue": "", "status": "제출", // 작성중 · 제출 "comments": [ { "by", "text", "time" } ], // 미션 4 "createdAt", "updatedAt", "submittedAt" }

기본 프롬프트 해설 — 왜 잘 작동할까?

"AI에게 잘 말하는 법" 네 가지

POINT 1데이터 모양을 먼저 보여준다

일지 한 건의 모양 { date, author, done … }을 적어 주면 AI가 화면 · 서버 · 저장을 모두 같은 모양으로 맞춥니다.

POINT 2규칙은 화면과 서버 둘 다에

"제출하면 잠금"을 화면에만 쓰면 서버는 아무거나 저장합니다. '서버 검사'에 409 · 400 조건을 따로 적었습니다.

POINT 3숫자 기준은 문장으로 못 박는다

"8 미만 주황, 8~10 초록, 10 초과 빨강"처럼 경계를 숫자로 적어야 사람마다 결과가 같아집니다.

POINT 4샘플은 '만드는 규칙'으로 준다

날짜가 오늘 기준으로 바뀌어도 같은 공식이면 지난주 숫자는 언제나 같습니다. 그래서 교재 기대값과 비교할 수 있습니다.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ 화면이 하얗거나 '서버에 연결하지 못했습니다'

터미널에서 node server.js가 켜져 있는지, 주소가 localhost:7823인지 확인. 파일을 더블클릭해서 열면 동작하지 않습니다.

📑 같은 날 일지가 두 장 생겨요

저장이 '추가(push)'만 하고 있습니다. "날짜와 이름이 같으면 고쳐 쓰고, 없을 때만 새로 만들어줘(upsert)"라고 요청하세요.

🔓 제출했는데 또 고쳐져요

화면만 잠갔습니다. "서버에서도 제출된 일지를 다시 제출하면 409로 거절해줘"라고 요청하세요.

📅 오전에 날짜가 하루 밀려요

toISOString()으로 날짜를 만든 경우입니다. "오늘 날짜를 로컬 기준으로 계산하게 고쳐줘"라고 요청하세요.

🔑 AI 버튼을 누르면 키 오류

.env 이름이 GOOGLE_AI_API_KEY인지, 키가 AIza로 시작하는지, 저장 후 서버를 다시 켰는지 확인.

🔣 CSV를 엑셀로 열면 한글 깨짐

파일 맨 앞 BOM이 빠졌습니다. "CSV 맨 앞에 UTF-8 BOM을 붙여줘"라고 요청하세요.

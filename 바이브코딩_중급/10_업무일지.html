오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 날짜 키(dateKey)

'2025-06-01' 형식의 문자열을 객체의 키로 써서 날짜별 일지를 저장/조회하는 방식

📌 배열 filter

배열에서 조건을 만족하는 항목만 골라 새 배열로 만드는 메서드. 검색·기간 필터링에 사용

📌 날짜 범위 비교

문자열로 된 날짜 키를 >= / <= 로 비교해 "이번 주", "이번 달" 같은 기간에 속하는지 판단

📌 템플릿 문자열

백틱( ` )과 ${}으로 변수를 문자열 안에 끼워 넣는 문법. 내보내기 텍스트 조립에 사용

📌 localStorage 목록 관리

날짜별 일지 전체를 하나의 객체로 만들어 브라우저 보관함에 저장/불러오는 방식

📌 debounce 자동저장

타이핑이 멈춘 뒤 일정 시간(1초) 후에만 저장을 실행해 과도한 저장을 방지하는 기법

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

날짜 키 데이터 구조

객체의 키를 날짜 문자열로 사용해서 O(1)로 빠르게 조회

// 날짜 키(YYYY-MM-DD)를 키로 사용하는 객체 const journal = { '2025-06-01': { content: '오전 팀 미팅 진행...', mood: '😊', tags: ['회의', '기획'] }, '2025-06-02': { content: '기능 개발 완료...', mood: '😤', tags: ['개발'] } }; // 오늘 날짜 키 생성 function getTodayKey() { const d = new Date(); return `${d.getFullYear()}-${ String(d.getMonth() + 1).padStart(2, '0') }-${ String(d.getDate()).padStart(2, '0') }`; } // 목록 최신순 정렬 const sorted = Object.keys(journal) .sort((a, b) => b.localeCompare(a)); // 역순
날짜 키 방식의 장점

• 빠른 조회: journal['2025-06-01'] → O(1)
• 중복 걱정 없음: 날짜가 고유 키
• 정렬 쉬움: 문자열 비교 = 날짜 비교
• localStorage 저장 간편: JSON 그대로
journal = {
'2025-06-01': {
content: "업무 내용...",
mood: "😊",
tags: ["회의"] // 배열
},
'2025-06-02': { ... }
}

Blob 텍스트 내보내기

일지 내용을 .txt 파일로 다운로드 — 이미지가 아닌 텍스트 Blob

function exportTxt(dateKey) { const entry = journal[dateKey]; if (!entry) return; // 텍스트 포맷 구성 const text = [ `=== 업무일지 ${dateKey} ===`, ``, `날짜: ${formatDate(dateKey)}`, `기분: ${entry.mood}`, `태그: ${entry.tags.join(', ')}`, ``, `[업무 내용]`, entry.content ].join('\n'); // Blob → URL → 다운로드 const blob = new Blob([text], { type: 'text/plain;charset=utf-8' }); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = `${dateKey}.txt`; a.click(); // 메모리 해제 (중요!) URL.revokeObjectURL(url); }

charset=utf-8 지정 이유

한글 포함 시 반드시 utf-8 명시.
없으면 일부 브라우저에서 깨짐.

revokeObjectURL() 왜 호출?

createObjectURL은 메모리에 임시 URL 생성.
사용 후 revokeObjectURL로 해제해야
메모리 누수 방지.

다른 형식도 같은 방법으로

'text/csv' → CSV 내보내기
'application/json' → JSON 내보내기
'text/html' → HTML 내보내기

AI에게 말 거는 법 — 프롬프트 3단 구조

중급도 원리는 같습니다. 다만 "파일을 나눠달라"는 조건이 하나 추가됩니다

①
무엇을 "업무일지 작성기를 만들어줘"
만들 것을 한 문장으로. 첫 줄이 가장 중요합니다
②
기능/라이브러리 "날짜별 목록, 1초 자동저장, 키워드 검색, TXT 내보내기"
필요한 기능을 목록으로 나열합니다
③
조건/파일 구조 "index.html, style.css, script.js 3개로 나눠줘"
중급부터는 파일을 나눠달라는 조건을 꼭 넣어야 관리가 편합니다
💡 데이터를 어떻게 저장할지 몰라도 괜찮습니다. "날짜별로 구분해서 저장해줘"처럼 말로 설명해도 AI가 날짜 키 구조를 설계해줍니다.

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

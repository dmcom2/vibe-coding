오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 견적서 (Quotation)

고객에게 제품/서비스의 예상 가격을 제안하는 문서. 품목·수량·단가·합계로 구성됩니다

📌 부가가치세 (VAT)

국내 거래에서 소계 금액의 10%를 더해 청구하는 세금. 견적서·세금계산서의 필수 항목

📌 html2canvas

화면의 특정 DOM 영역을 이미지(캔버스)로 캡처해주는 라이브러리. 문서를 PNG로 저장할 때 사용

📌 localStorage

브라우저에 데이터를 저장하는 공간. 작성한 견적서 목록을 새로고침해도 유지되게 해줍니다

📌 소계 / 총합계 / 할인

소계는 품목 금액의 합, 할인은 소계 × 할인율%, 총합계는 (소계−할인) + 부가세

📌 Blob / FileReader

Blob은 파일 데이터 덩어리. FileReader는 사용자가 선택한 파일을 읽어오는 API. JSON 내보내기·가져오기에 사용

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!
🧮

자동 합계 계산 로직

수량 × 단가 → 소계 → 부가세 10% → 총합계로 이어지는 계산 흐름

// ① 행별 금액 계산 (수량 × 단가) function recalcRow(inputEl) { const tr = inputEl.closest('tr'); const qty = Number(tr.querySelector('.f-qty').value); const price = Number(tr.querySelector('.f-price').value); tr.querySelector('.row-amount').textContent = formatWon(qty * price); recalcTotals(); } // ② 전체 합계 계산 function recalcTotals() { let subtotal = 0; document.querySelectorAll('#item-rows tr') .forEach(tr => { subtotal += qty * price; // 모든 행 합산 }); const vat = Math.round(subtotal * 0.1); // 부가세 10% const grand = subtotal + vat; // 총 합계 }

계산 흐름 미리보기

×

=
6,000,000원

왜 이렇게 나누나요?
행이 추가/삭제되거나 수량·단가가 바뀔 때마다 recalcTotals()가 전체를 다시 훑어서 합산하기 때문에, 몇 개를 고쳐도 합계가 항상 정확합니다.

견적번호 자동 생성 & 저장 구조

날짜 기반으로 겹치지 않는 견적번호를 스스로 만들어냅니다

// 오늘 날짜 + 순번으로 견적번호 생성 function generateQuoteNo() { const d = new Date(); const ymd = `${d.getFullYear()}${...}${...}`; // 오늘 날짜별로 순번을 따로 센다 const seqKey = 'quote_seq_' + ymd; const seq = (Number(localStorage.getItem(seqKey)) || 0) + 1; localStorage.setItem(seqKey, seq); return `Q-${ymd}-${String(seq).padStart(3,'0')}`; } // 예: Q-20260731-001, 다음 견적은 Q-20260731-002 // 저장할 때는 localStorage에 배열로 누적 savedQuotes.unshift(quote); localStorage.setItem( 'quotes', JSON.stringify(savedQuotes) );

같은 날 작성한 견적서 번호

Q-20260731-001
Q-20260731-002
Q-20260731-003
핵심 아이디어
날짜별로 순번을 별도의 키(quote_seq_20260731)에 저장하기 때문에, 날짜가 바뀌면 순번이 001부터 다시 시작합니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

✅ POINT 1

원하는 형식을 예시로 보여준다

"Q-날짜-순번 형식"처럼 출력 포맷을 직접 예시로 제시하면 AI가 해석할 여지 없이 정확히 구현합니다. "자동 생성해줘"보다 훨씬 강력합니다.

✅ POINT 2

쓸 라이브러리를 직접 지정한다

html2canvas, jsPDF처럼 라이브러리 이름을 명시하면 AI가 다른 도구를 임의로 선택하지 않습니다. 모르면 "이미지 캡처용 유명 JS 라이브러리"처럼 용도로 설명해도 됩니다.

✅ POINT 3

파일 구조와 코드 스타일을 못 박는다

"index.html, style.css, script.js 3개로 나눠줘"와 "한국어 주석 달아줘"처럼 결과물의 구조·형식을 지시하면 수정·유지 보수가 훨씬 편한 코드를 받을 수 있습니다.

✅ POINT 4

이모지 목록으로 기능을 하나씩 끊는다

💾 저장, 📄 PDF, 🖼️ 이미지처럼 이모지+짧은 라벨로 나열하면 AI가 각각을 독립 기능으로 인식해 빠짐없이 구현합니다. 긴 문단으로 쓰면 일부 기능을 빠트릴 수 있습니다.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

🖼️ "이미지 저장 버튼을 눌러도 반응이 없어요"

html2canvas는 CDN(인터넷 연결)이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

이미지 저장 & 인쇄 코드

이미지 저장 대신 PDF 파일로 다운로드되도록 변경합니다. jsPDF + html2canvas를 함께 사용합니다.

jsPDF 라이브러리를 추가해서
견적서를 A4 크기 PDF로 다운로드해줘.
파일명은 견적번호.pdf로 해줘.
⭐⭐

미션 2
이메일 본문 자동 생성

고객 이름·품목 목록·총합계를 읽어 이메일 제목과 본문 초안을 자동으로 채워줍니다.

이메일 초안 버튼을 누르면
고객명·품목·총액이 담긴
이메일 제목+본문을 자동 생성해줘.
모달로 보여주고 복사 버튼도 넣어줘.
⭐⭐⭐

미션 3
다중 견적서 비교

저장 목록에서 2개를 선택하면 각 항목의 금액 차이를 나란히 보여주는 비교 모달을 만듭니다.

저장 목록에서 2개를 선택해서
비교 버튼을 누르면
소계·부가세·총합계 차이를
나란히 보여주는 팝업을 만들어줘.
✏️

직접 수정 미션 ② — 응용편

미션 4
품목 라이브러리

자주 쓰는 품목과 단가를 라이브러리에 저장해 두고, 버튼 한 번으로 견적서에 바로 추가합니다.

📚 라이브러리 버튼을 누르면 팝업이 열리고
품목명·단가를 등록할 수 있게 해줘.
등록된 품목은 localStorage에 저장하고
클릭 시 현재 견적서에 행으로 추가해줘.
⭐⭐⭐

미션 5
JSON 내보내기·가져오기

저장된 견적서 전체를 JSON 파일로 백업하고, 파일을 선택해 다시 불러올 수 있게 합니다.

📤 내보내기: 견적서 전체를 JSON 파일로 저장해줘.
Blob으로 만들어서 파일 다운로드해줘.
📥 가져오기: 파일 선택 시 FileReader로 읽어서
기존 목록과 합쳐줘 (중복 견적번호 제외).
⭐

미션 6
전체 할인율 적용

할인율 입력 시 계산 근거를 한 줄로 표시해 부가세가 왜 그 금액인지 바로 이해할 수 있게 합니다.

합계 영역에 할인율(%) 입력란을 추가해줘.
할인금액 = 소계 × 할인율 / 100
과세표준 = 소계 − 할인금액
부가세 = 과세표준 × 10%
총합계 = 과세표준 + 부가세

할인율이 0보다 클 때만 부가세 행 위에
계산 흐름 힌트를 한 줄 표시해줘.
예: 200원 × 5% = 10원 → 190원

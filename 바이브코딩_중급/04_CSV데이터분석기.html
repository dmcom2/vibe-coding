오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 FileReader

사용자 컴퓨터의 파일을 브라우저에서 직접 읽는 내장 객체. 서버 업로드 없이 동작

📌 CSV

쉼표(,)로 값을 구분한 표 형식 텍스트 파일. 엑셀에서 흔히 내보내는 형식

📌 split / 파싱

긴 텍스트를 구분자 기준으로 잘라 원하는 데이터 구조로 바꾸는 작업

📌 배열의 배열

행과 열이 있는 표 데이터를 표현하는 2차원 배열. rows[행][열]로 접근

📌 통계(합계/평균)

숫자 컬럼의 합계·평균·최소·최대 등을 reduce로 한 번에 계산

📌 드래그&드롭

파일을 끌어다 놓는 것만으로 업로드하는 UI 패턴. dragover/drop 이벤트로 구현

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!
📂

FileReader API — 텍스트 파일 읽기

사용자 컴퓨터의 파일을 서버 없이 브라우저에서 직접 읽기

// 파일 input 또는 드롭으로 File 객체 획득 function readFile(file) { const reader = new FileReader(); // 읽기 완료 이벤트 (비동기) reader.addEventListener('load', (e) => { const text = e.target.result; // 파일 내용 (문자열) parseCSV(text); }); // 텍스트 파일로 읽기 시작 reader.readAsText(file, 'UTF-8'); } // 파일 input change 이벤트 document.getElementById('fileInput') .addEventListener('change', (e) => { const file = e.target.files[0]; if (file) readFile(file); });
FileReader 주요 메서드

• readAsText(file) — 텍스트로 읽기 (CSV, TXT)
• readAsDataURL(file) — Base64로 읽기 (이미지)
• readAsArrayBuffer(file) — 바이너리 (엑셀 등)
⚠️

UTF-8 vs EUC-KR

한글 CSV가 깨지면 인코딩 문제입니다.
readAsText(file, 'EUC-KR')로 변경하거나 사용자에게 인코딩 선택을 제공하세요.

CSV 파싱 & 드래그&드롭

텍스트를 2차원 배열로 변환하고 드롭 영역 구현

CSV 파싱

이름,나이,점수 홍길동,25,88 김철수,30,92
function parseCSV(text) { const lines = text.split('\n') .filter(l => l.trim()); // 빈 줄 제거 const headers = lines[0] .split(',') .map(h => h.trim()); // 첫 줄 = 헤더 const rows = lines.slice(1) .map(l => l.split(',') .map(v => v.trim())); // 나머지 = 데이터 // → headers: ['이름','나이','점수'] // → rows: [['홍길동','25','88'], ...] return { headers, rows }; }

드래그&드롭

const dropZone = document.getElementById('dropZone'); // 드래그 진입 — 기본 동작 차단 dropZone.addEventListener('dragover', e => { e.preventDefault(); // 필수! e.dataTransfer.dropEffect = 'copy'; dropZone.classList.add('drag-over'); }); dropZone.addEventListener('dragleave', () => { dropZone.classList.remove('drag-over'); }); // 드롭 — 파일 획득 dropZone.addEventListener('drop', e => { e.preventDefault(); const file = e.dataTransfer.files[0]; // File 객체 readFile(file); });

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

통계 계산 — reduce 활용

배열 메서드로 숫자 컬럼의 통계값을 한 번에 계산

function calcStats(values) { // 숫자로 변환 가능한 값만 필터 const nums = values .map(v => parseFloat(v)) .filter(n => !isNaN(n)); if (nums.length === 0) return null; // 숫자 컬럼 아님 const sum = nums.reduce((a, b) => a + b, 0); const avg = sum / nums.length; const min = Math.min(...nums); const max = Math.max(...nums); return { count: nums.length, missing: values.length - nums.length, sum, avg, min, max }; } // 컬럼 인덱스 i의 모든 값 추출 const colValues = rows.map(row => row[i]); const stats = calcStats(colValues);

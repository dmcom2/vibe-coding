3단계로 쌓아 올리는 실전 프로젝트 — 30분 시간표 · 서버 겹침 판정 · AI 말로 예약

🛡 겹침 · 인원 검사
🖥 Node.js 서버

오늘 만드는 것

회의실 4곳의 하루를 30분 칸으로 보여주고, 쉽게 예약하고, 겹치는 예약은 화면과 서버가 두 번 막는 시스템

🗓️

시간표에서 바로 예약

회의실 4곳 × 09:00~18:00 30분 칸. 빈 칸을 누르거나 옆으로 끌어 범위를 고르면 예약 창이 열리고, 내 예약은 블록 끝을 끌어 시간을 바꿉니다.

🧩

쉬운 예약 창

회의 이름 · 시간(30분 · 1시간 · 오전 · 하루 종일) · 인원(− +)을 버튼으로 고르고, 회의실 카드 4장에 그 시간 ✅ 비어 있음 / ⛔ 사용 중 / 추천이 바로 보입니다.

🔁

반복 예약 + 서버 판정

매일(평일) · 매주 · 매달 n회. 날짜마다 서버가 겹침을 판정해 되는 날만 예약하고 겹치는 날은 건너뜁니다. 동시에 눌러도 먼저 저장된 예약이 이깁니다(409).

🖨️

A4 안내문 + AI 말로 예약

확정하면 회의실 문 앞에 붙일 A4 안내문(회의실 · 제목 · 시간 · 담당자)을 한 장으로 인쇄. "내일 오후 2시 6명 1시간 회의"처럼 말로도 예약합니다.

📁

최종 파일 구조
index.html  ·  server.js  ·  .env.example → .env  ·  data.json (자동 생성)  ·  start.bat

🗺️

과제 진행 순서 — 3단계

각 단계마다 브라우저에서 직접 확인하고 다음 단계로 넘어가세요

1

1단계 — 시간표 · 쉬운 예약 창 · A4 안내문 (index.html 한 파일)

서버 없이 파일을 바로 열어도 동작하는 화면. 시간표, 끌어서 범위 선택 · 시간 조정, 버튼으로 고르는 예약 창과 실시간 검사, 확정 창과 A4 안내문 인쇄까지.
→ 겹치는 방은 카드에 ⛔, 확정 후 안내문이 A4 한 장으로 나오면 성공

2

2단계 — Node.js 서버 · data.json · 반복 예약

server.js 생성. Node.js 기본 모듈(http · fs · path)만 사용 — npm install 불필요. 같은 규칙으로 서버가 다시 검사(409)하고, 반복 예약은 날짜마다 판정해 되는 날만 저장.
→ 매주 4회 예약 중 겹치는 주만 건너뛰고, 창 두 개 동시 예약이 거절되면 성공

3

3단계 — AI 말로 예약 + 이번 주 가동률

Gemini가 문장에서 예약 정보를 JSON으로 뽑고, 서버가 규칙에 맞게 다듬고, 앱이 빈 방을 추천합니다. Chart.js로 회의실별 가동률.
→ 문장 하나로 예약 창이 채워지면 성공

💡 2단계부터는 서버 실행이 필요합니다. 터미널에서 node server.js 실행 후 http://localhost:3004 접속. 또는 start.bat 더블클릭(.env가 없으면 .env.example을 복사해 만들어 줍니다).

2단계 — Node.js 서버 · data.json · 반복 예약

화면 검사는 '안내', 서버 검사는 '최종 판정'입니다

🖥️
server.js · data.json
기본 모듈만 (http · fs · path · https), 포트 .env의 PORT (없으면 3004)
{ reservations: [ { id, room, date, start, end, title, owner, people, createdAt, seriesId?, repeat?, seq?, total? } ] }
🌐
API
GET /api/reservations · POST → 201 / 400 / 409 · PUT /:id (자기 자신은 겹침 비교에서 빼기) · DELETE /:id
POST /api/reservations/import (처음 샘플) · GET /api/status → { ok, geminiReady, model }
🔁
반복 예약 — 예약 창 ⑥
[반복 안 함 · 매일(평일) · 매주 · 매달] + 횟수 2~26 (− +), 날짜마다 ✅ / ⛔ 미리보기
매일은 주말 건너뜀, 매달 31일처럼 없는 날은 그 달 말일, '4회 중 3회 예약 · 겹치는 1회는 건너뜀'
📦
POST /api/reservations/batch · DELETE /api/reservations/series/:id?from=날짜
날짜마다 서버가 검사 → 되는 날만 저장 { created, skipped, seriesId }, 모두 안 되면 409
반복 블록에 🔁, 상세 창 [이 날만 취소] [이후 반복 모두 취소], 안내문은 날짜 목록 표 한 장
⚖️
서버 최종 판정 + 정적 파일 차단
겹치면 409 → 화면은 목록을 다시 받아 겹친 회의를 보여주기
.env 같은 점 파일 · server.js · data.json · start.bat · ../ 경로는 403 (안 막으면 /.env로 키 노출)
🔄
연결 표시 + start.bat
서버가 있으면 '서버 연결', 없으면 '브라우저 모드 (저장 안 됨)'

자주 막히는 문제 & 해결법

이 화면으로 돌아와서 확인하세요

❓ 10:00 끝 · 10:00 시작이 겹친다고 나와요

비교에 '같다'가 들어갔습니다. "겹침은 시작 < 상대 끝, 끝 > 상대 시작일 때만"이라고 요청하세요.

❓ 블록이 칸과 어긋나거나 끌면 튀어요

시각 ↔ 칸 계산이 틀렸습니다. "(시작 분 − 540) ÷ 30 + 2번째 열", "끈 거리 ÷ 칸 너비를 반올림한 만큼 30분씩"처럼 기준을 알려 주세요.

❓ 시간만 늘렸는데 자기 자신과 겹친대요

수정할 때 자기 예약까지 비교했습니다. "PUT에서는 같은 id는 겹침 비교에서 빼줘"라고 요청하세요. 서버 POST · PUT 모두 같은 규칙으로 409.

❓ 오늘 지난 시간도 예약돼요

날짜만 비교했습니다. "오늘이면 현재 시각보다 이른 시작은 막아줘, 날짜는 로컬 기준으로"라고 요청하세요.

❓ AI가 오후 2시를 02:00으로 읽어요

프롬프트에 오늘 날짜 · 요일과 "'오후 2시'는 14:00" 규칙을 넣고, 서버에서 09~18시로 다시 맞추세요.

❓ /.env 주소로 키가 보여요

정적 파일 서빙에 차단이 없습니다. "점으로 시작하는 파일과 server.js · data.json은 403으로 막아줘"라고 요청하세요.

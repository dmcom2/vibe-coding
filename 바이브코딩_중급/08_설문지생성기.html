오늘 나오는 용어 미리보기

외우지 마세요 — 눈에만 익혀두면 수업이 술술 풀립니다

📌 동적 폼 생성

질문 데이터 배열을 바탕으로 입력 화면(HTML)을 그때그때 코드로 만들어내는 방식. 질문이 늘어도 코드는 그대로

📌 질문 유형(type)

각 질문이 text·radio·checkbox·rating 중 무엇인지 나타내는 값. 유형에 따라 다른 입력 UI가 그려짐

📌 응답 배열

제출된 설문 응답이 하나씩 쌓이는 객체(object)들의 배열. 통계 계산의 원본 데이터

📌 시각화(Chart.js)

숫자로 된 응답 집계를 막대·도넛 그래프로 그려주는 CDN 라이브러리

📌 로컬 통계 집계

서버 없이 브라우저 안에서 응답 배열을 순회하며 직접 세고 합산해 통계를 만드는 방식

📌 localStorage 목록 관리

설문 구조와 응답 목록을 브라우저 보관함에 저장해 새로고침해도 유지되게 하는 방식

🌱 낯선 단어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

renderSurvey — 중첩 렌더링

questions 배열 → map → innerHTML 패턴

function renderSurvey() { const html = questions.map((q, idx) => ` <div class="question" data-id="${q.id}"> <p class="q-label"> ${idx + 1}. ${q.label} ${q.required ? '<span class="req">*</span>' : ''} </p> ${renderInput(q)} </div> `).join(''); // 배열 → 문자열 병합 document.getElementById('survey').innerHTML = html; } // 유형별 입력 렌더링 function renderInput(q) { switch (q.type) { case 'text': return `<input type="text" name="q${q.id}">`; case 'radio': case 'checkbox': return q.options.map(opt => ` <label> <input type="${q.type}" name="q${q.id}" value="${opt}"> ${opt} </label>`).join(''); // 중첩 map! case 'rating': return [...Array(q.max)].map((_, i) => `<span class="star" data-val="${i+1}">★</span>` ).join(''); } }

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트·변환 등 기능이 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

🧠

핵심 기술 개념

이미지 편집 도구의 4가지 핵심 브라우저 API

🎨

Canvas API

HTML <canvas> 요소에 이미지를 그리고, 픽셀 단위로 색상을 조작합니다. getImageData로 픽셀 배열을 읽어 밝기·채도를 수학적으로 변환합니다.

📂

FileReader

로컬 파일을 읽어 DataURL로 변환합니다. 드래그 앤 드롭이나 <input type="file">로 선택된 이미지를 화면에 표시하는 시작점입니다.

💾

Blob & URL.createObjectURL

Canvas의 toBlob()로 처리된 이미지를 Blob으로 내보냅니다. createObjectURL로 임시 URL을 만들어 미리보기와 다운로드에 사용합니다.

🚀

ESM Dynamic Import

import() 함수로 외부 라이브러리를 필요할 때만 로드합니다. AI 배경제거 모듈을 버튼 클릭 시점에 가져오므로 초기 로딩 속도가 빠릅니다.

🎨

Canvas API — 픽셀 처리 구조

이미지 압축·필터·회전의 공통 패턴

JS// 1. 이미지를 캔버스에 그리기 const c = document.getElementById('work-canvas'); c.width = origImg.width; c.height = origImg.height; const ctx = c.getContext('2d'); ctx.drawImage(origImg, 0, 0); // 2. 픽셀 데이터 읽기 — RGBA 배열 (4바이트/픽셀) const id = ctx.getImageData(0, 0, c.width, c.height); const data = id.data; for (let i = 0; i < data.length; i += 4) { data[i] += bright * 2.55; // R 채널 밝기 조정 data[i+1] += bright * 2.55; // G 채널 밝기 조정 data[i+2] += bright * 2.55; // B 채널 밝기 조정 } ctx.putImageData(id, 0, 0); // 3. Blob으로 내보내기 (JPEG 품질 0.92) c.toBlob(blob => setResult(blob), 'image/jpeg', 0.92);
회전·반전은 ctx.rotate()와 ctx.scale(-1, 1)을 ctx.save() / ctx.restore()로 감싸 변환 행렬을 누적합니다.

@imgly/background-removal 라이브러리

서버 없이 브라우저에서 AI로 배경 자동 제거 (누끼 따기)

🔒 클라이언트 100% 처리

이미지 데이터를 외부 서버로 전송하지 않습니다. 모든 처리가 사용자의 브라우저 메모리 안에서만 일어나므로 서버 API 비용이 없고 개인정보 보호에 강력합니다.

⚡ ONNX + WebAssembly / WebGPU

경량화된 AI 모델(ONNX 포맷)과 WebAssembly·WebGPU 기술로 신경망 연산을 수행합니다. 별도 소프트웨어 설치 없이 브라우저만으로 AI 추론이 가능합니다.

📁 다양한 입출력 포맷

입력: URL, File, Blob, ImageData, ArrayBuffer 등
출력: 배경이 투명(PNG)으로 처리된 Blob 반환
전경·배경·마스크 출력 타입 선택 가능

📊 모델 선택 & 진행률 콜백

isnet_fp16 — 기본값, 약 80MB, 고정밀
isnet_quint8 — 경량, 약 40MB, 빠름
첫 실행 시 모델 다운로드 진행률을 UI로 표시 가능

핵심 요약. @imgly/background-removal v1.4.5는 설치·서버 없이 브라우저 한 줄 import로 AI 누끼 따기가 가능한 오픈소스 라이브러리입니다. 첫 실행 시 모델 파일을 CDN에서 다운로드(30~80MB)하며, 이후에는 브라우저 캐시가 적용됩니다.
🚀

Blob 다운로드 & AI 배경 제거

처리 결과를 저장하고, 필요할 때만 AI 모델을 로드하는 패턴

💾 Blob URL 다운로드

// Blob → 임시 URL → 자동 클릭 function downloadResult() { const a = document.createElement('a'); a.href = URL.createObjectURL(resultBlob); a.download = 'image_edited.jpg'; a.click(); }

✂️ ESM Dynamic Import로 AI 로드

// 버튼 클릭 시 처음 다운로드 async function runBgRemove() { const { removeBackground } = await import('https://esm.sh/@imgly/background-removal@1.4.5'); const blob = await removeBackground(origImg.src); setResult(blob); // PNG 투명 배경 }
핵심 포인트. Dynamic Import는 함수처럼 호출되므로 페이지 로드 시가 아닌 버튼 클릭 시점에 네트워크 요청이 발생합니다. 첫 번째 클릭만 느리고 이후에는 브라우저 캐시가 사용됩니다.

효과적인 프롬프트 구성법

기능 명세를 AI가 오해 없이 구현하게 만드는 4가지 원칙

✅ POINT 1: UI 구조를 번호로 명시

헤더/드롭존/파일바/탭/미리보기/다운로드바를 순서대로 나열하면 AI가 레이아웃을 건너뛰거나 생략하지 않습니다.

✅ POINT 2: 탭별 동작 범위 상세 기술

각 탭의 컨트롤(슬라이더 범위, 체크박스, 프리셋 목록)을 구체적으로 서술해 기능 누락 없이 구현되게 합니다.

✅ POINT 3: 라이브러리와 방식 명시

"@imgly/background-removal@1.4.5를 esm.sh로 ESM dynamic import"처럼 라이브러리명·버전·로드 방식까지 명시해야 정확히 구현됩니다.

✅ POINT 4: 원본 보호 명시

"원본 파일은 변경하지 않고 Canvas에서만 처리"라고 명시해야 사용자 파일을 덮어쓰는 실수를 방지합니다.

프롬프트 해설 — 왜 효과적인가?

높은 완성도를 만드는 프롬프트 구성 요소

✅ POINT 1: 레이아웃 구조를 번호로 명시

헤더→파일바→탭→미리보기→다운로드바→일괄박스 순으로, 도움말 모달의 등장 조건·닫기 방법까지 적으면 AI가 UX 흐름 전체를 빠짐없이 구현합니다.

✅ POINT 2: 탭별 컨트롤과 연동 동작 상세 기술

슬라이더 범위·프리셋 목록·비율 자동 계산·실시간 미리보기 등 상세 동작을 쓸수록 기능 누락이 줄어들고 AI가 놓치는 UX 디테일이 사라집니다.

✅ POINT 3: 알고리즘과 API 이름을 힌트로 제공

"픽셀화는 imageSmoothingEnabled:false", "비네팅은 createRadialGradient", "ctx.globalAlpha로 투명도"처럼 구현 힌트를 주면 AI가 검색 없이 올바른 Canvas API를 바로 선택합니다.

✅ POINT 4: 외부 라이브러리·제약 조건 명시

@imgly 버전·CDN·로드 방식, JSZip 동적 로드, "Live Server 필수" 제약까지 적어야 실제로 동작하는 코드가 생성됩니다. 라이브러리명만 쓰면 버전·로드 방식이 달라져 오류가 납니다.

🚀

실행 및 확인 절차

생성된 코드를 구동하는 4단계 과정

1

파일 생성 확인

VS Code 탐색기에 index.html, style.css, script.js가 생성되었는지 확인합니다.

2

Go Live 실행

index.html을 열고 우측 하단 Go Live를 클릭해 브라우저에서 앱을 실행합니다.

3

이미지 드래그 & 기능 테스트

이미지를 드롭존에 드래그하고 각 탭(압축/리사이즈/필터/회전)의 기능을 순서대로 테스트합니다.

4

배경제거 테스트 (인터넷 필수)

✂️ 배경제거 탭에서 인물 사진을 올리고 [배경 제거 시작]을 클릭합니다. 첫 실행은 30~60초 소요됩니다.

🆘

자주 막히는 트러블슈팅

실습 중 에러가 발생할 때 체크해야 할 사항

🖼️ "드래그해도 이미지가 안 보여요"

dragover 이벤트에 e.preventDefault()가 있는지 확인하세요. 없으면 브라우저가 파일 기본 동작으로 열어버립니다.

🎨 "필터 적용 후 화면이 안 바뀌어요"

getImageData → 픽셀 수정 → putImageData → toBlob() 순서가 정확한지 확인하세요. 순서가 틀리면 원본 그대로 출력됩니다.

✂️ "배경제거가 오류나요"

인터넷 연결과 https://esm.sh 접속 여부를 먼저 확인하세요. file:// 프로토콜에서는 ESM import가 차단되므로 반드시 Live Server로 실행하세요.

💾 "다운로드가 안 돼요"

resultBlob이 null이면 다운로드 버튼이 비활성화됩니다. 탭 변경 후 처리 함수가 실제로 호출되는지 콘솔에서 확인하세요.

🔍

이미지 처리 핵심 코드 분석

회전·반전의 Canvas 변환 행렬 패턴

JS// 회전 + 반전을 한 번에 처리하는 Canvas 변환 패턴 function renderRotate() { const sw = origImg.width, sh = origImg.height; const is90 = rotAngle === 90 || rotAngle === 270; // 90°/270° 회전 시 캔버스 폭↔높이 교환 const cw = is90 ? sh : sw; const ch = is90 ? sw : sh; c.width = cw; c.height = ch; ctx.save(); ctx.translate(cw / 2, ch / 2); // 중심 이동 ctx.rotate((rotAngle * Math.PI) / 180); // 회전 ctx.scale(flipH ? -1 : 1, flipV ? -1 : 1); // 반전 ctx.drawImage(origImg, -sw / 2, -sh / 2); ctx.restore(); // 변환 행렬 복원 c.toBlob(blob => setResult(blob), 'image/jpeg', 0.92); }

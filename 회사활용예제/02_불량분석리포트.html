핵심 기술 ① — 파레토 혼합 차트

같은 canvas에 막대(건수) + 꺾은선(누적%)을 동시에 그리는 mixed chart
function renderPareto() { if(paretoChart) paretoChart.destroy(); // 기존 차트 정리 const ctx = document.getElementById('paretoChart').getContext('2d'); paretoChart = new Chart(ctx, { data: { labels: sorted.map(([k]) => k), // 불량 유형명 datasets: [ { type: 'bar', label: '불량수(매)', data: counts, yAxisID: 'y' }, { type: 'line', label: '누적률(%)', data: cumPcts, yAxisID: 'y2' } ] }, options: { scales: { y: { beginAtZero: true }, // 왼쪽 축 — 건수 y2: { min: 0, max: 100, position: 'right' } // 오른쪽 축 — % } } }); }
💡 datasets 배열의 각 항목이 type과 yAxisID를 개별 선언하므로, 건수(매)와 비율(%)처럼 단위가 다른 두 데이터가 한 화면에서 스케일 겹침 없이 표시됩니다.

핵심 기술 ② — 누적 비율(파레토) 계산

건수 집계 → 내림차순 정렬 → 누적 합 → 총합으로 나누기
// ① 불량유형별 건수 집계 const byType = {}; ds.forEach(d => { byType[d.type] = (byType[d.type]||0) + d.qty; }); // ② 건수 많은 순으로 내림차순 정렬 const sorted = Object.entries(byType).sort((a,b) => b[1]-a[1]); const total = sorted.reduce((s,[,v]) => s+v, 0); // ③ 누적 합을 하나씩 더하며 누적 비율(%) 계산 let cum = 0; const cumPcts = sorted.map(([,v]) => { cum += v; return +(cum/total*100).toFixed(1); });
💡 건수가 많은 유형부터 내림차순 정렬한 뒤 누적 합을 총합으로 나누면 "상위 몇 개가 전체의 몇 %를 차지하는지"가 바로 계산됩니다. 이 값이 파레토 차트의 꺾은선이 됩니다.

핵심 기술 ③ — 심각도(Severity) 3단계 분류

색상으로 관리 우선순위를 즉시 구분
1

심각(Critical)

즉시 생산 중단 여부를 검토해야 하는 수준. KPI 카드와 목록에서 진한 빨강(#b91c1c)으로 강조됩니다.

2

주의(Major)

당일 내 조치가 필요한 수준. 주황/앰버 계열(var(--amber)) 색상으로 표시됩니다.

3

경미(Minor)

차회 정기 점검 시 조치하면 되는 수준. 회색 계열로 표시되며, 등록 시 기본값입니다.

4

등록 화면에서 선택

현재는 불량 등록 모달의 <select id="d-severity">에서 담당자가 직접 선택합니다. "불량 건수에 따라 심각도를 자동 판정해줘"라고 AI에게 요청하면 자동화도 가능합니다.

핵심 기술 ④ — 다중 필터 & 날짜 범위 비교

기간·라인·불량유형 3가지 조건을 AND로 조합
function getFiltered() { const from = document.getElementById('f-from').value; const to = document.getElementById('f-to').value; const line = document.getElementById('f-line').value; const type = document.getElementById('f-type').value; return defects.filter(d => { if(from && d.date < from) return false; // 문자열 비교로 날짜 순서 판정 if(to && d.date > to) return false; if(line && d.line !== line) return false; if(type && d.type !== type) return false; return true; }); }
💡 YYYY-MM-DD 형식의 날짜 문자열은 비교 연산자(<, >)를 그대로 써도 시간 순서대로 정확히 비교됩니다. 4개 조건이 하나라도 어긋나면 걸러지는 AND 필터 구조입니다.

핵심 기술 ⑤ — 80% 기준 색상 강조

파레토 테이블에서 누적률 80%를 넘는 순간 색이 바뀐다
// 파레토 테이블 — 누적률 80% 이하는 빨강, 초과는 회색 let cum = 0; sorted.map(([type, cnt]) => { const pct = total ? (cnt/total*100) : 0; cum += pct; return `<td style="color:${cum<=80?'var(--red)':'var(--sub)'}"> ${cum.toFixed(1)}% </td>`; });
💡 누적률이 80%를 넘는 순간부터 회색으로 바뀌어, 표만 봐도 "여기까지가 집중 개선 대상"이 한눈에 구분됩니다. 차트에도 점선 기준선을 넣고 싶다면 "파레토 차트에 80% 기준 점선을 추가해줘"라고 AI에게 요청해보세요.

핵심 기술 ⑥ — CSV 내보내기 (한글 깨짐 방지)

BOM 문자 하나로 엑셀의 한글 깨짐을 막는다
function exportCSV() { const ds = getFiltered(); // 현재 필터가 적용된 데이터만 내보냄 const rows = ['날짜,라인,제품명,불량유형,수량,심각도,발견공정,원인,조치내용,담당자']; ds.forEach(d => rows.push(`${d.date},${d.line},${d.product},${d.type},${d.qty},...`)); const blob = new Blob(['﻿' + rows.join('\n')], // ★ BOM 추가 { type: 'text/csv;charset=utf-8;' }); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = '불량분석.csv'; a.click(); }
💡 ﻿ (BOM) = Byte Order Mark. Excel이 UTF-8 한글을 올바르게 읽도록 파일 맨 앞에 삽입하는 표시입니다. 없으면 "단락(Short)" 같은 한글이 깨져 보입니다.

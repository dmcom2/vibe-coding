📌 마스터-디테일

목록(마스터)을 클릭하면 상세(디테일)가 옆에 표시되는 2단 화면 구성 패턴

📌 every()

배열의 모든 요소가 조건을 만족하는지 검사. 하나라도 false면 전체 false

📌 @media print

인쇄할 때만 적용되는 CSS 규칙 — 화면용 버튼·헤더를 숨기고 문서만 남김

📌 템플릿 리터럴

백틱(`)과 ${변수}로 문자열에 값을 끼워 넣는 JS 문법

📌 localStorage

브라우저에 데이터를 영구 저장하는 저장소 — 새로고침해도 성적서가 유지됨

📌 padStart()

문자열 앞을 0 등으로 채워 자릿수를 맞추는 메서드. 성적서 번호 QC-202606-001 생성에 사용

🌱 낯선 용어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

핵심 기술 ① — 마스터-디테일 레이아웃

좌측 성적서 목록 클릭 → 우측에 상세 문서 표시
// 현재 선택된 성적서 id를 기억하는 상태 변수 let currentId = null; function selectCert(id) { currentId = id; // ① 선택 상태 저장 const c = certs.find(x => String(x.id) === String(id)); // ② 성적서 상세 문서 HTML을 우측 패널에 렌더링 document.getElementById('certDoc').innerHTML = ` <div class="doc-title"><h2>PCB 검사 성적서</h2></div> <div class="section-title">1. 외관 검사</div>${mkTable(c.visual)} <div class="section-title">2. 치수 검사</div>${mkTable(c.dim)} <div class="section-title">3. 전기 특성</div>${mkTable(c.elec)}`; renderList(); // ③ 목록도 다시 그려 선택 하이라이팅 반영 }
💡 currentId 하나로 "지금 무엇이 선택됐는지"를 기억합니다. 목록을 다시 그릴 때마다 currentId와 비교해 해당 항목에만 강조 스타일을 입힙니다.

핵심 기술 ② — 검사 항목 배열 정의

검사 항목을 배열로 정의해두면 추가·수정이 한 줄로 끝난다
// 외관 검사 5개 항목 — name(항목명) + spec(판정 기준) const VISUAL_ITEMS = [ { name: '외관 이물', spec: '이물 없음' }, { name: '스크래치', spec: '0.1mm 이하' }, { name: '솔더마스크 박리', spec: '없음' }, { name: '동박 노출', spec: '없음' }, { name: '실크인쇄 선명도', spec: '명확' }, ]; // 치수 검사 5개 — 길이/폭/두께/드릴홀경/랜드폭 (mm) const DIM_ITEMS = [ { name: '기판 길이', spec: '규격±0.2' }, { name: '기판 폭', spec: '규격±0.2' }, { name: '기판 두께', spec: '규격±0.1' }, ]; // 전기 특성 4개 — 절연저항/단락/개방/임피던스 const ELEC_ITEMS = [ { name: '절연저항', spec: '≥100MΩ' }, { name: '단락 검사', spec: '단락 없음' }, ];
💡 항목을 코드 여러 곳에 흩어 적지 않고 배열 하나로 모아두면, 회사 실제 검사 기준으로 바꿀 때 이 배열만 수정하면 됩니다 (실습 미션 1).

핵심 기술 ③ — 동적 행 생성 (입력 폼)

검사 항목 배열을 map()으로 돌려 입력 테이블 행을 자동 생성
function buildInspectRows(tbodyId, items, data) { document.getElementById(tbodyId).innerHTML = items.map((item, idx) => ` <tr> <td>${item.name}</td> <td>${item.spec}</td> <td><input id="${tbodyId}-v-${idx}" placeholder="측정값 입력"></td> <td> <select id="${tbodyId}-r-${idx}"> <option value="OK">OK</option> <option value="NG">NG</option> </select> </td> </tr>`).join(''); } // 저장 시 입력값을 다시 배열로 수집 function getInspectData(tbodyId, items) { return items.map((item, idx) => ({ ...item, value: document.getElementById(`${tbodyId}-v-${idx}`).value, result: document.getElementById(`${tbodyId}-r-${idx}`).value, })); }
💡 항목이 5개든 10개든 같은 코드가 그대로 동작합니다. VISUAL_ITEMS/DIM_ITEMS/ELEC_ITEMS 3개 배열에 동일한 함수 2개(build/get)만 재사용합니다.

핵심 기술 ④ — 자동 합부 판정 & 채번

every()로 판정하고, padStart()로 성적서 번호를 자동 생성
1

자동 합부 판정 — every()

[...visual,...dim,...elec].every(x => x.result === 'OK') — 세 영역을 합쳐 단 1줄로 전체 OK 여부 판정.

2

합격/불합격 결정

overall = allOK ? '합격' : '불합격' — 항목 하나라도 NG면 전체가 자동으로 "불합격"이 됩니다.

3

성적서 번호 자동 채번

QC-${년}${월}-${순번.padStart(3,'0')}` — 예: QC-202606-001, QC-202606-002 …

4

선택 항목 하이라이팅

currentId와 비교해 selected 클래스 부여 — CSS로 배경색·좌측 강조선을 다르게 표시.

핵심 기술 ⑤ — 인쇄 전용 CSS

@media print로 화면용 요소를 숨기고 성적서 문서만 출력
/* 인쇄할 때만 적용되는 스타일 */ @media print { /* 헤더·필터바·목록·no-print 요소는 화면에서만 필요 */ .header, .filter-bar, .card-list, .no-print { display: none !important; } /* 좌우 2단 레이아웃 → 1단(문서 전체 너비)으로 전환 */ .layout { grid-template-columns: 1fr; } /* 그림자·테두리 제거해 인쇄용 문서처럼 깔끔하게 */ .cert-panel { box-shadow: none; border: none; } }
💡 화면에서 쓰던 버튼·검색창·목록은 인쇄 결과에 필요 없는 요소입니다. no-print 클래스를 붙여두면 @media print 블록에서 한 번에 숨길 수 있습니다.

데이터 구조 명시

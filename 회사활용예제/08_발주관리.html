핵심 기술 ① — 동적 행 추가 & 실시간 금액 계산

+ 버튼으로 품목 행을 무한히 추가하고, 입력 즉시 금액을 계산하는 패턴
// ① 동적 품목 행 추가 — 행마다 고유 idx 부여 let itemCount = 0; // 삭제해도 idx는 계속 증가 → 중복 방지 function addItemRow(preset = null) { itemCount++; const idx = itemCount; const row = document.createElement('tr'); row.id = `item-row-${idx}`; row.innerHTML = ` <td><input id="i-name-${idx}"></td> <td><input type="number" id="i-qty-${idx}" oninput="calcRowTotal(${idx})"></td> <td><input type="number" id="i-price-${idx}" oninput="calcRowTotal(${idx})"></td> <td id="i-total-${idx}">₩0</td>`; document.getElementById('itemRows').appendChild(row); } // ② 행 합계 → 전체 합계 실시간 계산 function calcRowTotal(idx) { const qty = parseFloat(document.getElementById(`i-qty-${idx}`)?.value) || 0; const price = parseFloat(document.getElementById(`i-price-${idx}`)?.value) || 0; document.getElementById(`i-total-${idx}`).textContent = `₩${(qty*price).toLocaleString()}`; updateTotal(); // 모든 행을 다시 훑어 grandTotal 갱신 }
💡 id^="i-qty-" 선택자로 모든 수량 입력을 한 번에 훑어 합계를 매번 다시 계산합니다. 행이 몇 개든, 삭제되든 항상 정확합니다.

핵심 기술 ② — 발주 데이터 구조 & 발주번호 자동채번

발주서 한 건을 하나의 객체로 표현하고, 번호는 연월+순번으로 자동 생성
// 발주서 데이터 구조 const po = { id: 1001, no: 'PO-202606-001', vendor: '(주)동양CCL', dueDate: '2026-06-08', payment: '월말 30일 결제', status: 'ordered', // ordered | partial | received | cancelled items: [ { name: '동박적층판(CCL)', qty: 2000, price: 3800, received: 0 }, { name: '드라이필름', qty: 50, price: 12000, received: 0 }, ], }; // 발주 번호 자동 채번 — 연월(yyyymm) + 순번 3자리 function generatePONo() { const y = today.slice(0, 4); const m = today.slice(5, 7); const seq = String(pos.length + 1).padStart(3, '0'); return `PO-${y}${m}-${seq}`; // 결과: PO-202606-001 }
💡 received 필드를 qty와 별도로 두어 입고량을 발주량과 독립 추적합니다. 이 구조 덕분에 부분입고가 자연스럽게 표현됩니다.

핵심 기술 ③ — 부분 입고 처리 & 진행률 표시

입고 수량은 발주량을 넘지 않게 누적하고, 전체 완료 여부로 상태를 자동 전환
// 입고 처리 — 품목별 이번 입고 수량을 받아 누적 function saveReceive() { const po = pos.find(x => String(x.id) === String(receivePoId)); po.items.forEach((item, idx) => { const add = parseInt(document.getElementById(`r-qty-${idx}`)?.value) || 0; // 최대 발주량까지만 입고 가능 — 초과 입력 방지 item.received = Math.min(item.qty, item.received + add); }); // 모든 품목이 발주량만큼 입고됐으면 완료 const allDone = po.items.every(i => i.received >= i.qty); po.status = allDone ? 'received' : 'partial'; } // 입고 진행률(%) 계산 function calcReceiveProgress(po) { const ordered = po.items.reduce((s,i) => s+i.qty, 0); const received = po.items.reduce((s,i) => s+i.received, 0); return ordered ? Math.round(received/ordered*100) : 0; }
💡 Math.min(item.qty, item.received + add)로 이중 입고(초과 입고)를 원천 차단합니다. 상태는 저장할 때마다 다시 계산되므로 항상 최신입니다.

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

브라우저 팝업/인쇄 차단 설정을 확인하세요. F12 → Console의 빨간 오류를 복사해 Cline에게 붙여넣으세요.

📥 "입고 수량을 입력해도 상태가 안 바뀌어요"

입고 확인 버튼을 눌러 저장했는지 확인하세요. 발주수량을 초과 입력하면 최대치로 자동 조정됩니다.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.
